一、选择题与填空题

(经典计算)题目[1]:1的无穷次幂型极限与等价无穷小替换

$\lim\limits_{x\to 0} \left(\frac{\arcsin x}{x}\right)^{\frac{1}{\sin^2 x}} = \underline{\qquad\qquad}$.

答案: $\mathrm{e}^{\frac{1}{6}}$ (或 $\sqrt[6]{\mathrm{e}}$)

主要思路:[利用 $1^\infty$ 型极限公式 $\lim u^v = \mathrm{e}^{\lim v(u-1)}$，结合 $\arcsin x$ 的泰勒展开式求解]

[1]识别极限类型:
当 $x\to 0$ 时，$\frac{\arcsin x}{x} \to 1$，$\frac{1}{\sin^2 x} \to \infty$，属于标准的 $1^\infty$ 型未定式。
由重要公式: 若 $\lim u(x) = 1, \lim v(x) = \infty$，则:
$$\lim u(x)^{v(x)} = \mathrm{e}^{\lim v(x)[u(x)-1]}$$

[2]计算指数部分的极限:
$$v(x)[u(x)-1] = \frac{1}{\sin^2 x}\left(\frac{\arcsin x}{x} - 1\right) = \frac{\arcsin x - x}{x\sin^2 x}$$
由等价无穷小 $\sin x \sim x$，分母 $x\sin^2 x \sim x^3$。
由麦克劳林展开式:
$$\arcsin x = x + \frac{1}{6}x^3 + o(x^3)$$
因此分子为:
$$\arcsin x - x = \frac{1}{6}x^3 + o(x^3)$$

[3]代入求极限值:
$$\lim_{x\to 0} v(x)[u(x)-1] = \lim_{x\to 0} \frac{\frac{1}{6}x^3}{x^3} = \frac{1}{6}$$
故原极限为:
$$\lim_{x\to 0} \left(\frac{\arcsin x}{x}\right)^{\frac{1}{\sin^2 x}} = \mathrm{e}^{\frac{1}{6}} = \sqrt[6]{\mathrm{e}}$$

(经典计算)题目[2]:变限积分与1的无穷次幂型极限

$\lim\limits_{x\to 0} \frac{1}{x}\int_0^x (1+\sin 2t)^{\frac{1}{t}}\,\mathrm{d}t = \underline{\qquad\qquad}$.

答案: $\mathrm{e}^2$

主要思路:[利用洛必达法则结合变上限积分求导，将外层转化为 $1^\infty$ 型极限计算]

[1]形式化与洛必达法则:
当 $x\to 0$ 时，分子 $\int_0^x (1+\sin 2t)^{\frac{1}{t}}\,\mathrm{d}t \to 0$，分母 $x\to 0$，属于 $\frac{0}{0}$ 型。
由洛必达法则对变限积分求导:
$$\lim_{x\to 0} \frac{\int_0^x (1+\sin 2t)^{\frac{1}{t}}\,\mathrm{d}t}{x} = \lim_{x\to 0} (1+\sin 2x)^{\frac{1}{x}}$$

[2]计算 $1^\infty$ 型极限:
$$\lim_{x\to 0} (1+\sin 2x)^{\frac{1}{x}} = \mathrm{e}^{\lim\limits_{x\to 0} \frac{\sin 2x}{x}} = \mathrm{e}^2$$

(经典计算)题目[3]:0的0次幂型未定式与对数化简

$\lim\limits_{x\to +\infty} \left(x^{\frac{2}{x}} - 1\right)^{\frac{2}{\ln x}} = \underline{\qquad\qquad}$.

答案: $\mathrm{e}^{-2}$ (或 $\frac{1}{\mathrm{e}^2}$)

主要思路:[取对数将 $0^0$ 型转化为 $\frac{0}{0}$ 型，再通过指数等价代换 $\mathrm{e}^u - 1 \sim u$ 展开对数项]

[1]分析极限类型:
当 $x\to +\infty$ 时，$\lim\limits_{x\to +\infty} x^{\frac{2}{x}} = \mathrm{e}^{\lim\limits_{x\to +\infty}\frac{2\ln x}{x}} = \mathrm{e}^0 = 1$。
因此底数 $x^{\frac{2}{x}} - 1 \to 0$，指数 $\frac{2}{\ln x} \to 0$，此为 $0^0$ 型未定式。

[2]取对数化简:
设 $y = \left(x^{\frac{2}{x}} - 1\right)^{\frac{2}{\ln x}}$，则:
$$\ln y = \frac{2}{\ln x} \ln\left(x^{\frac{2}{x}} - 1\right) = \frac{2}{\ln x} \ln\left(\mathrm{e}^{\frac{2\ln x}{x}} - 1\right)$$
由于当 $x\to +\infty$ 时，$\frac{2\ln x}{x} \to 0$，利用等价无穷小 $\mathrm{e}^u - 1 \sim u$ ($u\to 0$):
$$\mathrm{e}^{\frac{2\ln x}{x}} - 1 = \frac{2\ln x}{x}(1+o(1))$$
因此:
$$\ln\left(\mathrm{e}^{\frac{2\ln x}{x}} - 1\right) = \ln\left(\frac{2\ln x}{x}\right) + o(1) = \ln 2 + \ln\ln x - \ln x + o(1)$$

[3]计算对数极限并还原:
$$\ln y = \frac{2}{\ln x}\left(\ln 2 + \ln\ln x - \ln x + o(1)\right) = \frac{2\ln 2}{\ln x} + \frac{2\ln\ln x}{\ln x} - 2 + o(1)$$
当 $x\to +\infty$ 时，$\frac{\ln 2}{\ln x} \to 0$ 且 $\frac{\ln\ln x}{\ln x} \to 0$。
故:
$$\lim_{x\to +\infty} \ln y = -2 \implies \lim_{x\to +\infty} y = \mathrm{e}^{-2} = \frac{1}{\mathrm{e}^2}$$

(经典计算)题目[4]:变限二重结构极限与变量代换

计算 $\lim\limits_{x\to 0} \frac{\int_0^x \left[\mathrm{e}^{(t-x)^2} - 1\right]\sin t\,\mathrm{d}t}{x^2(\mathrm{e}^{x^2}-1)}$.

答案: $\frac{1}{12}$

主要思路:[分母等价无穷小替换为 $x^4$；分子作变量代换 $t = xu$ 消除积分限与被积函数中的 $x$ 耦合，提出 $x^4$ 计算定积分]

[1]分母等价无穷小化简:
当 $x\to 0$ 时，$\mathrm{e}^{x^2} - 1 \sim x^2$，故分母:
$$x^2(\mathrm{e}^{x^2} - 1) \sim x^4$$

[2]分子变量代换提取主部:
对于分子积分 $\int_0^x \left[\mathrm{e}^{(t-x)^2} - 1\right]\sin t\,\mathrm{d}t$，令 $t = xu$，则 $\mathrm{d}t = x\,\mathrm{d}u$，$u \in [0, 1]$:
$$(t-x)^2 = x^2(u-1)^2 \implies \mathrm{e}^{x^2(u-1)^2} - 1 = x^2(u-1)^2 + o(x^2)$$
$$\sin t = \sin(xu) = xu + o(x)$$
代入被积式:
$$\int_0^1 \left[x^2(u-1)^2 + o(x^2)\right]\left[xu + o(x)\right] x\,\mathrm{d}u = x^4 \int_0^1 u(u-1)^2\,\mathrm{d}u + o(x^4)$$

[3]计算多项式定积分并求极限:
$$\int_0^1 u(u-1)^2\,\mathrm{d}u = \int_0^1 (u^3 - 2u^2 + u)\,\mathrm{d}u = \left[\frac{u^4}{4} - \frac{2u^3}{3} + \frac{u^2}{2}\right]_0^1 = \frac{1}{4} - \frac{2}{3} + \frac{1}{2} = \frac{1}{12}$$
因此分子等价于 $\frac{1}{12}x^4$。
原极限为:
$$\lim_{x\to 0} \frac{\frac{1}{12}x^4 + o(x^4)}{x^4} = \frac{1}{12}$$

(综合分析)题目[5]:根据1的无穷次幂型极限反求函数局域阶数

设 $\lim\limits_{x\to 0} \left[1+2x+3x^2+\frac{f(x)}{x}\right]^{\frac{1}{x}} = \mathrm{e}^5$，则 $\lim\limits_{x\to 0}\left[1+\frac{f(x)}{x}\right]^{\frac{1}{x}} = \underline{\qquad\qquad}$.

答案: $\mathrm{e}^3$

主要思路:[利用 $1^\infty$ 型极限的指数转化，由已知极限建立关于 $\frac{f(x)}{x^2}$ 极限的线性方程，解出后求待求极限]

[1]展开已知极限的指数部分:
由 $\lim\limits_{x\to 0} \left[1+2x+3x^2+\frac{f(x)}{x}\right]^{\frac{1}{x}} = \mathrm{e}^5$ 可知:
$$\lim_{x\to 0} \frac{1}{x}\left(2x + 3x^2 + \frac{f(x)}{x}\right) = 5$$
展开得:
$$\lim_{x\to 0} \left(2 + 3x + \frac{f(x)}{x^2}\right) = 5$$

[2]求出核心项 $\lim\limits_{x\to 0}\frac{f(x)}{x^2}$:
由于 $\lim\limits_{x\to 0} 3x = 0$，故:
$$2 + \lim_{x\to 0} \frac{f(x)}{x^2} = 5 \implies \lim_{x\to 0} \frac{f(x)}{x^2} = 3$$

[3]计算目标极限:
目标极限为 $1^\infty$ 型:
$$\lim_{x\to 0}\left[1+\frac{f(x)}{x}\right]^{\frac{1}{x}} = \mathrm{e}^{\lim\limits_{x\to 0}\frac{1}{x}\cdot\frac{f(x)}{x}} = \mathrm{e}^{\lim\limits_{x\to 0}\frac{f(x)}{x^2}} = \mathrm{e}^3$$

(经典综合)题目[6]:变限二次二重积分的极限与洛必达法则

设函数 $f(x)$ 在点 $x=3$ 的某邻域内可微，且 $\lim\limits_{x\to 3} f(x)=0$，$\lim\limits_{x\to 3} f'(x)=4016$. 求 $\lim\limits_{x\to 3} \frac{\int_3^x \left[\int_t^3 f(s)\,\mathrm{d}s\right]\mathrm{d}t}{(3-x)^3}$.

答案: $\frac{2008}{3}$

主要思路:[分子是对 $t$ 的变限积分，其被积函数也是变限积分；应用洛必达法则逐次求导，或由泰勒展开分析分子主部]

[1]设定分子函数并逐次求导:
设 $F(x) = \int_3^x \left[\int_t^3 f(s)\,\mathrm{d}s\right]\mathrm{d}t$。
由微积分基本定理:
$$F'(x) = \int_x^3 f(s)\,\mathrm{d}s = -\int_3^x f(s)\,\mathrm{d}s$$
对 $F'(x)$ 求导:
$$F''(x) = -f(x)$$
对 $F''(x)$ 求导:
$$F'''(x) = -f'(x)$$

[2]对分母逐次求导:
分母 $G(x) = (3-x)^3$。
$$G'(x) = -3(3-x)^2$$
$$G''(x) = 6(3-x)$$
$$G'''(x) = -6$$

[3]连续应用洛必达法则:
由于 $\lim\limits_{x\to 3} F(x) = 0, \lim\limits_{x\to 3} F'(x) = 0, \lim\limits_{x\to 3} F''(x) = -f(3) = 0$，且分母及导数均在 $x\to 3$ 时趋于 0，连续三次应用洛必达法则:
$$\lim_{x\to 3} \frac{F(x)}{(3-x)^3} = \lim_{x\to 3} \frac{F'''(x)}{G'''(x)} = \frac{-f'(3)}{-6} = \frac{f'(3)}{6}$$
代入 $f'(3) = 4016$:
$$\lim_{x\to 3} \frac{F(x)}{(3-x)^3} = \frac{4016}{6} = \frac{2008}{3}$$

(概念辨析)题目[7]:等价无穷小在变限积分中的同阶性

设 $f(x), g(x)$ 在点 $x=0$ 的某邻域内连续，且当 $x\to 0$ 时，$f(x)$ 与 $g(x)$ 为等价无穷小，则当 $x\to 0$ 时，$\int_0^x f(t)(1-\cos t)\,\mathrm{d}t$ 是 $\int_0^x t^2 g(t)\,\mathrm{d}t$ 的 $(\quad)$.

[A] 等价无穷小
[B] 同阶但非等价无穷小
[C] 高阶无穷小
[D] 低阶无穷小

答案: [B]

主要思路:[利用洛必达法则对变限积分比值求极限，利用 $1-\cos x \sim \frac{1}{2}x^2$ 与 $f(x)\sim g(x)$ 得出常数比值 $\frac{1}{2}$]

[1]建立两积分的比值极限:
令 $I_1(x) = \int_0^x f(t)(1-\cos t)\,\mathrm{d}t$，$I_2(x) = \int_0^x t^2 g(t)\,\mathrm{d}t$。
当 $x\to 0$ 时 $I_1(x) \to 0, I_2(x) \to 0$。

[2]应用洛必达法则求导:
$$\lim_{x\to 0} \frac{I_1(x)}{I_2(x)} = \lim_{x\to 0} \frac{f(x)(1-\cos x)}{x^2 g(x)}$$

[3]代入等价无穷小关系:
因为当 $x\to 0$ 时，$1-\cos x \sim \frac{1}{2}x^2$，且 $f(x)\sim g(x)$，所以:
$$\lim_{x\to 0} \frac{f(x)(1-\cos x)}{x^2 g(x)} = \lim_{x\to 0} \left(\frac{f(x)}{g(x)} \cdot \frac{\frac{1}{2}x^2}{x^2}\right) = 1 \cdot \frac{1}{2} = \frac{1}{2}$$
极限为非零常数 $\frac{1}{2} \ne 1$，故 $I_1(x)$ 是 $I_2(x)$ 的同阶但非等价无穷小。选 [B]。

(中等计算)题目[8]:双无穷小展开确定待定系数

设当 $x\to 0$ 时，$a\int_0^{x^2}\cos t^2\,\mathrm{d}t$ 与 $\sin x - b\ln(1+x)$ 是等价无穷小，则 $(a,b) = (\quad)$.

[A] $(1, 2)$
[B] $(-1, 2)$
[C] $\left(\frac{1}{2}, 1\right)$
[D] $\left(-\frac{1}{2}, 1\right)$

答案: [C]

主要思路:[分别对变限积分和组合函数展开到 $x^2$ 阶，利用等价关系对比对应阶系数]

[1]展开变限积分部分:
被积函数 $\cos t^2 = 1 + o(1)$，故:
$$\int_0^{x^2} \cos t^2\,\mathrm{d}t = \int_0^{x^2} [1+o(1)]\,\mathrm{d}t = x^2 + o(x^2)$$
因此:
$$a\int_0^{x^2} \cos t^2\,\mathrm{d}t = ax^2 + o(x^2)$$

[2]展开 $\sin x - b\ln(1+x)$ 到 $x^2$ 阶:
$$\sin x = x - \frac{x^3}{6} + o(x^3)$$
$$\ln(1+x) = x - \frac{x^2}{2} + \frac{x^3}{3} + o(x^3)$$
故:
$$\sin x - b\ln(1+x) = (1-b)x + \frac{b}{2}x^2 + o(x^2)$$

[3]对比系数建立方程:
因为二者为等价无穷小，必须同为 $x^2$ 阶且系数相等:
一次项必须消去: $1 - b = 0 \implies b = 1$。
二次项系数相等: $a = \frac{b}{2} = \frac{1}{2}$。
故 $(a, b) = \left(\frac{1}{2}, 1\right)$。选 [C]。

(中等计算)题目[9]:被积函数差的等价代换与积分阶数

设当 $x\to 0$ 时，$\int_0^x (\mathrm{e}^{t\cos t^2}-\mathrm{e}^t)\,\mathrm{d}t$ 与 $ax^b$ 是等价无穷小量，则 $(a,b) = (\quad)$.

[A] $\left(-\frac{1}{6}, 3\right)$
[B] $\left(-\frac{1}{24}, 4\right)$
[C] $\left(-\frac{1}{2}, 5\right)$
[D] $\left(-\frac{1}{12}, 6\right)$

答案: [D]

主要思路:[提取公因式 $\mathrm{e}^t$，将被积函数转化为 $\mathrm{e}^t(\mathrm{e}^{t(\cos t^2 - 1)} - 1)$，利用等价代换求出主部后积分]

[1]化简被积函数:
$$\mathrm{e}^{t\cos t^2} - \mathrm{e}^t = \mathrm{e}^t \left(\mathrm{e}^{t(\cos t^2 - 1)} - 1\right)$$
由于当 $t\to 0$ 时，$\cos t^2 - 1 \sim -\frac{1}{2}(t^2)^2 = -\frac{1}{2}t^4$。
故指数部分:
$$t(\cos t^2 - 1) \sim -\frac{1}{2}t^5$$
由等价无穷小 $\mathrm{e}^u - 1 \sim u$ 及 $\mathrm{e}^t \to 1$:
$$\mathrm{e}^{t\cos t^2} - \mathrm{e}^t \sim -\frac{1}{2}t^5$$

[2]对主部积分求阶数与系数:
$$\int_0^x (\mathrm{e}^{t\cos t^2} - \mathrm{e}^t)\,\mathrm{d}t \sim \int_0^x \left(-\frac{1}{2}t^5\right)\,\mathrm{d}t = -\frac{1}{2} \cdot \frac{x^6}{6} = -\frac{1}{12}x^6$$

[3]对比确定 $(a,b)$:
由题意与 $ax^b$ 等价，因此:
$$a = -\frac{1}{12}, \quad b = 6$$
选 [D]。

(经典计算)题目[10]:有理分式极限与因式分解反求待定系数

已知 $\lim\limits_{x\to 3} \frac{x^3-3x^2+bx^2+x-3bx-3}{x+a} = 25$，则 $ab = \underline{\qquad\qquad}$.

答案: $-15$

主要思路:[分子在 $x=3$ 处为 0，因式分解提取 $(x-3)$，由极限非零确定分母必有因子 $(x-3)$，求得 $a$ 与 $b$]

[1]对分子多项式因式分解:
$$P(x) = x^3 - 3x^2 + bx^2 - 3bx + x - 3 = x^2(x-3) + bx(x-3) + 1(x-3) = (x-3)(x^2+bx+1)$$

[2]确定分母参数 $a$:
分式为 $\frac{(x-3)(x^2+bx+1)}{x+a}$。
当 $x\to 3$ 时，分子趋于 0。若极限为非零常数 $25$，分母必须也趋于 0，即:
$$3 + a = 0 \implies a = -3$$

[3]消去零因子并求 $b$:
约去因子 $(x-3)$ 后:
$$\lim_{x\to 3} (x^2 + bx + 1) = 3^2 + 3b + 1 = 10 + 3b = 25 \implies 3b = 15 \implies b = 5$$
因此:
$$ab = (-3) \times 5 = -15$$

(经典计算)题目[11]:已知指数极限反求函数局部无穷小比值

设函数 $f(x)$ 在 $0<|x|<1$ 上有定义，且满足 $\lim\limits_{x\to 0}\left[\cos x + \frac{f(x)}{x}\right]^{\frac{1}{x^2}} = \mathrm{e}^{-1}$，求 $\lim\limits_{x\to 0}\frac{f(x)}{\sin^3 x}$.

答案: $-\frac{1}{2}$

主要思路:[利用 $1^\infty$ 型极限公式，将已知极限转化为 $\frac{\cos x - 1 + f(x)/x}{x^2}$ 的极限，泰勒展开后求出 $\frac{f(x)}{x^3}$ 的极限]

[1]转化已知条件:
此极限为 $1^\infty$ 型，根据公式:
$$\lim_{x\to 0} \frac{1}{x^2}\left[\cos x - 1 + \frac{f(x)}{x}\right] = -1$$

[2]泰勒展开化简:
因为 $\cos x - 1 = -\frac{1}{2}x^2 + o(x^2)$，代入上式:
$$\lim_{x\to 0} \left[-\frac{1}{2} + \frac{f(x)}{x^3}\right] = -1$$
解得:
$$\lim_{x\to 0} \frac{f(x)}{x^3} = -1 + \frac{1}{2} = -\frac{1}{2}$$

[3]目标极限替换:
由于当 $x\to 0$ 时，$\sin^3 x \sim x^3$，故:
$$\lim_{x\to 0} \frac{f(x)}{\sin^3 x} = \lim_{x\to 0} \frac{f(x)}{x^3} = -\frac{1}{2}$$

(综合计算)题目[12]:分段函数极限与变限积分极限的拆分求值

设函数 $f(x)$ 在点 $x=0$ 处连续，$f(0)=\frac{1}{2}$，且函数 $g(x) = \begin{cases} \frac{1}{x}\sin\frac{x}{2}, & x<0, \\ x+\frac{1}{2}, & x\geqslant 0, \end{cases}$ 则 $\lim\limits_{x\to 0}\frac{xf(x)+g(x)\int_0^{2x}\cos t^2\,\mathrm{d}t}{xg(x)} = \underline{\qquad\qquad}$.

答案: $3$

主要思路:[分析 $g(x)$ 在 $x=0$ 的连续性得出 $\lim\limits_{x\to 0} g(x) = \frac{1}{2}$，拆分为两个独立极限分别计算]

[1]验证 $g(x)$ 在 $x=0$ 的极限:
$$\lim_{x\to 0^-} g(x) = \lim_{x\to 0^-} \frac{\sin(x/2)}{x} = \frac{1}{2}$$
$$\lim_{x\to 0^+} g(x) = \lim_{x\to 0^+} \left(x + \frac{1}{2}\right) = \frac{1}{2}$$
$$g(0) = \frac{1}{2}$$
故 $\lim\limits_{x\to 0} g(x) = \frac{1}{2} \ne 0$。

[2]拆分待求分式:
$$\frac{xf(x) + g(x)\int_0^{2x}\cos t^2\,\mathrm{d}t}{xg(x)} = \frac{f(x)}{g(x)} + \frac{\int_0^{2x}\cos t^2\,\mathrm{d}t}{x}$$

[3]分别求各部分极限:
第一部分:
$$\lim_{x\to 0} \frac{f(x)}{g(x)} = \frac{f(0)}{g(0)} = \frac{1/2}{1/2} = 1$$
第二部分应用洛必达法则:
$$\lim_{x\to 0} \frac{\int_0^{2x}\cos t^2\,\mathrm{d}t}{x} = \lim_{x\to 0} \frac{2\cos(4x^2)}{1} = 2$$
因此原极限为:
$$1 + 2 = 3$$

(极限与连续)题目[13]:数列极限所定义的函数的单侧连续性

$f(x) = \lim\limits_{n\to\infty} n^x \left[\left(1+\frac{1}{n}\right)^n - \mathrm{e}\right]$ 在 $x=1$ 处 $(\quad)$.

[A] 左极限存在，右极限不存在
[B] 左极限不存在，右极限存在
[C] 左、右极限都存在，但不相等
[D] 连续

答案: [A]

主要思路:[利用 $(1+1/n)^n$ 的二阶渐近展开式得出 $(1+1/n)^n - \mathrm{e} \sim -\frac{\mathrm{e}}{2n}$，由此分析 $f(x)$ 在 $x<1, x=1, x>1$ 时的取值与单侧极限]

[1]渐近展开 $(1+\frac{1}{n})^n$:
$$\left(1+\frac{1}{n}\right)^n = \mathrm{e}^{n\ln(1+1/n)} = \mathrm{e}^{n\left(\frac{1}{n} - \frac{1}{2n^2} + o(1/n^2)\right)} = \mathrm{e}^{1 - \frac{1}{2n} + o(1/n)} = \mathrm{e}\left(1 - \frac{1}{2n} + o\left(\frac{1}{n}\right)\right)$$
故:
$$\left(1+\frac{1}{n}\right)^n - \mathrm{e} = -\frac{\mathrm{e}}{2n} + o\left(\frac{1}{n}\right)$$

[2]求 $f(x)$ 的解析表达式:
$$f(x) = \lim_{n\to\infty} n^x \left(-\frac{\mathrm{e}}{2n} + o\left(\frac{1}{n}\right)\right) = -\frac{\mathrm{e}}{2}\lim_{n\to\infty} n^{x-1}$$

[B] 充分非必要条件
[C] 必要非充分条件
[D] 既非充分又非必要条件

主要思路:[分析单侧符号可知分母为 $x$ 时若比值极限存在则该极限必为 0，从而与绝对值收敛等价]

当 $x > 0$ 时，$\frac{|f(x)|}{x} \geqslant 0$，故右极限 $A = \lim\limits_{x\to 0^+} \frac{|f(x)|}{x} \geqslant 0$；

由于 $\left|\frac{|f(x)|}{x}\right| = \left|\frac{f(x)}{x}\right| \to 0$，根据夹逼定理:
$$\lim_{x\to 0} \frac{|f(x)|}{x} = 0$$
极限存在且等于 0。必要性成立。

两者互为充分必要条件。选 [A]。

① 若 $\lim\limits_{x\to+\infty} f'(x)=a$，则 $\lim\limits_{x\to+\infty}\frac{f(x)}{x}=a$；
② 若 $\lim\limits_{x\to+\infty}\frac{f(x)}{x}=a$，则 $\lim\limits_{x\to+\infty} f'(x)=a$.

下列说法中正确的是 $(\quad)$.

[A] ①正确，②错误
[B] ①错误，②正确
[C] ①与②均正确
[D] ①与②均错误

由于 $x\to+\infty$ 时分母 $x\to+\infty$，且 $\lim\limits_{x\to+\infty} f'(x) = a$ 存在，
根据洛必达法则 ($\frac{*}{\infty}$ 型):

故 ② 错误。

[3]结论:
① 正确，② 错误。选 [A]。

[C] 一个可去间断点，一个跳跃间断点，一个无穷间断点
[D] 三个无穷间断点

分母为零或对数真数为零的点为: $x = 0, x = 1, x = -1$。

[2]判断 $x = 0$ 处的间断点类型:
当 $x\to 0$ 时，$|\ln|x|| \to +\infty$，而分母 $x^2 - 1 \to -1$。
故 $\lim\limits_{x\to 0} f(x) = -\infty$。
因此 $x = 0$ 是无穷间断点 (第二类)。

[3]判断 $x = 1$ 和 $x = -1$ 处的间断点类型:

$$\lim_{x\to 1^-} \frac{-\ln x}{x^2-1} = -\frac{1}{2}$$
左右极限均存在但不相等，故 $x = 1$ 为跳跃间断点。
又因为 $f(x)$ 为偶函数:
$$f(-x) = \frac{|\ln|-x||}{(-x)^2-1} = f(x)$$
由偶函数的对称性可知，$x = -1$ 处左右极限亦存在且不相等，同为跳跃间断点。

[4]结论:
共有两个跳跃间断点 ($x=\pm 1$) 和一个无穷间断点 ($x=0$)。选 [A]。
