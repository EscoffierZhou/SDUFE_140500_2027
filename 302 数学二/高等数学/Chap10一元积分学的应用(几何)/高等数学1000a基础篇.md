## 高等数学1000题基础篇 - 第10章 一元函数积分学的应用（一）——几何应用

**(反常面积)<font color=green>题目[1]:二次三项式分母反常积分求平面图形面积</font>**

曲线 $y = \frac{1}{x^2+4x+5}$ 在区间 $(0,+\infty)$ 上与 $x$ 轴所围成的图形的面积为 $\underline{\qquad\qquad}$.

答案: $\frac{\pi}{2} - \arctan 2$ (或 $\arctan\frac{1}{2}$)

主要思路:[配方法化为标准反正切反常积分]

[1]建立面积积分表达式:
由于在 $(0, +\infty)$ 上 $y > 0$，面积公式为:
$$S = \int_0^{+\infty} \frac{1}{x^2+4x+5}\mathrm{d}x = \int_0^{+\infty} \frac{1}{(x+2)^2+1}\mathrm{d}x$$

[2]计算定积分:
$$S = \left. \arctan(x+2) \right|_0^{+\infty} = \lim_{x\to +\infty}\arctan(x+2) - \arctan 2 = \frac{\pi}{2} - \arctan 2$$
利用反三角恒等式 $\frac{\pi}{2} - \arctan 2 = \arctan\frac{1}{2}$，两者均可。

**(根式对数面积)<font color=green>题目[2]:对数根式分部积分求平面图形面积</font>**

曲线 $y = \frac{\ln x}{\sqrt{x}}$ 在 $[1,\mathrm{e}^2]$ 上与 $x$ 轴所围成的图形的面积是 $\underline{\qquad\qquad}$.

答案: $4$

主要思路:[换元 $u = \sqrt{x}$ 或分部积分]

[1]换元法化简:
令 $u = \sqrt{x}$，则 $x = u^2$，$\mathrm{d}x = 2u\mathrm{d}u$。当 $x=1$ 时 $u=1$；当 $x=\mathrm{e}^2$ 时 $u=\mathrm{e}$。
$$S = \int_1^{\mathrm{e}^2} \frac{\ln x}{\sqrt{x}}\mathrm{d}x = \int_1^{\mathrm{e}} \frac{2\ln u}{u}\cdot 2u\mathrm{d}u = 4\int_1^{\mathrm{e}} \ln u\mathrm{d}u$$

[2]分部积分求值:
$$S = 4\left. [u\ln u - u] \right|_1^{\mathrm{e}} = 4\big[(\mathrm{e}-\mathrm{e}) - (0-1)\big] = 4$$

**(抛物线分割)<font color=deeppink>题目[3]:两曲线交点分割区域面积相等性判定</font>**

如图所示，抛物线 $y=(\sqrt{2}-1)x^2$ 把曲线 $y=x(b-x)\ (b>0)$ 与 $x$ 轴所围成的闭区域分成面积为 $S_A$ 与 $S_B$ 的两部分，则 $(\quad)$.

(A) $S_A < S_B$  
(B) $S_A = S_B$  
(C) $S_A > S_B$  
(D) $S_A$ 与 $S_B$ 的大小关系与 $b$ 的数值有关

答案: (B)

主要思路:[联立求交点横坐标，分别积分求出 $S_A$ 与总面积 $S$]

[1]求总面积 $S$:
曲线 $y = x(b-x)$ 与 $x$ 轴的交点为 $x=0$ 和 $x=b$。
$$S = \int_0^b (bx-x^2)\mathrm{d}x = \left. \left(\frac{b x^2}{2} - \frac{x^3}{3}\right) \right|_0^b = \frac{b^3}{6}$$

[2]联立求交点横坐标:
$$(\sqrt{2}-1)x^2 = x(b-x) \implies \sqrt{2}x^2 = bx \implies x_1 = 0,\quad x_2 = \frac{b}{\sqrt{2}}$$

[3]计算公共部分面积 $S_A$:
$$S_A = \int_0^{\frac{b}{\sqrt{2}}} [x(b-x) - (\sqrt{2}-1)x^2]\mathrm{d}x = \int_0^{\frac{b}{\sqrt{2}}} (bx - \sqrt{2}x^2)\mathrm{d}x$$
$$= \left. \left(\frac{b x^2}{2} - \frac{\sqrt{2}x^3}{3}\right) \right|_0^{\frac{b}{\sqrt{2}}} = \frac{b\cdot \frac{b^2}{2}}{2} - \frac{\sqrt{2}\cdot \frac{b^3}{2\sqrt{2}}}{3} = \frac{b^3}{4} - \frac{b^3}{6} = \frac{b^3}{12}$$

[4]计算剩余部分 $S_B$:
$$S_B = S - S_A = \frac{b^3}{6} - \frac{b^3}{12} = \frac{b^3}{12}$$
因为 $S_A = S_B = \frac{b^3}{12}$，两者恒等，选 (B)。

**(切线面积比极限)<font color=red>题目[4]:曲边梯形与切线所围面积比的渐近极限</font>**

过点 $(p, \sin p)$ 作曲线 $y=\sin x$ 的切线(见图)，设该曲线与切线及 $y$ 轴所围成的图形的面积为 $S_1$，曲线与直线 $x=p$ 及 $x$ 轴所围成的图形的面积为 $S_2$，则 $(\quad)$.

(A) $\lim_{p\to 0^+}\frac{S_2}{S_1+S_2} = \frac{1}{3}$  
(B) $\lim_{p\to 0^+}\frac{S_2}{S_1+S_2} = \frac{1}{2}$  
(C) $\lim_{p\to 0^+}\frac{S_2}{S_1+S_2} = \frac{2}{3}$  
(D) $\lim_{p\to 0^+}\frac{S_2}{S_1+S_2} = 1$

答案: (D)

主要思路:[写出切线方程求 $S_1$ 与 $S_2$ 的泰勒展开式，比较阶数]

[1]写出切线方程与 $S_1, S_2$ 表达式:
在点 $(p, \sin p)$ 处的切线方程为 $y - \sin p = (\cos p)(x-p)$，即 $y = (\cos p)x + \sin p - p\cos p$。
$$S_2 = \int_0^p \sin x\mathrm{d}x = 1 - \cos p$$
$$S_1 = \int_0^p [(\cos p)x + \sin p - p\cos p - \sin x]\mathrm{d}x = \frac{p^2\cos p}{2} + p\sin p - p^2\cos p - (1-\cos p) = p\sin p - \frac{p^2\cos p}{2} + \cos p - 1$$

[2]泰勒展开确定主部:
当 $p \to 0^+$ 时:
$$S_2 = 1 - \cos p = \frac{p^2}{2} - \frac{p^4}{24} + o(p^4) \sim \frac{p^2}{2}$$
对于 $S_1$:
$$p\sin p = p\left(p - \frac{p^3}{6} + o(p^3)\right) = p^2 - \frac{p^4}{6} + o(p^4)$$
$$-\frac{p^2\cos p}{2} = -\frac{p^2}{2}\left(1 - \frac{p^2}{2} + o(p^2)\right) = -\frac{p^2}{2} + \frac{p^4}{4} + o(p^4)$$
$$\cos p - 1 = -\frac{p^2}{2} + \frac{p^4}{24} + o(p^4)$$
将三项相加，二阶项恰好抵消：
$$S_1 = \left(1 - \frac{1}{2} - \frac{1}{2}\right)p^2 + \left(-\frac{1}{6} + \frac{1}{4} + \frac{1}{24}\right)p^4 + o(p^4) = \frac{p^4}{8} + o(p^4)$$

[3]计算极限:
$$\lim_{p\to 0^+}\frac{S_2}{S_1+S_2} = \lim_{p\to 0^+}\frac{\frac{p^2}{2}}{\frac{p^4}{8} + \frac{p^2}{2}} = 1$$
故选 (D)。

**(无界区域面积)<font color=green>题目[5]:双侧对称无界平面区域面积</font>**

平面无界区域 $D = \{(x,y)\mid (1+x^2)|y| \leqslant 1\}$ 的面积为 $\underline{\qquad\qquad}$.

答案: $2\pi$

主要思路:[由对称性解出 $|y| \leqslant \frac{1}{1+x^2}$ 后积分]

[1]区域形态分析:
由 $(1+x^2)|y| \leqslant 1$ 可得 $-\frac{1}{1+x^2} \leqslant y \leqslant \frac{1}{1+x^2}$。
区域关于 $x$ 轴与 $y$ 轴均对称。

[2]计算反常积分:
$$S = 2\int_{-\infty}^{+\infty} \frac{1}{1+x^2}\mathrm{d}x = 4\int_0^{+\infty} \frac{1}{1+x^2}\mathrm{d}x = 4\left. [\arctan x] \right|_0^{+\infty} = 4\cdot \frac{\pi}{2} = 2\pi$$

**(柱壳旋转体)<font color=deeppink>题目[6]:正弦拱绕轴旋转体的体积</font>**

设平面区域 $D$ 由曲线段 $y=\sin\pi x\ (0\leqslant x\leqslant 1)$ 与 $x$ 轴围成，则 $D$ 绕 $y$ 轴旋转一周所得旋转体的体积为 $\underline{\qquad\qquad}$.

答案: $2$

主要思路:[应用柱壳法（微元 $2\pi x y \mathrm{d}x$）快速求旋转体体积]

[1]柱壳法体积公式:
$$V = 2\pi \int_0^1 x y\,\mathrm{d}x = 2\pi \int_0^1 x \sin\pi x\,\mathrm{d}x$$

[2]分部积分:
令 $u = \pi x$，则 $x = \frac{u}{\pi}$，$\mathrm{d}x = \frac{\mathrm{d}u}{\pi}$：
$$V = 2\pi \int_0^\pi \frac{u}{\pi}\sin u\,\frac{\mathrm{d}u}{\pi} = \frac{2}{\pi}\int_0^\pi u\sin u\,\mathrm{d}u$$
$$= \frac{2}{\pi}\left( \left. -u\cos u \right|_0^\pi + \int_0^\pi \cos u\,\mathrm{d}u \right) = \frac{2}{\pi}(\pi + 0) = 2$$

**(变限函数平均值)<font color=deeppink>题目[7]:变限积分复合函数的区间平均值</font>**

已知函数 $f(x) = x\int_1^x \frac{\mathrm{e}^{t^2}}{t}\mathrm{d}t$，则 $f(x)$ 在 $(0,1)$ 上的平均值为 $\underline{\qquad\qquad}$.

答案: $\frac{1-\mathrm{e}}{4}$

主要思路:[根据平均值定义列出定积分，利用分部积分降阶]

[1]平均值公式:
$$\bar{f} = \frac{1}{1-0}\int_0^1 f(x)\mathrm{d}x = \int_0^1 x \left(\int_1^x \frac{\mathrm{e}^{t^2}}{t}\mathrm{d}t\right)\mathrm{d}x$$

[2]分部积分法:
$$\bar{f} = \frac{1}{2}\int_0^1 \left(\int_1^x \frac{\mathrm{e}^{t^2}}{t}\mathrm{d}t\right)\mathrm{d}(x^2) = \left. \frac{x^2}{2}\int_1^x \frac{\mathrm{e}^{t^2}}{t}\mathrm{d}t \right|_0^1 - \frac{1}{2}\int_0^1 x^2 \cdot \frac{\mathrm{e}^{x^2}}{x}\mathrm{d}x$$
第一项: 在 $x=1$ 处积分为 $0$；在 $x\to 0^+$ 处由洛必达法则极限为 $0$。
第二项:
$$-\frac{1}{2}\int_0^1 x\mathrm{e}^{x^2}\mathrm{d}x = -\frac{1}{4}\int_0^1 \mathrm{e}^{x^2}\mathrm{d}(x^2) = -\frac{1}{4}(\mathrm{e}-1) = \frac{1-\mathrm{e}}{4}$$

**(相关变化率体积)<font color=red>题目[8]:动截面旋转体体积关于时间的变化率</font>**

已知曲线 $L: y = \mathrm{e}^{-x}\ (x\geqslant 0)$，设 $P$ 是 $L$ 上的动点，$V$ 是 $L$ 上从点 $A(0,1)$ 到点 $P$ 的一段弧绕 $x$ 轴旋转一周所得的旋转体体积，当 $P$ 运动到点 $\left(1, \frac{1}{\mathrm{e}}\right)$ 时，沿 $x$ 轴正向的速度为 $1$，求此时 $V$ 关于时间 $t$ 的变化率.

答案: $\frac{\pi}{\mathrm{e}^2}$

主要思路:[建立体积 $V$ 关于横坐标 $x$ 的函数，应用链式法则 $\frac{\mathrm{d}V}{\mathrm{d}t} = \frac{\mathrm{d}V}{\mathrm{d}x}\frac{\mathrm{d}x}{\mathrm{d}t}$]

[1]写出体积函数 $V(x)$:
$$V(x) = \pi \int_0^x y^2(\tau)\mathrm{d}\tau = \pi \int_0^x \mathrm{e}^{-2\tau}\mathrm{d}\tau$$

[2]由微积分基本定理求导:
$$\frac{\mathrm{d}V}{\mathrm{d}x} = \pi \mathrm{e}^{-2x}$$

[3]应用相关变化率链式法则:
$$\frac{\mathrm{d}V}{\mathrm{d}t} = \frac{\mathrm{d}V}{\mathrm{d}x}\cdot \frac{\mathrm{d}x}{\mathrm{d}t} = \pi \mathrm{e}^{-2x} \cdot \frac{\mathrm{d}x}{\mathrm{d}t}$$
当 $P$ 运动到点 $\left(1, \frac{1}{\mathrm{e}}\right)$ 时，$x=1$，已知 $\frac{\mathrm{d}x}{\mathrm{d}t} = 1$：
$$\left.\frac{\mathrm{d}V}{\mathrm{d}t}\right|_{x=1} = \pi \mathrm{e}^{-2} \cdot 1 = \frac{\pi}{\mathrm{e}^2}$$

**(对数正弦弧长)<font color=deeppink>题目[9]:对数三角函数弧长积分</font>**

曲线 $y = \ln\sin x\left(\frac{\pi}{6}\leqslant x\leqslant \frac{\pi}{3}\right)$ 的弧长为 $\underline{\qquad\qquad}$.

答案: $\frac{1}{2}\ln 3$

主要思路:[弧长公式 $\mathrm{d}s = \sqrt{1+(y')^2}\mathrm{d}x$ 化为余割函数积分]

[1]求导与弧长微元:
$$y' = \frac{\cos x}{\sin x} = \cot x$$
$$\mathrm{d}s = \sqrt{1+\cot^2 x}\,\mathrm{d}x = \csc x\,\mathrm{d}x\quad \left(x\in\left[\frac{\pi}{6}, \frac{\pi}{3}\right], \sin x > 0\right)$$

[2]定积分计算:
$$s = \int_{\frac{\pi}{6}}^{\frac{\pi}{3}} \csc x\,\mathrm{d}x = \left. \ln\left|\tan\frac{x}{2}\right| \right|_{\frac{\pi}{6}}^{\frac{\pi}{3}} = \ln\tan\frac{\pi}{6} - \ln\tan\frac{\pi}{12}$$
已知 $\tan\frac{\pi}{6} = \frac{1}{\sqrt{3}}$，$\tan\frac{\pi}{12} = 2-\sqrt{3}$：
$$s = \ln\left(\frac{1}{\sqrt{3}(2-\sqrt{3})}\right) = \ln\left(\frac{2+\sqrt{3}}{\sqrt{3}}\right)$$
或直接用 $\left. \ln|\csc x - \cot x| \right|_{\frac{\pi}{6}}^{\frac{\pi}{3}} = \ln\left(\frac{2}{\sqrt{3}}-\frac{1}{\sqrt{3}}\right) - \ln(2-\sqrt{3}) = \ln\frac{1}{\sqrt{3}(2-\sqrt{3})} = \frac{1}{2}\ln 3$。

**(极坐标弧长)<font color=green>题目[10]:对数螺线极坐标弧长公式</font>**

曲线 $r = \mathrm{e}^\theta$ 从 $\theta = 0$ 到 $\theta = 1$ 的弧长为 $\underline{\qquad\qquad}$.

答案: $\sqrt{2}(\mathrm{e}-1)$

主要思路:[极坐标弧长微元 $\mathrm{d}s = \sqrt{r^2+(r')^2}\mathrm{d}\theta$]

[1]弧长微元:
$$r'(\theta) = \mathrm{e}^\theta \implies \mathrm{d}s = \sqrt{(\mathrm{e}^\theta)^2 + (\mathrm{e}^\theta)^2}\,\mathrm{d}\theta = \sqrt{2}\mathrm{e}^\theta\mathrm{d}\theta$$

[2]定积分计算:
$$s = \int_0^1 \sqrt{2}\mathrm{e}^\theta\mathrm{d}\theta = \left. \sqrt{2}\mathrm{e}^\theta \right|_0^1 = \sqrt{2}(\mathrm{e}-1)$$

**(隐函数弧长)<font color=deeppink>题目[11]:反函数/隐函数弧长配方开根</font>**

已知函数 $y=y(x)$ 由方程 $y^4-6xy+3=0\ (1\leqslant y\leqslant 2)$ 所确定，则曲线 $y=y(x)$ 从点 $\left(\frac{2}{3}, 1\right)$ 到点 $\left(\frac{19}{12}, 2\right)$ 的长度为 $\underline{\qquad\qquad}$.

答案: $\frac{17}{12}$

主要思路:[将 $x$ 视为 $y$ 的函数，应用 $x'(y)$ 配方化简弧长微元]

[1]反解 $x(y)$:
$$6xy = y^4 + 3 \implies x = \frac{y^3}{6} + \frac{1}{2y}$$

[2]求导与弧长微元配方:
$$x'(y) = \frac{y^2}{2} - \frac{1}{2y^2}$$
$$1 + [x'(y)]^2 = 1 + \left(\frac{y^2}{2} - \frac{1}{2y^2}\right)^2 = 1 + \frac{y^4}{4} - \frac{1}{2} + \frac{1}{4y^4} = \left(\frac{y^2}{2} + \frac{1}{2y^2}\right)^2$$
$$\mathrm{d}s = \left(\frac{y^2}{2} + \frac{1}{2y^2}\right)\mathrm{d}y$$

[3]定积分计算:
$$s = \int_1^2 \left(\frac{y^2}{2} + \frac{1}{2y^2}\right)\mathrm{d}y = \left. \left( \frac{y^3}{6} - \frac{1}{2y} \right) \right|_1^2 = \left(\frac{8}{6} - \frac{1}{4}\right) - \left(\frac{1}{6} - \frac{1}{2}\right) = \frac{7}{6} + \frac{1}{4} = \frac{17}{12}$$

**(切线围面积)<font color=green>题目[12]:过原点切线围成图形面积的积分表达式</font>**

曲线 $y = \mathrm{e}^x$ 与其过原点的切线及 $y$ 轴所围图形的面积为 $(\quad)$.

(A) $\int_0^1 (\ln y - y\ln y)\mathrm{d}x$  
(B) $\int_0^1 (\mathrm{e}^x - \mathrm{e}x)\mathrm{d}x$  
(C) $\int_1^{\mathrm{e}} (\ln y - y\ln y)\mathrm{d}x$  
(D) $\int_1^{\mathrm{e}} (\mathrm{e}^x - x\mathrm{e}^x)\mathrm{d}x$

答案: (B)

主要思路:[求过原点的切线方程，确定交点积分区间]

[1]求切线方程:
设切点为 $(x_0, \mathrm{e}^{x_0})$，切线斜率 $k = \mathrm{e}^{x_0}$。
切线过原点 $(0,0)$：
$$\frac{\mathrm{e}^{x_0}-0}{x_0-0} = \mathrm{e}^{x_0} \implies x_0 = 1$$
切线方程为 $y = \mathrm{e}x$。

[2]建立面积积分式:
在区间 $[0, 1]$ 上，$y = \mathrm{e}^x$ 在切线上方，图形由 $x=0$ 到 $x=1$：
$$S = \int_0^1 (\mathrm{e}^x - \mathrm{e}x)\mathrm{d}x$$
故选 (B)。

**(无界旋转体积)<font color=deeppink>题目[13]:无界区域绕轴旋转体的广义积分体积</font>**

曲线 $y = x^2\mathrm{e}^{-x}\ (0\leqslant x < +\infty)$ 绕 $x$ 轴旋转一周所得延展到无穷远的旋转体的体积为 $\underline{\qquad\qquad}$.

答案: $\frac{3\pi}{4}$

主要思路:[圆盘法列出无穷限广义积分，应用 Gamma 函数或分部积分]

[1]体积公式:
$$V = \pi \int_0^{+\infty} y^2\mathrm{d}x = \pi \int_0^{+\infty} x^4\mathrm{e}^{-2x}\mathrm{d}x$$

[2]换元与伽马函数积分:
令 $u = 2x$，则 $x = \frac{u}{2}$，$\mathrm{d}x = \frac{\mathrm{d}u}{2}$：
$$V = \pi \int_0^{+\infty} \frac{u^4}{16}\mathrm{e}^{-u}\frac{\mathrm{d}u}{2} = \frac{\pi}{32}\int_0^{+\infty} u^4\mathrm{e}^{-u}\mathrm{d}u = \frac{\pi}{32}\cdot 4! = \frac{24\pi}{32} = \frac{3\pi}{4}$$

**(分部旋转体积)<font color=deeppink>题目[14]:对数函数旋转体体积的分部积分</font>**

曲线 $f(x) = x\ln x\ (0 < x\leqslant 2)$ 绕 $x$ 轴旋转一周所得旋转体的体积为 $\underline{\qquad\qquad}$.

答案: $\frac{8\pi}{27}(9\ln^2 2 - 6\ln 2 + 2)$

主要思路:[圆盘法结合多次分部积分]

[1]体积表达式:
$$V = \pi \int_0^2 [x\ln x]^2\mathrm{d}x = \pi \int_0^2 x^2\ln^2 x\,\mathrm{d}x$$

[2]分部积分计算:
$$V = \frac{\pi}{3}\int_0^2 \ln^2 x\,\mathrm{d}(x^3) = \frac{\pi}{3}\left( \left. x^3\ln^2 x \right|_0^2 - 2\int_0^2 x^2\ln x\,\mathrm{d}x \right)$$
由极限 $\lim_{x\to 0^+} x^3\ln^2 x = 0$，首项为 $8\ln^2 2$。
第二项再分部:
$$\int_0^2 x^2\ln x\,\mathrm{d}x = \frac{1}{3}\left( \left. x^3\ln x \right|_0^2 - \int_0^2 x^2\mathrm{d}x \right) = \frac{1}{3}\left(8\ln 2 - \frac{8}{3}\right) = \frac{8}{3}\ln 2 - \frac{8}{9}$$
代入得:
$$V = \frac{\pi}{3}\left[8\ln^2 2 - 2\left(\frac{8}{3}\ln 2 - \frac{8}{9}\right)\right] = \frac{8\pi}{27}(9\ln^2 2 - 6\ln 2 + 2)$$

曲线 $y = \frac{1}{2}x^2\ (0\leqslant x\leqslant 1)$ 的长度为 $\underline{\qquad\qquad}$.

**(两轴旋转体比较)<font color=red>题目[16]:不同旋转轴所得旋转体体积大小判定</font>**

设平面 $D$ 是由 $y = \ln x$，$x=1$，$y=1$ 围成的第一象限的有界区域，记 $D$ 绕 $x$ 轴与绕 $y=1$ 旋转一周所得旋转体的体积分别为 $V_1$，$V_2$，则 $(\quad)$.

(A) $V_1 > \frac{\pi}{2} > V_2$  
(B) $V_2 > \frac{\pi}{2} > V_1$  
(C) $\frac{\pi}{2} > V_1 > V_2$  
(D) $\frac{\pi}{2} > V_2 > V_1$

答案: (A)

主要思路:[分别计算 $V_1$ 与 $V_2$ 的具体数值并与 $\frac{\pi}{2}$ 对比]

[1]计算 $V_1$（绕 $x$ 轴）:
区域 $D$ 的交点为 $(1, 0), (1, 1), (\mathrm{e}, 1)$。
利用圆环法（$x$ 从 $1$ 到 $\mathrm{e}$）：
$$V_1 = \pi \int_1^{\mathrm{e}} (1^2 - \ln^2 x)\mathrm{d}x = \pi \left[(\mathrm{e}-1) - \left. (x\ln^2 x - 2x\ln x + 2x) \right|_1^{\mathrm{e}}\right]$$
$$= \pi [(\mathrm{e}-1) - (\mathrm{e} - 2)] = \pi$$
显然 $V_1 = \pi > \frac{\pi}{2}$。

[2]计算 $V_2$（绕 $y=1$）:
各点到旋转轴 $y=1$ 的距离为 $1 - \ln x$：
$$V_2 = \pi \int_1^{\mathrm{e}} (1-\ln x)^2\mathrm{d}x$$
令 $u = 1-\ln x$，则 $x = \mathrm{e}^{1-u}$，$\mathrm{d}x = -\mathrm{e}^{1-u}\mathrm{d}u$。当 $x=1$ 时 $u=1$；当 $x=\mathrm{e}$ 时 $u=0$：
$$V_2 = \pi \int_0^1 u^2\mathrm{e}^{1-u}\mathrm{d}u = \pi \mathrm{e}\int_0^1 u^2\mathrm{e}^{-u}\mathrm{d}u = \pi \mathrm{e}\left(2 - \frac{5}{\mathrm{e}}\right) = \pi(2\mathrm{e}-5)$$
因为 $\mathrm{e} \approx 2.718$，故 $2\mathrm{e}-5 \approx 0.436 < 0.5$。
所以 $V_2 = \pi(2\mathrm{e}-5) < \frac{\pi}{2}$。
综上：$V_1 > \frac{\pi}{2} > V_2$。选 (A)。

**(旋转侧面积)<font color=deeppink>题目[17]:抛物线绕 $y$ 轴旋转所得侧面积</font>**

曲线 $y = x^2$ 从点 $(1,1)$ 到点 $(2,4)$ 的一段弧绕 $y$ 轴旋转一周所得旋转体的侧面积为 $\underline{\qquad\qquad}$.

答案: $\frac{\pi}{6}(17\sqrt{17} - 5\sqrt{5})$

主要思路:[旋转曲面侧面积微元 $\mathrm{d}A = 2\pi x \mathrm{d}s$]

[1]侧面积公式:
$$A = 2\pi \int_1^2 x\mathrm{d}s = 2\pi \int_1^2 x\sqrt{1+(y')^2}\mathrm{d}x$$
由于 $y = x^2$，$y' = 2x$：
$$A = 2\pi \int_1^2 x\sqrt{1+4x^2}\,\mathrm{d}x$$

[2]凑微分积分:
$$A = \frac{2\pi}{8}\int_1^2 (1+4x^2)^{\frac{1}{2}}\,\mathrm{d}(1+4x^2) = \left. \frac{\pi}{6}(1+4x^2)^{\frac{3}{2}} \right|_1^2 = \frac{\pi}{6}(17^{\frac{3}{2}} - 5^{\frac{3}{2}}) = \frac{\pi}{6}(17\sqrt{17} - 5\sqrt{5})$$

**(瑕积分平均值)<font color=green>题目[18]:瑕积分函数在区间上的平均值</font>**

函数 $y = \frac{x^2}{\sqrt{1-x^2}}$ 在区间 $[0,1]$ 上的平均值为 $\underline{\qquad\qquad}$.

答案: $\frac{\pi}{4}$

主要思路:[平均值公式结合三角换元]

$$\bar{y} = \frac{1}{1-0}\int_0^1 \frac{x^2}{\sqrt{1-x^2}}\mathrm{d}x$$
令 $x = \sin t$，$\mathrm{d}x = \cos t\mathrm{d}t$：
$$\bar{y} = \int_0^{\frac{\pi}{2}} \frac{\sin^2 t}{\cos t}\cos t\mathrm{d}t = \int_0^{\frac{\pi}{2}} \sin^2 t\mathrm{d}t = \frac{1}{2}\cdot \frac{\pi}{2} = \frac{\pi}{4}$$

**(综合面积与旋转体)<font color=deeppink>题目[19]:几何区域面积与绕轴旋转体体积综合题</font>**

设平面区域 $D = \left\{(x,y)\,\middle|\, 0\leqslant y\leqslant \frac{\sqrt{x^2-1}}{x^2},\, \sqrt{2}\leqslant x\leqslant 2\right\}$，求：

(1) $D$ 的面积；

(2) $D$ 绕 $x$ 轴旋转一周所得旋转体的体积.

答案: (1) $\ln\frac{2+\sqrt{3}}{\sqrt{2}+1} + \frac{\sqrt{2}-\sqrt{3}}{2}$；(2) $\frac{10\sqrt{2}-11}{24}\pi$

主要思路:[(1) 三角换元求面积；(2) 平方有理化分式求旋转体积]

[1]求 $D$ 的面积:
$$S = \int_{\sqrt{2}}^2 \frac{\sqrt{x^2-1}}{x^2}\mathrm{d}x$$
令 $x = \sec\theta$，$\mathrm{d}x = \sec\theta\tan\theta\mathrm{d}\theta$。当 $x=\sqrt{2}$ 时 $\theta=\frac{\pi}{4}$；当 $x=2$ 时 $\theta=\frac{\pi}{3}$：
$$S = \int_{\frac{\pi}{4}}^{\frac{\pi}{3}} \frac{\tan\theta}{\sec^2\theta}\cdot \sec\theta\tan\theta\mathrm{d}\theta = \int_{\frac{\pi}{4}}^{\frac{\pi}{3}} \frac{\sin^2\theta}{\cos\theta}\mathrm{d}\theta = \int_{\frac{\pi}{4}}^{\frac{\pi}{3}} (\sec\theta - \cos\theta)\mathrm{d}\theta$$
$$= \left. \big(\ln|\sec\theta+\tan\theta| - \sin\theta\big) \right|_{\frac{\pi}{4}}^{\frac{\pi}{3}} = \ln(2+\sqrt{3}) - \frac{\sqrt{3}}{2} - \left(\ln(\sqrt{2}+1) - \frac{\sqrt{2}}{2}\right)$$
$$= \ln\left(\frac{2+\sqrt{3}}{\sqrt{2}+1}\right) + \frac{\sqrt{2}-\sqrt{3}}{2}$$

[2]求绕 $x$ 轴旋转体的体积:
$$V = \pi \int_{\sqrt{2}}^2 y^2\mathrm{d}x = \pi \int_{\sqrt{2}}^2 \frac{x^2-1}{x^4}\mathrm{d}x = \pi \int_{\sqrt{2}}^2 (x^{-2} - x^{-4})\mathrm{d}x$$
$$= \pi \left. \left( -\frac{1}{x} + \frac{1}{3x^3} \right) \right|_{\sqrt{2}}^2 = \pi \left[ \left(-\frac{1}{2} + \frac{1}{24}\right) - \left(-\frac{1}{\sqrt{2}} + \frac{1}{6\sqrt{2}}\right) \right]$$
$$= \pi \left( -\frac{11}{24} + \frac{5}{6\sqrt{2}} \right) = \pi \left( -\frac{11}{24} + \frac{5\sqrt{2}}{12} \right) = \frac{10\sqrt{2}-11}{24}\pi$$
