第七章 一元函数微分学的应用（三）——物理应用（强化篇）

(相关变化率与几何运动)题目[1]:抛物线上质点到原点距离的变化率

质点 $P$ 沿抛物线 $x = y^2 (y > 0)$ 移动，$P$ 的横坐标 $x$ 的变化速度为 $5\text{ cm/s}$. 当 $x = 9$ 时，点 $P$ 到原点 $O$ 的距离变化速度为 $\underline{\qquad\qquad}$.

答案: $\dfrac{19\sqrt{10}}{12}\text{ cm/s}$

主要思路:[建立质点到原点距离关于 $x$ 的函数表达式，利用链式法则计算相关变化率]

[1] 建立距离函数：
质点 $P$ 在抛物线 $x = y^2$ ($y > 0$) 上运动，其坐标为 $(x, y) = (x, \sqrt{x})$.
质点 $P$ 到原点 $O(0, 0)$ 的距离为：
$$L = \sqrt{x^2 + y^2} = \sqrt{x^2 + x}$$

[2] 求导并代入变化率：
对时间 $t$ 求导，由复合函数求导法则：
$$\frac{\mathrm{d}L}{\mathrm{d}t} = \frac{\mathrm{d}L}{\mathrm{d}x} \cdot \frac{\mathrm{d}x}{\mathrm{d}t} = \frac{2x + 1}{2\sqrt{x^2 + x}} \cdot \frac{\mathrm{d}x}{\mathrm{d}t}$$

[3] 代入 $x = 9$ 计算：
当 $x = 9$ 时：
$$\sqrt{x^2 + x} = \sqrt{81 + 9} = \sqrt{90} = 3\sqrt{10}$$
$$2x + 1 = 2 \times 9 + 1 = 19$$
已知 $\frac{\mathrm{d}x}{\mathrm{d}t} = 5\text{ cm/s}$，代入得：
$$\left.\frac{\mathrm{d}L}{\mathrm{d}t}\right|_{x=9} = \frac{19}{2 \times 3\sqrt{10}} \times 5 = \frac{95}{6\sqrt{10}} = \frac{19\sqrt{10}}{12}\text{ cm/s}$$

(相关变化率与几何体度量)题目[2]:球体表面积与体积的变化率

球的半径以 $5\text{ cm/s}$ 的速度匀速增长，当球的半径为 $50\text{ cm}$ 时，球的表面积和体积的增长速度各是多少？

答案: 表面积增长速度为 $2000\pi\text{ cm}^2/\text{s}$，体积增长速度为 $50000\pi\text{ cm}^3/\text{s}$

主要思路:[根据球的表面积与体积公式，分别对时间 $t$ 求导建立相关变化率方程]

[1] 表面积的增长速度：
球的表面积公式为 $S = 4\pi R^2$.
两边对时间 $t$ 求导：
$$\frac{\mathrm{d}S}{\mathrm{d}t} = 8\pi R \cdot \frac{\mathrm{d}R}{\mathrm{d}t}$$
已知 $\frac{\mathrm{d}R}{\mathrm{d}t} = 5\text{ cm/s}$，当 $R = 50\text{ cm}$ 时：
$$\left.\frac{\mathrm{d}S}{\mathrm{d}t}\right|_{R=50} = 8\pi \times 50 \times 5 = 2000\pi\text{ cm}^2/\text{s}$$

[2] 体积的增长速度：
球的体积公式为 $V = \frac{4}{3}\pi R^3$.
两边对时间 $t$ 求导：
$$\frac{\mathrm{d}V}{\mathrm{d}t} = 4\pi R^2 \cdot \frac{\mathrm{d}R}{\mathrm{d}t}$$
当 $R = 50\text{ cm}$ 时：
$$\left.\frac{\mathrm{d}V}{\mathrm{d}t}\right|_{R=50} = 4\pi \times 50^2 \times 5 = 4\pi \times 2500 \times 5 = 50000\pi\text{ cm}^3/\text{s}$$

(动态切线与所围面积变化率)题目[3]:切线所围面积的变化率与驻点求解

已知曲线 $L: y = \ln\sqrt{x}\ (2 \le x \le 4)$，在 $L$ 上的任意点 $P(x,y)$ 作切线，记切线与曲线 $L$ 在 $2 \le x \le 4$ 时所围成的有界区域的面积为 $S$.

(1) 求一点 $P_0$，使上述面积 $S$ 关于 $x$ 的变化率为零；

(2) 当点 $P(x,y)$ 在曲线上移动至 $\left(\mathrm{e}, \dfrac{1}{2}\right)$ 时，横坐标关于时间的变化率为 $1$，求此时面积关于时间的变化率 $\dfrac{\mathrm{d}S}{\mathrm{d}t}$.

答案: (1) $P_0\left(3, \frac{1}{2}\ln 3\right)$; (2) $\dfrac{\mathrm{d}S}{\mathrm{d}t} = \dfrac{\mathrm{e} - 3}{\mathrm{e}^2}$

主要思路:[(1)写出切线方程，对积分变量 $X$ 积分表示出面积 $S(x)$，对 $x$ 求导求驻点；(2)利用复合函数链式法则计算 $\frac{\mathrm{d}S}{\mathrm{d}t}$]

[1] 写出切线方程并建立面积函数：
曲线方程为 $y = \ln\sqrt{x} = \frac{1}{2}\ln x$ ($2 \leqslant x \leqslant 4$).
导数为 $y' = \frac{1}{2x}$.
二阶导数 $y'' = -\frac{1}{2x^2} < 0$，因此曲线在 $[2, 4]$ 上是严格上凸的，任意切线均位于曲线上方（除切点外）.
在点 $P(x, y)$ 处的切线方程（以 $X, Y$ 为坐标）为：
$$Y - \frac{1}{2}\ln x = \frac{1}{2x}(X - x) \implies Y = \frac{1}{2}\ln x + \frac{1}{2x}(X - x)$$
切线与曲线在 $X \in [2, 4]$ 之间所围成的有界区域面积为：
$$S(x) = \int_2^4 \left[\left(\frac{1}{2}\ln x + \frac{1}{2x}(X - x)\right) - \frac{1}{2}\ln X\right]\,\mathrm{d}X$$
将积分展开：
$$S(x) = \frac{1}{2}\ln x \int_2^4 \mathrm{d}X + \frac{1}{2x}\int_2^4 (X - x)\,\mathrm{d}X - \frac{1}{2}\int_2^4 \ln X\,\mathrm{d}X$$
计算前两项积分：
$$\int_2^4 \mathrm{d}X = 4 - 2 = 2$$
$$\int_2^4 (X - x)\,\mathrm{d}X = \left[\frac{X^2}{2} - xX\right]_2^4 = (8 - 4x) - (2 - 2x) = 6 - 2x$$
第三项为与参数 $x$ 无关的常数，记为 $C = \frac{1}{2}\int_2^4 \ln X\,\mathrm{d}X$.
整理得：
$$S(x) = \ln x + \frac{6 - 2x}{2x} - C = \ln x + \frac{3}{x} - 1 - C$$

[2] 求解(1)：
计算面积 $S$ 关于 $x$ 的导数（变化率）：
$$\frac{\mathrm{d}S}{\mathrm{d}x} = \frac{1}{x} - \frac{3}{x^2} = \frac{x - 3}{x^2}$$
令 $\frac{\mathrm{d}S}{\mathrm{d}x} = 0$，得：
$$x - 3 = 0 \implies x = 3 \in [2, 4]$$
对应的纵坐标为：
$$y = \ln\sqrt{3} = \frac{1}{2}\ln 3$$
故所求点为 $P_0\left(3, \frac{1}{2}\ln 3\right)$.

[3] 求解(2)：
由复合函数求导法则：
$$\frac{\mathrm{d}S}{\mathrm{d}t} = \frac{\mathrm{d}S}{\mathrm{d}x} \cdot \frac{\mathrm{d}x}{\mathrm{d}t}$$
当点 $P$ 移动至 $\left(\mathrm{e}, \frac{1}{2}\right)$ 时，横坐标 $x = \mathrm{e}$.
此时面积对 $x$ 的变化率为：
$$\left.\frac{\mathrm{d}S}{\mathrm{d}x}\right|_{x=\mathrm{e}} = \frac{\mathrm{e} - 3}{\mathrm{e}^2}$$
已知此时横坐标关于时间的变化率为 $\frac{\mathrm{d}x}{\mathrm{d}t} = 1$，因此：
$$\left.\frac{\mathrm{d}S}{\mathrm{d}t}\right|_{x=\mathrm{e}} = \frac{\mathrm{e} - 3}{\mathrm{e}^2} \times 1 = \frac{\mathrm{e} - 3}{\mathrm{e}^2}$$
