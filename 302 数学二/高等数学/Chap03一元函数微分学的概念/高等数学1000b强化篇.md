### 一、选择题与填空题

**(不可导点判定)<font color=green>题目[1]:绝对值因式分解与零点可导性判定</font>**

函数 $f(x) = (\mathrm{e}^x - 1)|x^3 - x^2 + x|$ 的不可导点的个数为 $(\quad)$.

[A] 0  
[B] 1  
[C] 2  
[D] 3  

答案: [A]

主要思路:[对绝对值内多项式因式分解，判断二次项判别式小于 0 恒正，再利用导数定义验证 $x=0$ 处可导性]

[1]化简绝对值内的多项式:
$$x^3 - x^2 + x = x(x^2 - x + 1)$$
由于二次多项式 $x^2 - x + 1 = \left(x - \frac{1}{2}\right)^2 + \frac{3}{4} > 0$ 对任意 $x\in\mathbb{R}$ 恒成立。
因此:
$$|x^3 - x^2 + x| = |x|(x^2 - x + 1)$$
原函数可化为:
$$f(x) = (\mathrm{e}^x - 1)|x|(x^2 - x + 1)$$

[2]考察唯一可能不可导点 $x=0$:
由导数定义考察 $x=0$ 处的导数:
$$\lim_{x\to 0} \frac{f(x) - f(0)}{x - 0} = \lim_{x\to 0} \frac{(\mathrm{e}^x - 1)|x|(x^2 - x + 1)}{x}$$
利用等价无穷小 $\mathrm{e}^x - 1 \sim x$:
$$\lim_{x\to 0} \frac{x |x| (x^2 - x + 1)}{x} = \lim_{x\to 0} |x|(x^2 - x + 1) = 0$$
极限存在且等于 0，故 $f'(0) = 0$ 存在。

[3]结论:
在 $x \ne 0$ 处函数为初等函数显然可导，在 $x=0$ 处亦可导。不可导点个数为 0。选 [A]。

**(导数定义)<font color=green>题目[2]:抽象函数平移比例关系的导数求解</font>**

设 $f(x+x_0) = \alpha f(x)$ 恒成立，$f'(0)=\beta$ ($\alpha, \beta$ 为非零常数)，则 $f(x)$ 在点 $x_0$ 处 $(\quad)$.

[A] 可导且 $f'(x_0) = \alpha \beta$  
[B] 可导且 $f'(x_0) = \alpha$  
[C] 可导且 $f'(x_0) = \beta$  
[D] 不可导  

答案: [A]

主要思路:[由导数定义写出 $f'(x_0)$ 的极限表达式，代入已知函数等式化为在 $x=0$ 处的导数]

[1]应用导数定义:
根据点 $x_0$ 处的导数定义:
$$f'(x_0) = \lim_{h\to 0} \frac{f(x_0 + h) - f(x_0)}{h}$$

[2]利用已知等式代换:
由已知 $f(x + x_0) = \alpha f(x)$，取 $x = h$ 得 $f(x_0 + h) = \alpha f(h)$；
取 $x = 0$ 得 $f(x_0) = \alpha f(0)$。
代入导数定义式:
$$f'(x_0) = \lim_{h\to 0} \frac{\alpha f(h) - \alpha f(0)}{h} = \alpha \lim_{h\to 0} \frac{f(h) - f(0)}{h}$$

[3]代入 $f'(0)=\beta$:
$$f'(x_0) = \alpha f'(0) = \alpha \beta$$
故 $f(x)$ 在点 $x_0$ 处可导且 $f'(x_0) = \alpha\beta$。选 [A]。

**(导数性质)<font color=deeppink>题目[3]:可导但导函数不连续的经典反例</font>**

设 $f(x) = \begin{cases} x^2 \sin \frac{t}{x}, & x \ne 0, \\ 0, & x = 0, \end{cases}$ 其中 $t$ 为非零常数，则 $f(x)$ 在 $x=0$ 处 $(\quad)$.

[A] 不连续  
[B] 连续但不可导  
[C] 可导但 $f'(x)$ 不连续  
[D] 可导且 $f'(x)$ 连续  

答案: [C]

主要思路:[用导数定义求 $f'(0)=0$；求导公式求 $x\ne 0$ 的导数，考察 $x\to 0$ 时导函数极限的振荡不存在性]

[1]利用导数定义求 $f'(0)$:
$$f'(0) = \lim_{x\to 0} \frac{f(x) - f(0)}{x - 0} = \lim_{x\to 0} \frac{x^2 \sin\frac{t}{x} - 0}{x} = \lim_{x\to 0} x\sin\frac{t}{x}$$
因为 $|\sin\frac{t}{x}| \leqslant 1$，无穷小量乘以有界量等于无穷小量:
$$f'(0) = 0$$
故 $f(x)$ 在 $x=0$ 处可导。

[2]求 $x \ne 0$ 处的导函数:
当 $x \ne 0$ 时，直接求导:
$$f'(x) = 2x \sin\frac{t}{x} + x^2 \cos\frac{t}{x} \cdot \left(-\frac{t}{x^2}\right) = 2x \sin\frac{t}{x} - t \cos\frac{t}{x}$$

[3]考察 $\lim\limits_{x\to 0} f'(x)$ 的极限:
当 $x\to 0$ 时，$2x\sin\frac{t}{x} \to 0$。
但 $-t\cos\frac{t}{x}$ 在 $[-t, t]$ 之间剧烈振荡，极限不存在。
因此 $\lim\limits_{x\to 0} f'(x)$ 不存在，即 $f'(x)$ 在 $x=0$ 处不连续。选 [C]。

**(概念辨析)<font color=red>题目[4]:高阶无穷小与连续点可导性充分必要条件辨析</font>**

设函数 $f(x)$ 在区间 $(-1, 1)$ 内有定义，且在点 $x=0$ 处连续，则以下结论：

① 当 $\lim\limits_{x\to 0}\frac{f(x)}{\sqrt[3]{x}} = 0$ 时，$f(x)$ 在点 $x=0$ 处可导；  
② 当 $\lim\limits_{x\to 0}\frac{f(x)}{x^2} = 0$ 时，$f(x)$ 在点 $x=0$ 处可导；  
③ 当 $f(x)$ 在点 $x=0$ 处可导时，$\lim\limits_{x\to 0}\frac{f(x)}{\sqrt[3]{x}} = 0$.  

所有正确结论的序号为 $(\quad)$.

[A] ①  
[B] ②  
[C] ②③  
[D] ①②  

答案: [B]

主要思路:[举反例 $f(x)=x^{2/3}$ 否定 ①；由定义与因式分解证明 ②；举反例 $f(x)=1$ 否定 ③]

[1]反例否定结论 ①:
取 $f(x) = x^{\frac{2}{3}}$，则 $f(x)$ 在 $x=0$ 处连续，且:
$$\lim_{x\to 0} \frac{f(x)}{\sqrt[3]{x}} = \lim_{x\to 0} \frac{x^{2/3}}{x^{1/3}} = \lim_{x\to 0} x^{\frac{1}{3}} = 0$$
满足题设条件。但由导数定义:
$$\lim_{x\to 0} \frac{f(x) - f(0)}{x} = \lim_{x\to 0} \frac{x^{2/3}}{x} = \lim_{x\to 0} \frac{1}{x^{1/3}} = \infty$$
导数不存在，故 ① 错误。

[2]证明结论 ②:
由 $\lim\limits_{x\to 0} \frac{f(x)}{x^2} = 0$，由极限的局部保号性与乘积性质:
$$f(0) = \lim_{x\to 0} f(x) = \lim_{x\to 0} \left[x^2 \cdot \frac{f(x)}{x^2}\right] = 0 \times 0 = 0$$
考察导数定义极限:
$$\lim_{x\to 0} \frac{f(x) - f(0)}{x} = \lim_{x\to 0} \frac{f(x)}{x} = \lim_{x\to 0} \left[x \cdot \frac{f(x)}{x^2}\right] = 0 \times 0 = 0$$
极限存在且等于 0，故 $f(x)$ 在 $x=0$ 处必可导且 $f'(0)=0$。故 ② 正确。

[3]反例否定结论 ③:
结论 ③ 中未假定 $f(0)=0$。若取常数函数 $f(x) = 1$，显然在 $x=0$ 处可导，但:
$$\lim_{x\to 0} \frac{f(x)}{\sqrt[3]{x}} = \lim_{x\to 0} \frac{1}{\sqrt[3]{x}} = \infty \ne 0$$
故 ③ 错误。
综上，只有 ② 正确。选 [B]。

**(复合求导)<font color=deeppink>题目[5]:振荡可导函数与可导函数复合的可导性</font>**

设 $f(x) = \begin{cases} x^2 \sin\frac{1}{x}, & x \ne 0, \\ 0, & x = 0, \end{cases}$ 记 $F(x) = g\big[f(x)\big]$，$g(x)$ 可导，则 $F(x)$ 在 $x=0$ 处 $(\quad)$.

[A] 不连续  
[B] 可导且 $F'(0) = 0$  
[C] 连续但不可导  
[D] 可导且 $F'(0) \ne 0$  

答案: [B]

主要思路:[利用导数定义与可微性展开 $g(u)-g(0)=g'(0)u+o(u)$，求出复合函数的导数]

[1]利用导数定义建立极限:
$$F'(0) = \lim_{x\to 0} \frac{F(x) - F(0)}{x - 0} = \lim_{x\to 0} \frac{g(f(x)) - g(f(0))}{x} = \lim_{x\to 0} \frac{g(f(x)) - g(0)}{x}$$

[2]由 $g(x)$ 可导展开增量:
因为 $g(x)$ 可导，所以当 $u\to 0$ 时，$g(u) - g(0) = g'(0)u + o(u)$。
当 $x\to 0$ 时，$f(x) \to 0$，故:
$$g(f(x)) - g(0) = g'(0)f(x) + o(f(x))$$

[3]代入极限求解:
$$\lim_{x\to 0} \frac{g(f(x)) - g(0)}{x} = \lim_{x\to 0} \left[g'(0)\frac{f(x)}{x} + \frac{o(f(x))}{x}\right]$$
因为 $\frac{f(x)}{x} = x\sin\frac{1}{x} \to 0$，且 $\frac{o(f(x))}{x} = \frac{o(f(x))}{f(x)} \cdot \frac{f(x)}{x} \to 0 \times 0 = 0$。
所以:
$$F'(0) = g'(0) \times 0 + 0 = 0$$
故 $F(x)$ 在 $x=0$ 处可导且 $F'(0) = 0$。选 [B]。

**(参数方程导数)<font color=deeppink>题目[6]:参数方程确定的函数增量极限</font>**

设函数 $y=f(x)$ 由参数方程 $\begin{cases} x = t^3 + \frac{\pi}{2} - 1, \\ y = \mathrm{e}^{t^2} \end{cases}$ 确定，则 $\lim\limits_{n\to\infty} n \left[ f\left(\frac{\pi}{2} + \frac{2}{n}\right) - f\left(\frac{\pi}{2}\right) \right] = (\quad)$.

[A] $2\mathrm{e}$  
[B] $\frac{4\mathrm{e}}{3}$  
[C] $\frac{2\mathrm{e}}{3}$  
[D] $\frac{\mathrm{e}}{3}$  

答案: [B]

主要思路:[将待求和式转化为导数表达式 $2f'(\pi/2)$，利用参数方程求导公式求对应点导数]

[1]将极限转化为导数形式:
令 $\Delta x = \frac{2}{n} \to 0$ ($n\to\infty$):
$$\lim_{n\to\infty} n \left[ f\left(\frac{\pi}{2} + \frac{2}{n}\right) - f\left(\frac{\pi}{2}\right) \right] = \lim_{n\to\infty} 2 \cdot \frac{f\left(\frac{\pi}{2} + \frac{2}{n}\right) - f\left(\frac{\pi}{2}\right)}{\frac{2}{n}} = 2 f'\left(\frac{\pi}{2}\right)$$

[2]确定对应的参数 $t$:
令 $x = t^3 + \frac{\pi}{2} - 1 = \frac{\pi}{2}$，解得:
$$t^3 = 1 \implies t = 1$$

[3]由参数方程求导并代入计算:
$$\frac{\mathrm{d}x}{\mathrm{d}t} = 3t^2, \qquad \frac{\mathrm{d}y}{\mathrm{d}t} = 2t\mathrm{e}^{t^2}$$
故:
$$\frac{\mathrm{d}y}{\mathrm{d}x} = \frac{2t\mathrm{e}^{t^2}}{3t^2} = \frac{2\mathrm{e}^{t^2}}{3t}$$
代入 $t = 1$:
$$f'\left(\frac{\pi}{2}\right) = \frac{2\mathrm{e}^1}{3 \times 1} = \frac{2\mathrm{e}}{3}$$
因此原极限为:
$$2 f'\left(\frac{\pi}{2}\right) = 2 \times \frac{2\mathrm{e}}{3} = \frac{4\mathrm{e}}{3}$$
选 [B]。

**(经典计算)<font color=deeppink>题目[7]:幂指复合函数的导数定义极限</font>**

设 $f(0)=a>0, f'(0)=b$，求 $\lim\limits_{x\to 0}\frac{f(x)^{f(x)} - f(0)^{f(0)}}{x}$.

答案: $b a^a (1 + \ln a)$

主要思路:[识别该极限为复合函数 $H(x) = f(x)^{f(x)}$ 在 $x=0$ 处的导数 $H'(0)$，利用对数求导法或复合求导求值]

[1]识别导数结构:
设 $H(x) = f(x)^{f(x)}$。
待求极限为:
$$\lim_{x\to 0} \frac{f(x)^{f(x)} - f(0)^{f(0)}}{x} = \lim_{x\to 0} \frac{H(x) - H(0)}{x - 0} = H'(0)$$

[2]对幂指函数求导:
将 $H(x)$ 改写为指数形式:
$$H(x) = \mathrm{e}^{f(x)\ln f(x)}$$
求导得:
$$H'(x) = \mathrm{e}^{f(x)\ln f(x)} \cdot [f(x)\ln f(x)]' = f(x)^{f(x)} \left[f'(x)\ln f(x) + f(x)\cdot \frac{f'(x)}{f(x)}\right] = f(x)^{f(x)} f'(x) [1 + \ln f(x)]$$

[3]代入 $x=0$ 求导数值:
代入 $f(0) = a, f'(0) = b$:
$$H'(0) = a^a \cdot b [1 + \ln a] = b a^a (1 + \ln a)$$

**(综合分析)<font color=red>题目[8]:含参变限积分的导数表达式与连续性</font>**

已知函数 $g(x)$ 连续，设 $f(x) = \int_0^{x^3} g(xt)\,\mathrm{d}t$，求 $f'(x)$ 的表达式，并判断 $f'(x)$ 在 $x=0$ 处的连续性.

答案: $f'(x) = \begin{cases} -\frac{1}{x^2}\int_0^{x^4} g(u)\,\mathrm{d}u + 4x^2 g(x^4), & x \ne 0 \\ 0, & x = 0 \end{cases}$，且 $f'(x)$ 在 $x=0$ 处连续

主要思路:[令 $u=xt$ 换元将 $x$ 提至积分号外，分 $x\ne 0$ 求导与 $x=0$ 按定义求导，再利用洛必达法则验证连续性]

[1]变量代换化简积分:
对于 $x \ne 0$，令 $u = xt$，则 $t = \frac{u}{x}$，$\mathrm{d}t = \frac{1}{x}\mathrm{d}u$。
当 $t = 0$ 时 $u = 0$；当 $t = x^3$ 时 $u = x^4$。
$$f(x) = \frac{1}{x}\int_0^{x^4} g(u)\,\mathrm{d}u$$

[2]对 $x \ne 0$ 求导:
$$f'(x) = \left(\frac{1}{x}\right)' \int_0^{x^4} g(u)\,\mathrm{d}u + \frac{1}{x} \frac{\mathrm{d}}{\mathrm{d}x}\left[\int_0^{x^4} g(u)\,\mathrm{d}u\right]$$
$$= -\frac{1}{x^2}\int_0^{x^4} g(u)\,\mathrm{d}u + \frac{1}{x} \left[g(x^4) \cdot 4x^3\right] = -\frac{1}{x^2}\int_0^{x^4} g(u)\,\mathrm{d}u + 4x^2 g(x^4)$$

[3]利用导数定义求 $f'(0)$:
易知 $f(0) = \int_0^0 g(0)\,\mathrm{d}t = 0$。
$$f'(0) = \lim_{x\to 0} \frac{f(x) - f(0)}{x} = \lim_{x\to 0} \frac{\int_0^{x^4} g(u)\,\mathrm{d}u}{x^2}$$
此为 $\frac{0}{0}$ 型，应用洛必达法则:
$$f'(0) = \lim_{x\to 0} \frac{g(x^4)\cdot 4x^3}{2x} = \lim_{x\to 0} 2x^2 g(x^4) = 0$$

[4]验证 $f'(x)$ 在 $x=0$ 处的连续性:
考察 $\lim\limits_{x\to 0} f'(x)$:
$$\lim_{x\to 0} f'(x) = \lim_{x\to 0} \left[-\frac{\int_0^{x^4} g(u)\,\mathrm{d}u}{x^2} + 4x^2 g(x^4)\right] = -f'(0) + 0 = 0 = f'(0)$$
因此 $f'(x)$ 在 $x=0$ 处连续。

**(概念证明)<font color=deeppink>题目[9]:绝对值函数在零点可导的充要条件证明</font>**

设函数 $f(x)$ 在 $x=a$ 的某个邻域内可导且 $f(a)=0$. 若绝对值函数 $|f(x)|$ 在 $x=a$ 处也可导，求 $f'(a)$ 的值，并说明理由.

答案: $f'(a) = 0$

主要思路:[写出 $|f(x)|$ 在 $x=a$ 处的左右导数，利用可导必有左右导数相等且符号相反推导导数必为 0]

[1]写出绝对值函数在 $x=a$ 处的导数极限:
令 $F(x) = |f(x)|$。因为 $f(a) = 0$，所以 $F(a) = |f(a)| = 0$。
$$F'(a) = \lim_{x\to a} \frac{|f(x)| - |f(a)|}{x - a} = \lim_{x\to a} \frac{|f(x)|}{x - a}$$

[2]分析左右单侧极限的符号:
当 $x \to a^+$ 时，$x - a > 0$，故 $\frac{|f(x)|}{x-a} \geqslant 0$，因此右导数:
$$F'_+(a) = \lim_{x\to a^+} \frac{|f(x)|}{x - a} \geqslant 0$$
当 $x \to a^-$ 时，$x - a < 0$，故 $\frac{|f(x)|}{x-a} \leqslant 0$，因此左导数:
$$F'_-(a) = \lim_{x\to a^-} \frac{|f(x)|}{x - a} \leqslant 0$$

[3]由可导性得出结论:
因为 $F(x) = |f(x)|$ 在 $x=a$ 处可导，左右导数必相等:
$$F'_+(a) = F'_-(a) \implies F'(a) = 0$$
由此可得:
$$\lim_{x\to a} \left|\frac{f(x) - f(a)}{x - a}\right| = \lim_{x\to a} \frac{|f(x)|}{|x - a|} = |F'(a)| = 0$$
由绝对值趋于 0 则本身趋于 0:
$$f'(a) = \lim_{x\to a} \frac{f(x) - f(a)}{x - a} = 0$$

**(综合计算)<font color=red>题目[10]:分段函数连续性与高阶泰勒展开可导性讨论</font>**

设 $f(x) = \begin{cases} \frac{g(x) - \mathrm{e}^{-x}}{x}, & x \ne 0, \\ a, & x = 0, \end{cases}$ 其中 $g(x)$ 有二阶连续导函数，$g(0)=1, g'(0)=-1$.

(1) $a$ 为何值时，$f(x)$ 在 $(-\infty, +\infty)$ 上连续？  
(2) 当 $f(x)$ 为连续函数时，$f(x)$ 是否可导？若可导，求 $f'(x)$.

答案: (1) $a = 0$；(2) 可导，$f'(x) = \begin{cases} \frac{x g'(x) - g(x) + (x+1)\mathrm{e}^{-x}}{x^2}, & x \ne 0 \\ \frac{1}{2}(g''(0) - 1), & x = 0 \end{cases}$

主要思路:[(1) 洛必达法则求 $x\to 0$ 极限确定 $a$；(2) 用导数定义结合二阶泰勒展开求 $f'(0)$，由求导法则求 $x\ne 0$ 的导数]

[1]第 (1) 问: 确定 $a$ 的取值:
由题设，$g(0) - \mathrm{e}^0 = 1 - 1 = 0$。
当 $x\to 0$ 时应用洛必达法则:
$$\lim_{x\to 0} \frac{g(x) - \mathrm{e}^{-x}}{x} = \lim_{x\to 0} \frac{g'(x) + \mathrm{e}^{-x}}{1} = g'(0) + 1$$
代入 $g'(0) = -1$:
$$\lim_{x\to 0} f(x) = -1 + 1 = 0$$
要使 $f(x)$ 在 $(-\infty, +\infty)$ 上连续，必须在 $x=0$ 处连续，故:
$$a = f(0) = \lim_{x\to 0} f(x) = 0$$

[2]第 (2) 问: 考察 $x=0$ 处的可导性:
由导数定义与 $a=0$:
$$f'(0) = \lim_{x\to 0} \frac{f(x) - f(0)}{x} = \lim_{x\to 0} \frac{g(x) - \mathrm{e}^{-x}}{x^2}$$
对 $g(x)$ 与 $\mathrm{e}^{-x}$ 在 $x=0$ 处进行二阶泰勒展开:
$$g(x) = g(0) + g'(0)x + \frac{1}{2}g''(0)x^2 + o(x^2) = 1 - x + \frac{1}{2}g''(0)x^2 + o(x^2)$$
$$\mathrm{e}^{-x} = 1 - x + \frac{1}{2}x^2 + o(x^2)$$
两式相减:
$$g(x) - \mathrm{e}^{-x} = \frac{1}{2}\left[g''(0) - 1\right]x^2 + o(x^2)$$
代入极限:
$$f'(0) = \lim_{x\to 0} \frac{\frac{1}{2}[g''(0) - 1]x^2 + o(x^2)}{x^2} = \frac{1}{2}\left[g''(0) - 1\right]$$
极限存在，因此 $f(x)$ 在 $x=0$ 处可导。

[3]求 $f'(x)$ 的完整表达式:
当 $x \ne 0$ 时，直接应用商的求导法则:
$$f'(x) = \frac{(g'(x) + \mathrm{e}^{-x})x - (g(x) - \mathrm{e}^{-x})}{x^2} = \frac{x g'(x) - g(x) + (x+1)\mathrm{e}^{-x}}{x^2}$$
故 $f(x)$ 在 $(-\infty, +\infty)$ 上处处可导，且:
$$f'(x) = \begin{cases} \frac{x g'(x) - g(x) + (x+1)\mathrm{e}^{-x}}{x^2}, & x \ne 0 \\ \frac{1}{2}(g''(0) - 1), & x = 0 \end{cases}$$

**(经典计算)<font color=deeppink>题目[11]:差商函数的导数与导函数连续性</font>**

设 $f(x)$ 有二阶连续导函数，且 $f(0)=0$，令 $g(x) = \begin{cases} \frac{f(x)}{x}, & x \ne 0, \\ f'(0), & x = 0. \end{cases}$

(1) 求 $g'(x)$；  
(2) 讨论 $g'(x)$ 在点 $x=0$ 处的连续性.

答案: (1) $g'(x) = \begin{cases} \frac{x f'(x) - f(x)}{x^2}, & x \ne 0 \\ \frac{1}{2}f''(0), & x = 0 \end{cases}$；(2) $g'(x)$ 在 $x=0$ 处连续

主要思路:[(1) 泰勒展开或洛必达法则按定义求 $g'(0)$；(2) 洛必达法则求 $\lim_{x\to 0} g'(x)$ 并与 $g'(0)$ 对比]

[1]第 (1) 问: 求 $g'(x)$:
当 $x \ne 0$ 时，应用商的求导法则:
$$g'(x) = \frac{x f'(x) - f(x)}{x^2}$$
当 $x = 0$ 时，按导数定义:
$$g'(0) = \lim_{x\to 0} \frac{g(x) - g(0)}{x} = \lim_{x\to 0} \frac{\frac{f(x)}{x} - f'(0)}{x} = \lim_{x\to 0} \frac{f(x) - x f'(0)}{x^2}$$
将 $f(x)$ 在 $x=0$ 处展开到二阶泰勒公式:
$$f(x) = f(0) + f'(0)x + \frac{1}{2}f''(0)x^2 + o(x^2) = f'(0)x + \frac{1}{2}f''(0)x^2 + o(x^2)$$
代入得:
$$g'(0) = \lim_{x\to 0} \frac{\frac{1}{2}f''(0)x^2 + o(x^2)}{x^2} = \frac{1}{2}f''(0)$$
故:
$$g'(x) = \begin{cases} \frac{x f'(x) - f(x)}{x^2}, & x \ne 0 \\ \frac{1}{2}f''(0), & x = 0 \end{cases}$$

[2]第 (2) 问: 讨论连续性:
考察极限 $\lim\limits_{x\to 0} g'(x)$:
$$\lim_{x\to 0} g'(x) = \lim_{x\to 0} \frac{x f'(x) - f(x)}{x^2}$$
此为 $\frac{0}{0}$ 型，应用洛必达法则:
$$\lim_{x\to 0} \frac{f'(x) + x f''(x) - f'(x)}{2x} = \lim_{x\to 0} \frac{x f''(x)}{2x} = \frac{1}{2}\lim_{x\to 0} f''(x)$$
因为 $f(x)$ 有二阶连续导函数，$\lim\limits_{x\to 0} f''(x) = f''(0)$。
故:
$$\lim_{x\to 0} g'(x) = \frac{1}{2}f''(0) = g'(0)$$
因此 $g'(x)$ 在点 $x=0$ 处连续。

**(综合分析)<font color=red>题目[12]:分段函数连续性、可导性及导函数连续性全分析</font>**

设 $f(x) = \begin{cases} x\arctan \frac{1}{\sqrt{x}}, & x > 0, \\ \frac{\pi}{2}(\mathrm{e}^{\sin x} - 1), & x \leqslant 0, \end{cases}$ 讨论 $f(x)$ 在点 $x=0$ 处的连续性和可导性；若可导，讨论其导函数 $f'(x)$ 在 $x=0$ 处的连续性.

答案: $f(x)$ 在 $x=0$ 处连续且可导，$f'(0)=\frac{\pi}{2}$；导函数 $f'(x)$ 在 $x=0$ 处连续

主要思路:[分侧计算左右极限判定连续；分侧计算左右导数判定可导；求出单侧导函数解析式验证导函数极限等于导数值]

[1]讨论连续性:
右极限: $\lim\limits_{x\to 0^+} f(x) = \lim\limits_{x\to 0^+} x\arctan\frac{1}{\sqrt{x}} = 0 \times \frac{\pi}{2} = 0$。
左极限: $\lim\limits_{x\to 0^-} f(x) = \lim\limits_{x\to 0^-} \frac{\pi}{2}(\mathrm{e}^{\sin x} - 1) = 0$。
函数值: $f(0) = 0$。
由于左右极限均存在且等于函数值，故 $f(x)$ 在 $x=0$ 处连续。

[2]讨论可导性:
右导数:
$$f'_+(0) = \lim_{x\to 0^+} \frac{x\arctan\frac{1}{\sqrt{x}} - 0}{x} = \lim_{x\to 0^+} \arctan\frac{1}{\sqrt{x}} = \frac{\pi}{2}$$
左导数:
$$f'_-(0) = \lim_{x\to 0^-} \frac{\frac{\pi}{2}(\mathrm{e}^{\sin x}-1) - 0}{x} = \frac{\pi}{2} \lim_{x\to 0^-} \frac{\sin x}{x} = \frac{\pi}{2}$$
因为 $f'_+(0) = f'_-(0) = \frac{\pi}{2}$，故 $f(x)$ 在 $x=0$ 处可导，且 $f'(0) = \frac{\pi}{2}$。

[3]讨论导函数的连续性:
当 $x > 0$ 时，直接求导:
$$f'(x) = \arctan\frac{1}{\sqrt{x}} + x \cdot \frac{1}{1 + \frac{1}{x}} \cdot \left(-\frac{1}{2}x^{-\frac{3}{2}}\right) = \arctan\frac{1}{\sqrt{x}} - \frac{\sqrt{x}}{2(x+1)}$$
当 $x\to 0^+$ 时:
$$\lim_{x\to 0^+} f'(x) = \frac{\pi}{2} - 0 = \frac{\pi}{2}$$
当 $x < 0$ 时，直接求导:
$$f'(x) = \frac{\pi}{2}\mathrm{e}^{\sin x}\cos x$$
当 $x\to 0^-$ 时:
$$\lim_{x\to 0^-} f'(x) = \frac{\pi}{2} \times 1 \times 1 = \frac{\pi}{2}$$
因此 $\lim\limits_{x\to 0} f'(x) = \frac{\pi}{2} = f'(0)$，导函数 $f'(x)$ 在 $x=0$ 处连续。

**(概念辨析)<font color=deeppink>题目[13]:绝对值函数不可导的充要条件</font>**

设 $f(x)$ 在 $x=a$ 处可导，则 $|f(x)|$ 在 $x=a$ 处不可导的充分必要条件是 $(\quad)$.

[A] $f(a)=0, f'(a)=0$  
[B] $f(a)=0, f'(a)\ne 0$  
[C] $f(a)\ne 0, f'(a)=0$  
[D] $f(a)\ne 0, f'(a)\ne 0$  

答案: [B]

主要思路:[若 $f(a)\ne 0$ 则局部保号必可导；若 $f(a)=0$ 则导数存在当且仅当 $f'(a)=0$]

[1]分析 $f(a) \ne 0$ 的情形:
若 $f(a) \ne 0$，由可导必连续及极限的保号性，在 $x=a$ 的某邻域内 $f(x)$ 恒正或恒负。
此时 $|f(x)| = f(x)$ 或 $|f(x)| = -f(x)$，显然在 $x=a$ 处可导。
因此 $|f(x)|$ 不可导的前提条件必为 $f(a) = 0$。

[2]分析 $f(a) = 0$ 的情形:
考察导数定义极限:
$$\lim_{x\to a} \frac{|f(x)| - |f(a)|}{x - a} = \lim_{x\to a} \frac{|f(x)|}{x - a}$$
- 若 $f'(a) = 0$，由题目[9]结论，左右导数均为 0，故 $|f(x)|$ 可导且导数为 0；
- 若 $f'(a) \ne 0$:
  - 右导数: $\lim\limits_{x\to a^+} \frac{|f(x)|}{x-a} = \left|\lim\limits_{x\to a^+} \frac{f(x)}{x-a}\right| = |f'(a)|$；
  - 左导数: $\lim\limits_{x\to a^-} \frac{|f(x)|}{x-a} = -\left|\lim\limits_{x\to a^-} \frac{f(x)}{x-a}\right| = -|f'(a)|$。
  由于 $f'(a) \ne 0$，左右导数符号相反不相等，因此不可导！

[3]结论:
充要条件为 $f(a) = 0$ 且 $f'(a) \ne 0$。选 [B]。

**(高阶导数)<font color=deeppink>题目[14]:幂指函数在原点的二阶导数存在性</font>**

设 $f(x) = \begin{cases} (1+x)^x - 1, & x > -1, x \ne 0, \\ 0, & x = 0, \end{cases}$ 则在 $x=0$ 处 $(\quad)$.

[A] $f(x)$ 连续，但 $f'(0)$ 不存在  
[B] $f'(0)$ 存在，但 $f'(x)$ 在 $x=0$ 处不连续  
[C] $f'(x)$ 连续，但 $f''(0)$ 不存在  
[D] $f''(0)$ 存在  

答案: [D]

主要思路:[将 $(1+x)^x$ 进行泰勒展开至 $x^2$ 项，由二阶差商极限直接得出二阶导数存在]

[1]泰勒展开分析局部性态:
当 $x\to 0$ 时:
$$(1+x)^x = \mathrm{e}^{x\ln(1+x)}$$
利用 $\ln(1+x) = x - \frac{1}{2}x^2 + o(x^2)$:
$$x\ln(1+x) = x^2 - \frac{1}{2}x^3 + o(x^3)$$
利用 $\mathrm{e}^u = 1 + u + \frac{1}{2}u^2 + o(u^2)$:
$$(1+x)^x = 1 + \left(x^2 - \frac{1}{2}x^3 + o(x^3)\right) + o(x^2) = 1 + x^2 - \frac{1}{2}x^3 + o(x^3)$$
因此:
$$f(x) = x^2 - \frac{1}{2}x^3 + o(x^3)$$

[2]求一阶导数 $f'(0)$:
$$f'(0) = \lim_{x\to 0} \frac{f(x) - f(0)}{x} = \lim_{x\to 0} \frac{x^2 - \frac{1}{2}x^3 + o(x^3)}{x} = \lim_{x\to 0} \left(x - \frac{1}{2}x^2 + o(x^2)\right) = 0$$

[3]验证二阶导数 $f''(0)$ 存在性:
当 $x \ne 0$ 时求导:
$$f'(x) = (1+x)^x \left[\ln(1+x) + \frac{x}{1+x}\right]$$
按二阶导数定义:
$$f''(0) = \lim_{x\to 0} \frac{f'(x) - f'(0)}{x} = \lim_{x\to 0} \frac{(1+x)^x \left[\ln(1+x) + \frac{x}{1+x}\right]}{x}$$
由于 $\lim\limits_{x\to 0} (1+x)^x = 1$，且:
$$\ln(1+x) = x - \frac{1}{2}x^2 + o(x^2), \qquad \frac{x}{1+x} = x(1-x+o(x)) = x - x^2 + o(x^2)$$
因此:
$$\ln(1+x) + \frac{x}{1+x} = 2x - \frac{3}{2}x^2 + o(x^2)$$
代入极限:
$$f''(0) = \lim_{x\to 0} \frac{2x - \frac{3}{2}x^2 + o(x^2)}{x} = 2$$
故 $f''(0)$ 存在且等于 2。选 [D]。

**(切线与极限)<font color=red>题目[15]:公切线斜率与数列增量极限</font>**

已知 $(1, 0)$ 在曲线 $y=f(x)$ 上，且曲线在该点与 $y=\ln(2x^2 - 1)$ 有公共的切线，则 $\lim\limits_{n\to\infty} n\left[f\left(\frac{n+1}{n}\right) - f\left(\frac{n+2}{n}\right)\right] = \underline{\qquad\qquad}$.

答案: $-4$

主要思路:[求公切线斜率确定 $f'(1)$，将数列增量化为导数定义计算]

[1]求公切线在点 $(1, 0)$ 处的斜率:
设 $g(x) = \ln(2x^2 - 1)$。
$$g'(x) = \frac{4x}{2x^2 - 1}$$
在 $x = 1$ 处:
$$g'(1) = \frac{4(1)}{2(1)^2 - 1} = 4$$
因为曲线 $y=f(x)$ 在 $(1, 0)$ 处与 $g(x)$ 有公共切线，所以:
$$f(1) = 0, \qquad f'(1) = g'(1) = 4$$

[2]展开数列增量并求极限:
$$\lim_{n\to\infty} n\left[f\left(1 + \frac{1}{n}\right) - f\left(1 + \frac{2}{n}\right)\right]$$
因为 $f(x)$ 在 $x=1$ 处可导，根据泰勒展开式:
$$f\left(1 + \frac{1}{n}\right) = f(1) + f'(1)\frac{1}{n} + o\left(\frac{1}{n}\right)$$
$$f\left(1 + \frac{2}{n}\right) = f(1) + f'(1)\frac{2}{n} + o\left(\frac{1}{n}\right)$$
两式相减:
$$f\left(1 + \frac{1}{n}\right) - f\left(1 + \frac{2}{n}\right) = -f'(1)\frac{1}{n} + o\left(\frac{1}{n}\right)$$

[3]计算极限:
$$\lim_{n\to\infty} n \left[-f'(1)\frac{1}{n} + o\left(\frac{1}{n}\right)\right] = -f'(1) = -4$$

**(经典计算)<font color=deeppink>题目[16]:可导函数与1的无穷次幂极限</font>**

设 $f(x)$ 在点 $x=a$ 处可导，且 $f(a)\ne 0$，计算 $I = \lim\limits_{x\to\infty} \left[\frac{f\left(a+\frac{1}{x}\right)}{f(a)}\right]^x$.

答案: $\mathrm{e}^{\frac{f'(a)}{f(a)}}$

主要思路:[识别 $1^\infty$ 型极限，指数化后利用导数定义求指数的极限]

[1]识别极限类型:
当 $x\to\infty$ 时，$\frac{1}{x} \to 0$。由 $f(x)$ 在 $x=a$ 处连续可知 $\lim\limits_{x\to\infty} f(a+\frac{1}{x}) = f(a)$。
因此底数趋于 1，指数趋于 $\infty$，属于 $1^\infty$ 型未定式。

[2]指数化转化极限:
$$I = \mathrm{e}^{\lim\limits_{x\to\infty} x \left[\frac{f\left(a+\frac{1}{x}\right)}{f(a)} - 1\right]} = \mathrm{e}^{\frac{1}{f(a)}\lim\limits_{x\to\infty} \frac{f\left(a+\frac{1}{x}\right) - f(a)}{\frac{1}{x}}}$$

[3]由导数定义求值:
令 $h = \frac{1}{x} \to 0$:
$$\lim_{x\to\infty} \frac{f\left(a+\frac{1}{x}\right) - f(a)}{\frac{1}{x}} = \lim_{h\to 0} \frac{f(a+h) - f(a)}{h} = f'(a)$$
因此:
$$I = \mathrm{e}^{\frac{f'(a)}{f(a)}}$$

**(概念辨析)<font color=red>题目[17]:导函数极限与点导数存在性辨析</font>**

设 $f(x)$ 在 $x=a$ 的某邻域内有定义，在 $x=a$ 的某去心邻域内可导，下述论断正确的是 $(\quad)$.

[A] 若 $\lim\limits_{x\to a} f'(x) = A$，则 $f'(a) = A$  
[B] 若 $f'(a) = A$，则 $\lim\limits_{x\to a} f'(x) = A$  
[C] 若 $\lim\limits_{x\to a} f'(x) = \infty$，则 $f'(a)$ 不存在  
[D] 若 $f'(a)$ 不存在，则 $\lim\limits_{x\to a} f'(x) = \infty$  

答案: [C]

主要思路:[举反例否定 [A][B][D]；利用达布定理或拉格朗日中值定理证明 [C]]

[1]反例否定 [A]、[B]、[D]:
- 对 [A]: 若 $f(x) = \begin{cases} 0, & x \ne a \\ 1, & x = a \end{cases}$，则去心邻域内 $f'(x) = 0 \to 0$，但 $f(x)$ 在 $x=a$ 处不连续必不可导，$f'(a)$ 不存在。[A] 错误；
- 对 [B]: 取经典反例 $f(x) = \begin{cases} x^2\sin\frac{1}{x}, & x \ne 0 \\ 0, & x = 0 \end{cases}$，在 $x=0$ 处 $f'(0)=0$ 存在，但去心邻域内 $f'(x) = 2x\sin\frac{1}{x} - \cos\frac{1}{x}$ 在 $x\to 0$ 时振荡发散，极限不存在。[B] 错误；
- 对 [D]: 取 $f(x) = |x|$，在 $x=0$ 处导数不存在，但去心邻域内 $f'(x) = \pm 1$，极限不存在但并非 $\infty$。[D] 错误。

[2]证明论断 [C]:
用反证法。若 $f'(a)$ 存在且有限，由可导必连续，$f(x)$ 在 $x=a$ 处连续。
在区间 $[a, x]$（或 $[x, a]$）上应用拉格朗日中值定理:
$$\frac{f(x) - f(a)}{x - a} = f'(\xi)$$
其中 $\xi$ 介于 $a$ 与 $x$ 之间。
当 $x\to a$ 时，$\xi \to a$。若 $\lim\limits_{x\to a} f'(x) = \infty$，则 $\lim\limits_{x\to a} f'(\xi) = \infty$。
这导致 $f'(a) = \lim\limits_{x\to a} \frac{f(x)-f(a)}{x-a} = \infty$，与 $f'(a)$ 存在且有限矛盾！
因此若 $\lim\limits_{x\to a} f'(x) = \infty$，$f'(a)$ 必不存在。选 [C]。

**(经典计算)<font color=deeppink>题目[18]:对称对数复合函数的导数计算</font>**

[1]求 $f(-1)$ 的值:
$$f(-1) = \frac{\ln|-1|}{2(-1)^2 - \ln|-1|} = \frac{0}{2 - 0} = 0$$

[2]应用导数定义:
$$f'(-1) = \lim_{x\to -1} \frac{f(x) - f(-1)}{x - (-1)} = \lim_{x\to -1} \frac{\frac{\ln|x|}{2x^2 - \ln|x|}}{x + 1}$$

[3]分离非零极限项并换元:
当 $x\to -1$ 时，分母项 $2x^2 - \ln|x| \to 2(-1)^2 - 0 = 2$。

$$\lim_{x\to -1} \frac{\ln|x|}{x+1} = \lim_{t\to 0} \frac{\ln(1-t)}{t} = \lim_{t\to 0} \frac{-t}{t} = -1$$
因此:
$$f'(-1) = \frac{1}{2} \times (-1) = -\frac{1}{2}$$

**(导数性质)<font color=green>题目[19]:余弦差与导数极限的链式转化</font>**

**(综合计算)<font color=red>题目[20]:已知包含导数的极限反求特定点导数值</font>**

已知函数 $f(x)$ 在 $x=1$ 处可导，且 $\lim\limits_{x\to 0}\frac{f(\cos x) - 3f(1+\sin^2 x)}{x^2} = 2$，求 $f'(1)$.

答案: $-\frac{4}{7}$

主要思路:[分母为 0 推出分子极限为 0 得到 $f(1)=0$；利用可导性展开为导数定义形式求解 $f'(1)$]

[1]由极限存在性确定 $f(1)$:
当 $x\to 0$ 时，$\cos x \to 1$ 且 $1+\sin^2 x \to 1$。
因为 $f(x)$ 在 $x=1$ 处可导，所以 $f(x)$ 在 $x=1$ 处连续。
分子极限为:
$$\lim_{x\to 0} [f(\cos x) - 3f(1+\sin^2 x)] = f(1) - 3f(1) = -2f(1)$$
分母 $x^2 \to 0$，若极限为有限值 2，分子必须趋于 0:
$$-2f(1) = 0 \implies f(1) = 0$$

[2]展开分子至导数定义形式:
由 $f(1) = 0$，当 $u\to 1$ 时，$f(u) = f'(1)(u-1) + o(u-1)$。

$$\cos x - 1 \sim -\frac{1}{2}x^2 \implies f(\cos x) = -\frac{1}{2}f'(1)x^2 + o(x^2)$$
对 $u = 1 + \sin^2 x$:
$$(1+\sin^2 x) - 1 = \sin^2 x \sim x^2 \implies f(1+\sin^2 x) = f'(1)x^2 + o(x^2)$$

[3]代入极限求解 $f'(1)$:
$$\lim_{x\to 0} \frac{f(\cos x) - 3f(1+\sin^2 x)}{x^2} = \lim_{x\to 0} \frac{-\frac{1}{2}f'(1)x^2 - 3f'(1)x^2 + o(x^2)}{x^2} = -\frac{7}{2}f'(1)$$
由题意:
$$-\frac{7}{2}f'(1) = 2 \implies f'(1) = -\frac{4}{7}$$

**(经典计算)<font color=deeppink>题目[21]:非负函数平方差极限与导数求解</font>**

设 $f(x)$ 是非负连续函数，且 $\lim\limits_{x\to a} \frac{f^2(x) - a}{x^2 - a^2} = 1 \ (a>0)$，求 $f'(a)$.

答案: $\sqrt{a}$

主要思路:[分母为 0 结合非负连续性求得 $f(a)=\sqrt{a}$；因式分解平方差分离出导数定义极限]

[1]确定 $f(a)$ 的值:
当 $x\to a$ 时，分母 $x^2 - a^2 \to 0$。
由于极限为 1，分子必趋于 0:
$$\lim_{x\to a} [f^2(x) - a] = 0 \implies \lim_{x\to a} f^2(x) = a$$
因为 $f(x)$ 连续且非负，所以:
$$f(a) = \lim_{x\to a} f(x) = \sqrt{a} > 0$$

[2]因式分解极限式:
$$\frac{f^2(x) - a}{x^2 - a^2} = \frac{[f(x) - \sqrt{a}][f(x) + \sqrt{a}]}{(x - a)(x + a)} = \frac{f(x) - \sqrt{a}}{x - a} \cdot \frac{f(x) + \sqrt{a}}{x + a}$$

[3]分别计算极限:
因为 $\lim\limits_{x\to a} \frac{f(x) + \sqrt{a}}{x + a} = \frac{\sqrt{a} + \sqrt{a}}{a + a} = \frac{2\sqrt{a}}{2a} = \frac{1}{\sqrt{a}}$。
原极限为:
$$\lim_{x\to a} \left[\frac{f(x) - f(a)}{x - a} \cdot \frac{1}{\sqrt{a}}\right] = 1$$
故:
$$f'(a) = \lim_{x\to a} \frac{f(x) - f(a)}{x - a} = \sqrt{a}$$

**(极值与导数)<font color=red>题目[22]:极值点费马引理与复合数列增量极限</font>**

已知 $a_n = 1 - \mathrm{e}^{\frac{1}{n}} - \sin \frac{1}{n^2}$，可导函数 $y = f(x) - \sin x$ 在 $x=0$ 处取得极值. 计算

$$\lim_{n\to\infty} n\left[f\left(\frac{1}{n}\right) - f(a_n)\right].$$

答案: $2$

主要思路:[由费马引理得 $f'(0)=1$；展开 $a_n$ 至 $\frac{1}{n}$ 主部，利用可导函数增量展开求极限]

[1]利用费马引理求 $f'(0)$:
设 $h(x) = f(x) - \sin x$。
因为 $h(x)$ 可导且在 $x=0$ 处取得极值，由费马引理:
$$h'(0) = 0$$
求导得 $h'(x) = f'(x) - \cos x$，代入 $x=0$:
$$h'(0) = f'(0) - \cos 0 = f'(0) - 1 = 0 \implies f'(0) = 1$$

[2]展开数列 $a_n$ 的渐近主部:
当 $n\to\infty$ 时:
$$\mathrm{e}^{\frac{1}{n}} = 1 + \frac{1}{n} + O\left(\frac{1}{n^2}\right), \qquad \sin\frac{1}{n^2} = O\left(\frac{1}{n^2}\right)$$
代入 $a_n$:
$$a_n = 1 - \left(1 + \frac{1}{n} + O\left(\frac{1}{n^2}\right)\right) - O\left(\frac{1}{n^2}\right) = -\frac{1}{n} + O\left(\frac{1}{n^2}\right)$$

[3]利用微分定义计算极限:
因为 $f(x)$ 在 $x=0$ 处可导，当 $u\to 0$ 时，$f(u) = f(0) + f'(0)u + o(u)$。
对 $u = \frac{1}{n}$:
$$f\left(\frac{1}{n}\right) = f(0) + f'(0)\frac{1}{n} + o\left(\frac{1}{n}\right)$$
对 $u = a_n$:
$$f(a_n) = f(0) + f'(0)\left(-\frac{1}{n}\right) + o\left(\frac{1}{n}\right)$$
两式相减:
$$f\left(\frac{1}{n}\right) - f(a_n) = f'(0)\left[\frac{1}{n} - \left(-\frac{1}{n}\right)\right] + o\left(\frac{1}{n}\right) = \frac{2}{n}f'(0) + o\left(\frac{1}{n}\right)$$
代入 $f'(0) = 1$ 并乘以 $n$:
$$\lim_{n\to\infty} n\left[f\left(\frac{1}{n}\right) - f(a_n)\right] = 2 f'(0) = 2 \times 1 = 2$$
