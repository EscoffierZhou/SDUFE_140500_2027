高等数学1000题基础篇 - 第11章 一元函数积分学的应用（二）——积分等式与积分不等式

(根的个数)题目[1]:变限积分方程在闭区间上实根个数判定

设 $a>0$，则在 $[0,a]$ 上方程 $\int_0^x \sqrt{4a^2-t^2}\mathrm{d}t + \int_a^x \frac{1}{\sqrt{4a^2-t^2}}\mathrm{d}t = 0$ 的根的个数为 $(\quad)$.

(A) $0$
(B) $1$
(C) $2$
(D) $3$

答案: (B)

主要思路:[构造辅助函数，分析单调性与区间端点函数值符号]

[1]构造辅助函数与求导:
设 $F(x) = \int_0^x \sqrt{4a^2-t^2}\mathrm{d}t + \int_a^x \frac{1}{\sqrt{4a^2-t^2}}\mathrm{d}t$，定义域为 $[0, a]$。
由变限积分求导法则：
$$F'(x) = \sqrt{4a^2-x^2} + \frac{1}{\sqrt{4a^2-x^2}}$$
因为当 $x\in [0, a]$ 时，$4a^2-x^2 \geqslant 3a^2 > 0$，所以 $F'(x) > 0$ 恒成立。
因此 $F(x)$ 在 $[0, a]$ 上严格单调递增。

[2]检验端点符号:
对于左端点 $x=0$：
$$F(0) = 0 + \int_a^0 \frac{1}{\sqrt{4a^2-t^2}}\mathrm{d}t = -\int_0^a \frac{1}{\sqrt{4a^2-t^2}}\mathrm{d}t = -\left. \arcsin\frac{t}{2a} \right|_0^a = -\arcsin\frac{1}{2} = -\frac{\pi}{6} < 0$$
对于右端点 $x=a$：
$$F(a) = \int_0^a \sqrt{4a^2-t^2}\mathrm{d}t + 0 > 0$$

[3]零点定理与唯一性结论:
由零点存在定理，$F(x)$ 在 $(0, a)$ 内至少存在一个根；
再由严格单调递增性，$F(x)=0$ 在 $[0, a]$ 上恰有且仅有 $1$ 个实根。选 (B)。

(正负判定)题目[2]:二阶导数凹凸性与三角函数加权定积分符号

设函数 $f(x)$ 具有二阶导数，$f'(x)>0, f''(x)<0$，记 $I_1 = \int_{-\pi}^\pi f(x)\sin x\mathrm{d}x$，$I_2 = \int_{-\pi}^\pi f(x)\cos x\mathrm{d}x$，则 $(\quad)$.

(A) $I_1>0, I_2<0$
(B) $I_1<0, I_2>0$
(C) $I_1<0, I_2<0$
(D) $I_1>0, I_2>0$

答案: (D)

主要思路:[利用对称区间拆分化为 $[0, \pi]$ 上的积分，结合单调性与分部积分判定正负]

[1]分析 $I_1$ 的符号:
将对称区间拆分并换元：
$$I_1 = \int_0^\pi f(x)\sin x\mathrm{d}x + \int_{-\pi}^0 f(x)\sin x\mathrm{d}x = \int_0^\pi f(x)\sin x\mathrm{d}x - \int_0^\pi f(-x)\sin x\mathrm{d}x = \int_0^\pi [f(x)-f(-x)]\sin x\mathrm{d}x$$
因为已知 $f'(x)>0$，$f(x)$ 严格单调递增。
当 $x\in(0, \pi)$ 时，$x > -x$，故 $f(x) - f(-x) > 0$；
又在 $(0, \pi)$ 上 $\sin x > 0$，被积函数严格大于零，故 $I_1 > 0$。

[2]分析 $I_2$ 的符号:
对 $I_2$ 应用分部积分法：
$$I_2 = \int_{-\pi}^\pi f(x)\mathrm{d}(\sin x) = \left. f(x)\sin x \right|_{-\pi}^\pi - \int_{-\pi}^\pi f'(x)\sin x\mathrm{d}x = -\int_{-\pi}^\pi f'(x)\sin x\mathrm{d}x$$
同理将该对称区间拆分：
$$\int_{-\pi}^\pi f'(x)\sin x\mathrm{d}x = \int_0^\pi [f'(x) - f'(-x)]\sin x\mathrm{d}x$$
因为已知 $f''(x) < 0$，$f'(x)$ 严格单调递减。
当 $x\in(0, \pi)$ 时，$x > -x$，故 $f'(x) < f'(-x) \implies f'(x) - f'(-x) < 0$；
因此 $\int_{-\pi}^\pi f'(x)\sin x\mathrm{d}x < 0$。
故 $I_2 = -\int_{-\pi}^\pi f'(x)\sin x\mathrm{d}x > 0$。
综上：$I_1 > 0$ 且 $I_2 > 0$。选 (D)。

(周期充要)题目[3]:周期函数定积分性质的充分必要性证明

设 $f(x)$ 为连续函数，$T>0$，证明：$f(x)$ 以 $T$ 为周期的充分必要条件是任给常数 $a$，$\int_a^{a+T} f(x)\mathrm{d}x$ 为常数.

答案: 证明见解析

主要思路:[必要性两边对 $a$ 求导验零；充分性由变限定积分导数为零反推 $f(a+T)=f(a)$]

[1]必要性证明 ($\implies$):
若 $f(x)$ 以 $T$ 为周期，即对任意实数 $x$ 恒有 $f(x+T) = f(x)$。
记函数 $F(a) = \int_a^{a+T} f(x)\mathrm{d}x$。
由于 $f(x)$ 连续，由变限定积分求导法则对 $a$ 求导：
$$F'(a) = \frac{\mathrm{d}}{\mathrm{d}a}\int_a^{a+T} f(x)\mathrm{d}x = f(a+T) - f(a)$$
由于 $f(a+T) = f(a)$，故 $F'(a) = 0$ 对任意实数 $a$ 恒成立。
因此 $F(a) = \int_a^{a+T} f(x)\mathrm{d}x$ 必为与 $a$ 无关的常数。

[2]充分性证明 ($\impliedby$):
若任给常数 $a$，$F(a) = \int_a^{a+T} f(x)\mathrm{d}x = C$（常数）。
则对其求导得：
$$F'(a) = 0 \implies f(a+T) - f(a) = 0 \implies f(a+T) = f(a)$$
由于该式对任意实数 $a$ 均成立，由周期函数定义，函数 $f(x)$ 必以 $T$ 为周期。
证毕。

(二重交换/分部)题目[4]:累次积分交换次序或分部积分恒等式证明

设 $f(x)$ 连续，证明：$\int_0^x \left[ \int_0^t f(u)\mathrm{d}u \right]\mathrm{d}t = \int_0^x f(t)(x-t)\mathrm{d}t$.

答案: 证明见解析

主要思路:[交换累次二重积分次序，或以 $(t-x)$ 为积分微元分部积分]

[1]方法一：交换积分次序法:
左端式子表示二重积分 $I = \iint_D f(u)\,\mathrm{d}u\mathrm{d}t$，其中积分区域为：
$$D = \{(u, t)\mid 0 \leqslant u \leqslant t \leqslant x\}$$
在 $u-t$ 平面上，将积分次序调整为先对 $t$ 积分，后对 $u$ 积分：
$u$ 的变化范围为 $[0, x]$；对于固定的 $u$，$t$ 的变化范围为 $[u, x]$。
$$I = \int_0^x \mathrm{d}u \int_u^x f(u)\,\mathrm{d}t = \int_0^x f(u) \left( \int_u^x \mathrm{d}t \right)\mathrm{d}u = \int_0^x f(u)(x-u)\,\mathrm{d}u$$
将积分哑变量 $u$ 改写为 $t$，即得 $\int_0^x f(t)(x-t)\mathrm{d}t$。

[2]方法二：分部积分法:
$$\int_0^x \left[ \int_0^t f(u)\mathrm{d}u \right]\mathrm{d}t = \int_0^x \left[ \int_0^t f(u)\mathrm{d}u \right]\mathrm{d}(t-x)$$
$$= \left. (t-x)\int_0^t f(u)\mathrm{d}u \right|_0^x - \int_0^x (t-x) f(t)\,\mathrm{d}t = 0 - 0 + \int_0^x (x-t)f(t)\,\mathrm{d}t$$
证毕。

(罗尔定理积分)题目[5]:双变限积分构造辅助函数应用罗尔定理

设 $f(x), g(x)$ 连续，$x\in [a,b]$，证明至少存在一点 $\xi\in (a,b)$，使 $f(\xi)\int_\xi^b g(x)\mathrm{d}x = g(\xi)\int_a^\xi f(x)\mathrm{d}x$.

答案: 证明见解析

主要思路:[构造乘积型变限积分辅助函数 $H(x) = \left(\int_a^x f(t)\mathrm{d}t\right)\left(\int_x^b g(t)\mathrm{d}t\right)$ 并验证端点]

[1]构造辅助函数:
设 $H(x) = \left(\int_a^x f(t)\mathrm{d}t\right)\left(\int_x^b g(t)\mathrm{d}t\right)$，定义域为 $[a, b]$。

[2]验证连续与可导条件:
因为 $f(t), g(t)$ 在 $[a, b]$ 上连续，由微积分基本定理，变限积分 $\int_a^x f(t)\mathrm{d}t$ 与 $\int_x^b g(t)\mathrm{d}t$ 均在 $[a, b]$ 上可导。
故 $H(x)$ 在 $[a, b]$ 上连续，在 $(a, b)$ 内可导。

[3]检验区间端点值:
$$H(a) = \left(\int_a^a f(t)\mathrm{d}t\right)\left(\int_a^b g(t)\mathrm{d}t\right) = 0 \cdot \int_a^b g(t)\mathrm{d}t = 0$$
$$H(b) = \left(\int_a^b f(t)\mathrm{d}t\right)\left(\int_b^b g(t)\mathrm{d}t\right) = \left(\int_a^b f(t)\mathrm{d}t\right) \cdot 0 = 0$$

[4]应用罗尔定理:
由罗尔定理，至少存在一点 $\xi \in (a, b)$，使得 $H'(\xi) = 0$。
求导展开：
$$H'(x) = f(x)\int_x^b g(t)\mathrm{d}t + \left(\int_a^x f(t)\mathrm{d}t\right)\big(-g(x)\big) = f(x)\int_x^b g(t)\mathrm{d}t - g(x)\int_a^x f(t)\mathrm{d}t$$
代入 $\xi$ 得：
$$f(\xi)\int_\xi^b g(x)\mathrm{d}x - g(\xi)\int_a^\xi f(x)\mathrm{d}x = 0 \implies f(\xi)\int_\xi^b g(x)\mathrm{d}x = g(\xi)\int_a^\xi f(x)\mathrm{d}x$$
证毕。

(倒代换反常)题目[6]:倒代换与对称配凑求解反常积分等式

证明：$\int_0^{+\infty}\frac{\mathrm{d}x}{1+x^4} = \int_0^{+\infty}\frac{x^2}{1+x^4}\mathrm{d}x = \frac{\sqrt{2}}{4}\pi$.

答案: 证明见解析

主要思路:[倒代换 $x = \frac{1}{t}$ 证明两积分相等，两式相加配方求解]

[1]证明第一等号成立（倒代换）:
设 $I = \int_0^{+\infty}\frac{\mathrm{d}x}{1+x^4}$。令 $x = \frac{1}{t}$，则 $\mathrm{d}x = -\frac{1}{t^2}\mathrm{d}t$：
$$I = \int_{+\infty}^0 \frac{1}{1+\frac{1}{t^4}}\left(-\frac{1}{t^2}\right)\mathrm{d}t = \int_0^{+\infty} \frac{t^2}{t^4+1}\mathrm{d}t = \int_0^{+\infty} \frac{x^2}{1+x^4}\mathrm{d}x$$
两积分严格相等。

[2]两式相加并配凑:
$$2I = \int_0^{+\infty} \frac{1+x^2}{1+x^4}\mathrm{d}x = \int_0^{+\infty} \frac{1+\frac{1}{x^2}}{x^2+\frac{1}{x^2}}\mathrm{d}x = \int_0^{+\infty} \frac{\mathrm{d}\left(x-\frac{1}{x}\right)}{\left(x-\frac{1}{x}\right)^2 + 2}$$
令 $u = x - \frac{1}{x}$，当 $x\to 0^+$ 时 $u\to -\infty$；当 $x\to +\infty$ 时 $u\to +\infty$：
$$2I = \int_{-\infty}^{+\infty} \frac{\mathrm{d}u}{u^2+2} = \left. \frac{1}{\sqrt{2}}\arctan\frac{u}{\sqrt{2}} \right|_{-\infty}^{+\infty} = \frac{1}{\sqrt{2}}\left[\frac{\pi}{2} - \left(-\frac{\pi}{2}\right)\right] = \frac{\pi}{\sqrt{2}} = \frac{\sqrt{2}}{2}\pi$$
$$I = \frac{\sqrt{2}}{4}\pi$$
证毕。

(复合单调性)题目[7]:复合函数导数单调性与定积分大小比较

已知函数 $f(x), g(x)$ 可导，且 $f'(x)>0, g'(x)<0$，则 $(\quad)$.

(A) $\int_{-1}^0 f(x)g(x)\mathrm{d}x > \int_0^1 f(x)g(x)\mathrm{d}x$
(B) $\int_{-1}^0 |f(x)g(x)|\mathrm{d}x > \int_0^1 |f(x)g(x)|\mathrm{d}x$
(C) $\int_{-1}^0 f\big[g(x)\big]\mathrm{d}x > \int_0^1 f\big[g(x)\big]\mathrm{d}x$
(D) $\int_{-1}^0 f\big[f(x)\big]\mathrm{d}x > \int_0^1 g\big[g(x)\big]\mathrm{d}x$

答案: (C)

主要思路:[利用链式法则分析复合函数 $h(x) = f(g(x))$ 的严格单调性]

[1]求导分析 $h(x) = f(g(x))$ 的单调性:
$$h'(x) = f'\big(g(x)\big) \cdot g'(x)$$
已知 $f'>0$（增函数），$g'<0$（减函数），故 $h'(x) < 0$ 恒成立。
因此 $h(x) = f(g(x))$ 在实数域上是严格单调递减函数。

[2]定积分大小比较:
因为 $h(x)$ 严格递减，所以对于任意 $x_1 \in [-1, 0]$ 与 $x_2 \in [0, 1]$，均有 $x_1 \leqslant 0 \leqslant x_2$，进而 $h(x_1) \geqslant h(0) \geqslant h(x_2)$（且不恒为常数）。
两边在长度为 $1$ 的区间上积分：
$$\int_{-1}^0 f\big[g(x)\big]\mathrm{d}x > h(0) > \int_0^1 f\big[g(x)\big]\mathrm{d}x$$
故 (C) 正确。

(切比雪夫不等式)题目[8]:切比雪夫积分不等式反向单调性判定

设 $f(x), g(x)$ 在 $[0,1]$ 上连续，则使得 $\int_0^1 f(x)\mathrm{d}x \int_0^1 g(x)\mathrm{d}x \geqslant \int_0^1 f(x)g(x)\mathrm{d}x$ 成立的条件是在 $[0,1]$ 上 $(\quad)$.

(A) $f(x), g(x)$ 均为增函数
(B) $f(x), g(x)$ 均为减函数
(C) $f(x)$ 为减函数，$g(x)$ 为增函数
(D) $f(x)$ 为奇函数，$g(x)$ 为偶函数

答案: (C)

主要思路:[建立双重积分二重对称恒等式判定被积函数符号]

[1]恒等式展开:
考虑二重积分：
$$\int_0^1 \int_0^1 [f(x)-f(y)][g(x)-g(y)]\mathrm{d}x\mathrm{d}y$$
$$= \int_0^1 \int_0^1 [f(x)g(x) - f(x)g(y) - f(y)g(x) + f(y)g(y)]\mathrm{d}x\mathrm{d}y$$
$$= 2\int_0^1 f(x)g(x)\mathrm{d}x - 2\left(\int_0^1 f(x)\mathrm{d}x\right)\left(\int_0^1 g(x)\mathrm{d}x\right)$$

[2]单调性符号判定:
对于 (C) 选项，若 $f(x)$ 为减函数，$g(x)$ 为增函数：
当 $x \geqslant y$ 时，$f(x) - f(y) \leqslant 0$，而 $g(x) - g(y) \geqslant 0$；
两式异号，乘积必有 $[f(x)-f(y)][g(x)-g(y)] \leqslant 0$。
在 $[0, 1]\times [0, 1]$ 上积分保持非正：
$$2\int_0^1 f(x)g(x)\mathrm{d}x - 2\left(\int_0^1 f(x)\mathrm{d}x\right)\left(\int_0^1 g(x)\mathrm{d}x\right) \leqslant 0$$
$$\implies \int_0^1 f(x)\mathrm{d}x \int_0^1 g(x)\mathrm{d}x \geqslant \int_0^1 f(x)g(x)\mathrm{d}x$$
故选 (C)。

(双端点不等式)题目[9]:两端为零函数的积分导数上界证明

设 $f'(x)$ 在 $[a,b]$ 上连续，$f(a)=f(b)=0$，证明：当 $x\in (a,b)$ 时，$|f(x)|\leqslant \frac{1}{2}\int_a^b |f'(x)|\mathrm{d}x$.

答案: 证明见解析

主要思路:[分别从两端点建立牛顿-莱布尼茨公式，两式绝对值相加平均]

[1]从左端点 $a$ 积分:
由牛顿-莱布尼茨公式及 $f(a)=0$：
$$f(x) = f(x) - f(a) = \int_a^x f'(t)\mathrm{d}t \implies |f(x)| \leqslant \int_a^x |f'(t)|\mathrm{d}t$$

[2]从右端点 $b$ 积分:
由 $f(b)=0$：
$$f(x) = f(x) - f(b) = -\int_x^b f'(t)\mathrm{d}t \implies |f(x)| \leqslant \int_x^b |f'(t)|\mathrm{d}t$$

[3]相加并除以 2:
$$2|f(x)| \leqslant \int_a^x |f'(t)|\mathrm{d}t + \int_x^b |f'(t)|\mathrm{d}t = \int_a^b |f'(t)|\mathrm{d}t$$
$$|f(x)| \leqslant \frac{1}{2}\int_a^b |f'(t)|\mathrm{d}t = \frac{1}{2}\int_a^b |f'(x)|\mathrm{d}x$$
证毕。

(微分上界估计)题目[10]:导数最大值控制定积分绝对值上界证明

设 $f'(x)$ 在 $[0,1]$ 上连续，且 $f(0)=0$，证明：$\left|\int_0^1 f(x)\mathrm{d}x\right| \leqslant \frac{M}{2}$，其中 $M = \max_{0\leqslant x\leqslant 1}|f'(x)|$.

答案: 证明见解析

主要思路:[拉格朗日中值定理点点放缩，或分部积分法统一估值]

[1]方法一：拉格朗日中值定理放缩:
对任意 $x \in [0, 1]$，应用拉格朗日中值定理：
$$f(x) = f(x) - f(0) = f'(\xi) x\quad (\xi \in (0, x))$$
两边取绝对值：
$$|f(x)| = |f'(\xi)| x \leqslant M x$$
由积分绝对值不等式：
$$\left|\int_0^1 f(x)\mathrm{d}x\right| \leqslant \int_0^1 |f(x)|\mathrm{d}x \leqslant \int_0^1 M x\,\mathrm{d}x = \left. \frac{M x^2}{2} \right|_0^1 = \frac{M}{2}$$

[2]方法二：分部积分法:
$$\int_0^1 f(x)\mathrm{d}x = \left. (x-1)f(x) \right|_0^1 - \int_0^1 (x-1)f'(x)\mathrm{d}x = 0 - \int_0^1 (x-1)f'(x)\mathrm{d}x = \int_0^1 (1-x)f'(x)\mathrm{d}x$$
$$\left|\int_0^1 f(x)\mathrm{d}x\right| \leqslant \int_0^1 (1-x)|f'(x)|\mathrm{d}x \leqslant M\int_0^1 (1-x)\mathrm{d}x = \frac{M}{2}$$
证毕。

(快速振荡积分)题目[11]:二次三角振荡积分分部积分上界放缩

设 $f(x) = \int_x^{x+1}\sin u^2\mathrm{d}u$，证明：当 $x>0$ 时，有 $|f(x)|\leqslant \frac{1}{x}$.

答案: 证明见解析

主要思路:[凑微分 $\sin u^2 \mathrm{d}u = -\frac{1}{2u}\mathrm{d}(\cos u^2)$，分部积分后应用三角不等式放缩]

[1]凑微分与分部积分:
当 $x>0$ 时，$u \in [x, x+1]$ 恒大于 $0$：
$$f(x) = \int_x^{x+1} \sin u^2\,\mathrm{d}u = -\int_x^{x+1} \frac{1}{2u}\,\mathrm{d}(\cos u^2)$$
$$= \left. -\frac{\cos u^2}{2u} \right|_x^{x+1} - \int_x^{x+1} \frac{\cos u^2}{2u^2}\,\mathrm{d}u = \frac{\cos x^2}{2x} - \frac{\cos(x+1)^2}{2(x+1)} - \int_x^{x+1} \frac{\cos u^2}{2u^2}\,\mathrm{d}u$$

[2]绝对值三角不等式放缩:
$$|f(x)| \leqslant \frac{|\cos x^2|}{2x} + \frac{|\cos(x+1)^2|}{2(x+1)} + \int_x^{x+1} \frac{|\cos u^2|}{2u^2}\,\mathrm{d}u$$
因为对任意实数恒有 $|\cos(\cdot)| \leqslant 1$：
$$|f(x)| \leqslant \frac{1}{2x} + \frac{1}{2(x+1)} + \int_x^{x+1} \frac{1}{2u^2}\,\mathrm{d}u$$

[3]计算剩余积分合并:
$$\int_x^{x+1} \frac{1}{2u^2}\,\mathrm{d}u = \left. -\frac{1}{2u} \right|_x^{x+1} = \frac{1}{2x} - \frac{1}{2(x+1)}$$
代入得：
$$|f(x)| \leqslant \frac{1}{2x} + \frac{1}{2(x+1)} + \left(\frac{1}{2x} - \frac{1}{2(x+1)}\right) = \frac{1}{2x} + \frac{1}{2x} = \frac{1}{x}$$
证毕。
