## 高等数学1000题基础篇 - 第15章 微分方程

### 一、选择题与填空题

**(一阶全微分方程)<font color=green>题目[1]:一阶可化为全微分的初值问题</font>**

$x\mathrm{d}y + y\mathrm{d}x = \sin x\,\mathrm{d}x$ 满足 $y(\pi)=0$ 的特解为 $\underline{\qquad\qquad}$.

答案: $y = -\frac{1+\cos x}{x}$

主要思路:[将左端识别为乘积微分 $\mathrm{d}(xy)$，直接积分确定特解]

[1]识别全微分形式:
方程左端为乘积的导数形式：
$$x\mathrm{d}y + y\mathrm{d}x = \mathrm{d}(xy)$$
方程变形为：
$$\mathrm{d}(xy) = \sin x\,\mathrm{d}x$$

[2]两端积分求通解:
$$xy = \int \sin x\,\mathrm{d}x = -\cos x + C$$

[3]代入初始条件确定常数:
由 $y(\pi) = 0$，得：
$$\pi \cdot 0 = -\cos\pi + C \implies 0 = -(-1) + C \implies C = -1$$
故特解为：
$$xy = -(1+\cos x) \implies y = -\frac{1+\cos x}{x}$$

**(几何应用反求方程)<font color=deeppink>题目[2]:切线截距与法线截距比例反求曲线方程</font>**

已知曲线上任一点的切线在 $y$ 轴上的截距与法线在 $x$ 轴上的截距之比为 $3:1$，则该曲线方程为 $\underline{\qquad\qquad}$.

答案: $3\ln(x^2+y^2) + 2\arctan\frac{y}{x} = C$

主要思路:[列出切线与法线截距表达式，建立齐次微分方程求解]

[1]写出切线与法线的截距:
设曲线上任一点为 $(x, y)$，切线方程为：
$$Y - y = y'(X - x)$$
令 $X = 0$，得切线在 $y$ 轴上的截距：
$$Y_T = y - x y'$$
过该点的法线斜率为 $-\frac{1}{y'}$，法线方程为：
$$Y - y = -\frac{1}{y'}(X - x)$$
令 $Y = 0$，得法线在 $x$ 轴上的截距：
$$X_N = x + y y'$$

[2]建立微分方程:
由题意截距之比为 $3:1$：
$$\frac{y - x y'}{x + y y'} = 3 \implies y - x y' = 3x + 3y y'$$
整理得：
$$(3y + x)y' = y - 3x \implies \frac{\mathrm{d}y}{\mathrm{d}x} = \frac{y - 3x}{3y + x}$$

[3]解齐次微分方程:
令 $y = ux$，则 $\frac{\mathrm{d}y}{\mathrm{d}x} = u + x\frac{\mathrm{d}u}{\mathrm{d}x}$：
$$u + x\frac{\mathrm{d}u}{\mathrm{d}x} = \frac{ux - 3x}{3ux + x} = \frac{u - 3}{3u + 1}$$
$$x\frac{\mathrm{d}u}{\mathrm{d}x} = \frac{u - 3 - u(3u + 1)}{3u + 1} = -\frac{3(u^2+1)}{3u+1}$$
分离变量：
$$\frac{3u+1}{u^2+1}\mathrm{d}u = -\frac{3}{x}\mathrm{d}x$$
积分两端：
$$\frac{3}{2}\ln(u^2+1) + \arctan u = -3\ln|x| + C_1$$
两端同乘 $2$ 并移项：
$$3\ln(u^2+1) + 6\ln|x| + 2\arctan u = C$$
$$\ln[(u^2+1)^3 x^6] + 2\arctan u = C$$
因 $(u^2+1)x^2 = x^2+y^2$，$u = \frac{y}{x}$，代回得：
$$3\ln(x^2+y^2) + 2\arctan\frac{y}{x} = C$$

**(一阶线性解的结构)<font color=green>题目[3]:一阶非齐次特解线性组合充要条件</font>**

设 $y_1, y_2$ 是一阶非齐次线性微分方程 $y' + p(x)y = q(x)$ 的两个特解，若常数 $\lambda, \mu$ 使 $\lambda y_1 + \mu y_2$ 是该方程的解，$\lambda y_1 - \mu y_2$ 是该方程对应的齐次方程的解，则 $(\quad)$.

[A] $\lambda = \frac{1}{2}, \mu = \frac{1}{2}$  
[B] $\lambda = -\frac{1}{2}, \mu = -\frac{1}{2}$  
[C] $\lambda = \frac{2}{3}, \mu = \frac{1}{3}$  
[D] $\lambda = \frac{2}{3}, \mu = \frac{2}{3}$

答案: [A]

主要思路:[根据线性方程解的叠加原理，系数和为1对应非齐次解，系数和为0对应齐次解]

[1]利用非齐次解的叠加性质:
若 $y = \lambda y_1 + \mu y_2$ 是非齐次方程 $y' + p(x)y = q(x)$ 的解，则：
$$(\lambda y_1 + \mu y_2)' + p(x)(\lambda y_1 + \mu y_2) = \lambda(y_1' + py_1) + \mu(y_2' + py_2) = (\lambda + \mu)q(x)$$
要使其恒等于 $q(x)$，必须且只需：
$$\lambda + \mu = 1$$

[2]利用齐次解的叠加性质:
若 $y = \lambda y_1 - \mu y_2$ 是齐次方程 $y' + p(x)y = 0$ 的解，则：
$$(\lambda y_1 - \mu y_2)' + p(x)(\lambda y_1 - \mu y_2) = (\lambda - \mu)q(x) = 0$$
因 $q(x)\not\equiv 0$，必有：
$$\lambda - \mu = 0 \implies \lambda = \mu$$

[3]联立方程组求解:
$$\begin{cases} \lambda + \mu = 1 \\ \lambda = \mu \end{cases} \implies \lambda = \frac{1}{2},\quad \mu = \frac{1}{2}$$
故选 [A]。

**(反函数法求解)<font color=deeppink>题目[4]:互换自变量与因变量的一阶线性微分方程</font>**

求微分方程 $(2x-3xy^2-y^3)y' + y^3 = 0$ 的通解.

答案: $x = \frac{1}{2}y^3 + C y^3 \mathrm{e}^{\frac{1}{y^2}}$（或 $2x = y^3(1+C\mathrm{e}^{\frac{1}{y^2}})$）

主要思路:[将 $x$ 视为 $y$ 的函数，将关于 $x$ 的非线性方程转化为关于 $x$ 的一阶线性微分方程]

[1]互换变量改写方程:
原方程中 $y'$ 带有复杂的 $y$ 的高次式，但 $x$ 仅为一次。将 $x$ 视作因变量，改写为：
$$(2x-3xy^2-y^3)\frac{\mathrm{d}y}{\mathrm{d}x} + y^3 = 0 \implies y^3\frac{\mathrm{d}x}{\mathrm{d}y} + (2-3y^2)x = y^3$$
两端同除以 $y^3$：
$$\frac{\mathrm{d}x}{\mathrm{d}y} + \frac{2-3y^2}{y^3}x = 1$$

[2]求积分因子:
$$P(y) = \frac{2}{y^3} - \frac{3}{y}$$
$$\int P(y)\mathrm{d}y = -\frac{1}{y^2} - 3\ln|y|$$
取积分因子为：
$$\mu(y) = \mathrm{e}^{\int P(y)\mathrm{d}y} = \frac{\mathrm{e}^{-\frac{1}{y^2}}}{y^3}$$

[3]求解线性微分方程:
两端同乘 $\mu(y)$：
$$\frac{\mathrm{d}}{\mathrm{d}y}\left[x \cdot \frac{\mathrm{e}^{-\frac{1}{y^2}}}{y^3}\right] = \frac{\mathrm{e}^{-\frac{1}{y^2}}}{y^3}$$
积分右端，令 $t = -\frac{1}{y^2}$，则 $\mathrm{d}t = \frac{2}{y^3}\mathrm{d}y$：
$$\int \frac{\mathrm{e}^{-\frac{1}{y^2}}}{y^3}\mathrm{d}y = \frac{1}{2}\int \mathrm{e}^t\mathrm{d}t = \frac{1}{2}\mathrm{e}^{-\frac{1}{y^2}} + C$$
故：
$$x \frac{\mathrm{e}^{-\frac{1}{y^2}}}{y^3} = \frac{1}{2}\mathrm{e}^{-\frac{1}{y^2}} + C \implies x = \frac{1}{2}y^3 + C y^3 \mathrm{e}^{\frac{1}{y^2}}$$

**(变量代换与极限)<font color=green>题目[5]:可降阶换元微分方程与幂指函数极限</font>**

过原点的曲线 $y=y(x)$ 满足 $\frac{\mathrm{d}y}{\mathrm{d}x} = (x+y)^2$，则 $\lim_{x\to 0^+} [y(x)]^x = \underline{\qquad\qquad}$.

答案: $1$

主要思路:[换元 $u = x+y$ 分离变量求得解析式，再利用对数换元求 $0^0$ 型极限]

[1]换元求解微分方程:
令 $u = x+y$，则 $\frac{\mathrm{d}u}{\mathrm{d}x} = 1 + \frac{\mathrm{d}y}{\mathrm{d}x} = 1 + u^2$。
分离变量：
$$\frac{\mathrm{d}u}{1+u^2} = \mathrm{d}x \implies \arctan u = x + C$$
由曲线过原点 $y(0)=0$，得 $u(0)=0$，故 $C = 0$。
从而：
$$\arctan(x+y) = x \implies x+y = \tan x \implies y = \tan x - x$$

[2]求幂指函数极限:
所求极限为 $0^0$ 型不定式：
$$\lim_{x\to 0^+} [y(x)]^x = \lim_{x\to 0^+} (\tan x - x)^x = \mathrm{e}^{\lim_{x\to 0^+} x\ln(\tan x - x)}$$
当 $x\to 0^+$ 时，$\tan x - x \sim \frac{1}{3}x^3$：
$$\lim_{x\to 0^+} x\ln(\tan x - x) = \lim_{x\to 0^+} x\ln\left(\frac{1}{3}x^3\right) = \lim_{x\to 0^+} (3x\ln x - x\ln 3) = 0$$
故：
$$\lim_{x\to 0^+} [y(x)]^x = \mathrm{e}^0 = 1$$

**(换元化线性方程)<font color=deeppink>题目[6]:三角复合可化为一阶线性的微分方程</font>**

微分方程 $y' = (x+1)\sec y - \tan y$ 的通解为 $\underline{\qquad\qquad}$.

答案: $\sin y = x + C\mathrm{e}^{-x}$

主要思路:[两边同乘 $\cos y$ 移项，令 $u = \sin y$ 化为关于 $u$ 的一阶线性微分方程]

[1]化简方程结构:
方程两端同乘以 $\cos y$：
$$\cos y \frac{\mathrm{d}y}{\mathrm{d}x} = (x+1) - \sin y \implies \cos y \frac{\mathrm{d}y}{\mathrm{d}x} + \sin y = x+1$$

[2]变量替换化为线性微分方程:
令 $u = \sin y$，则 $\frac{\mathrm{d}u}{\mathrm{d}x} = \cos y \frac{\mathrm{d}y}{\mathrm{d}x}$，代入方程得：
$$\frac{\mathrm{d}u}{\mathrm{d}x} + u = x+1$$

[3]求解线性微分方程:
两端同乘积分因子 $\mathrm{e}^x$：
$$\frac{\mathrm{d}}{\mathrm{d}x}(u\mathrm{e}^x) = (x+1)\mathrm{e}^x$$
积分得：
$$u\mathrm{e}^x = \int (x+1)\mathrm{e}^x\,\mathrm{d}x = x\mathrm{e}^x + C \implies u = x + C\mathrm{e}^{-x}$$
代回 $u = \sin y$，得原方程的通解为：
$$\sin y = x + C\mathrm{e}^{-x}$$

**(一阶线性与斜渐近线)<font color=green>题目[7]:一阶线性方程初值解及曲线的斜渐近线</font>**

设函数 $y(x)$ 是微分方程 $y' + \frac{1}{x^2}y = 2\mathrm{e}^{\frac{1}{x}}$ 满足 $y\left(\frac{1}{2}\right)=0$ 的解.

[1] 求 $y=y(x)$ 的表达式；  
[2] 求曲线 $y(x)$ 的斜渐近线.

答案: [1] $y = (2x-1)\mathrm{e}^{\frac{1}{x}}$；[2] $y = 2x+1$

主要思路:[通解公式代入初值求出解析式，再利用泰勒展开求斜渐近线 $y=kx+b$]

[1]求解一阶线性微分方程:
积分因子为 $\mathrm{e}^{\int \frac{1}{x^2}\mathrm{d}x} = \mathrm{e}^{-\frac{1}{x}}$。
两端同乘 $\mathrm{e}^{-\frac{1}{x}}$：
$$\frac{\mathrm{d}}{\mathrm{d}x}\left[y\mathrm{e}^{-\frac{1}{x}}\right] = 2\mathrm{e}^{\frac{1}{x}}\cdot\mathrm{e}^{-\frac{1}{x}} = 2$$
积分得：
$$y\mathrm{e}^{-\frac{1}{x}} = 2x + C \implies y = (2x+C)\mathrm{e}^{\frac{1}{x}}$$
代入初始条件 $y\left(\frac{1}{2}\right) = 0$：
$$\left(2\cdot\frac{1}{2} + C\right)\mathrm{e}^2 = 0 \implies 1+C = 0 \implies C = -1$$
故：
$$y = (2x-1)\mathrm{e}^{\frac{1}{x}}$$

[2]求斜渐近线:
设斜渐近线为 $y = kx + b$：
$$k = \lim_{x\to \infty} \frac{y(x)}{x} = \lim_{x\to \infty} \frac{(2x-1)\mathrm{e}^{\frac{1}{x}}}{x} = \lim_{x\to \infty}\left(2 - \frac{1}{x}\right)\mathrm{e}^{\frac{1}{x}} = 2\cdot 1 = 2$$
$$b = \lim_{x\to \infty} [y(x) - kx] = \lim_{x\to \infty} [(2x-1)\mathrm{e}^{\frac{1}{x}} - 2x]$$
利用 $\mathrm{e}^{\frac{1}{x}} = 1 + \frac{1}{x} + \frac{1}{2x^2} + o\left(\frac{1}{x^2}\right)$ 展开：
$$(2x-1)\mathrm{e}^{\frac{1}{x}} = (2x-1)\left(1 + \frac{1}{x} + \frac{1}{2x^2} + o\left(\frac{1}{x^2}\right)\right) = 2x + 2 - 1 - \frac{1}{x} + o\left(\frac{1}{x}\right) = 2x + 1 + o(1)$$
因此：
$$b = \lim_{x\to \infty} (2x+1 - 2x) = 1$$
故所求斜渐近线方程为 $y = 2x + 1$。

**(旋转体注水速率模型)<font color=deeppink>题目[8]:变化速率与旋转体截面积微分方程建模</font>**

以 $yOz$ 面上的平面曲线段 $y=f(z)\ (z\geqslant 0)$ 绕 $z$ 轴旋转一周所成旋转曲面与 $xOy$ 面围成一个无上盖容器，现以 $3\,\text{cm}^3/\text{s}$ 的速率把水注入容器内，水面的面积以 $\pi\,\text{cm}^2/\text{s}$ 的速率增大. 已知容器底面积为 $16\pi\,\text{cm}^2$，求曲线 $y=f(z)$ 的方程.

答案: $y = 4\mathrm{e}^{\frac{\pi}{6}z}\ (z\geqslant 0)$

主要思路:[利用链式法则建立水面面积关于水深的微分方程，解出面积后再求母线方程]

[1]建立体积、截面积与水深的导数关系:
水面在高度 $z$ 处的截面积为 $S(z) = \pi [f(z)]^2$。
水的体积为 $V(z) = \int_0^z S(u)\mathrm{d}u$，由微积分基本定理：
$$\frac{\mathrm{d}V}{\mathrm{d}z} = S(z)$$
由复合函数求导链式法则：
$$\frac{\mathrm{d}V}{\mathrm{d}t} = \frac{\mathrm{d}V}{\mathrm{d}z}\cdot\frac{\mathrm{d}z}{\mathrm{d}t} = S(z)\frac{\mathrm{d}z}{\mathrm{d}t} = 3 \implies \frac{\mathrm{d}z}{\mathrm{d}t} = \frac{3}{S(z)}$$

[2]建立面积关于深度的微分方程:
水面面积的增长速率为：
$$\frac{\mathrm{d}S}{\mathrm{d}t} = \frac{\mathrm{d}S}{\mathrm{d}z}\cdot\frac{\mathrm{d}z}{\mathrm{d}t} = S'(z)\cdot\frac{3}{S(z)} = \pi$$
整理得分离变量微分方程：
$$\frac{\mathrm{d}S}{S} = \frac{\pi}{3}\mathrm{d}z$$

[3]求解微分方程并确定母线:
积分得：
$$\ln S(z) = \frac{\pi}{3}z + C_1 \implies S(z) = S(0)\mathrm{e}^{\frac{\pi}{3}z}$$
由底面积 $S(0) = 16\pi$，得：
$$S(z) = 16\pi\mathrm{e}^{\frac{\pi}{3}z}$$
又因 $S(z) = \pi y^2$，故：
$$\pi y^2 = 16\pi\mathrm{e}^{\frac{\pi}{3}z} \implies y^2 = 16\mathrm{e}^{\frac{\pi}{3}z}$$
由于 $y = f(z) > 0$，开方得曲线方程：
$$y = 4\mathrm{e}^{\frac{\pi}{6}z}\quad (z\geqslant 0)$$

**(积分方程化微分方程)<font color=green>题目[9]:含变限积分方程化一阶常系数线性方程</font>**

设 $f(x)$ 有连续导数，$x\in [0, +\infty)$，且满足方程 $\int_0^x (x-1)f(t)\,\mathrm{d}t - \int_0^x tf(t)\,\mathrm{d}t = x$，求函数 $f(x)$.

答案: $f(x) = -\mathrm{e}^x$

主要思路:[拆分积分项后对 $x$ 两次求导，转化为齐次常系数线性微分方程求解]

[1]提取变量并第一次求导:
将方程改写为：
$$(x-1)\int_0^x f(t)\,\mathrm{d}t - \int_0^x tf(t)\,\mathrm{d}t = x$$
两端对 $x$ 求导：
$$1\cdot \int_0^x f(t)\,\mathrm{d}t + (x-1)f(x) - x f(x) = 1 \implies \int_0^x f(t)\,\mathrm{d}t - f(x) = 1$$

[2]第二次求导建立微分方程:
对上述等式两端再次对 $x$ 求导：
$$f(x) - f'(x) = 0 \implies f'(x) - f(x) = 0$$
此为一阶齐次线性微分方程，其通解为：
$$f(x) = C\mathrm{e}^x$$

[3]由初值确定常数:
在第一次求导后的等式 $\int_0^x f(t)\mathrm{d}t - f(x) = 1$ 中，令 $x = 0$：
$$0 - f(0) = 1 \implies f(0) = -1$$
代入通解得 $C = -1$，故：
$$f(x) = -\mathrm{e}^x$$

**(一阶线性特解与积分估值)<font color=deeppink>题目[10]:一阶线性方程特解求解与不等式估值证明</font>**

设 $\varphi(x)$ 为连续函数，$|\varphi(x)|\leqslant k$（$k$ 为常数），求微分方程 $\frac{\mathrm{d}y}{\mathrm{d}x} + y = \varphi(x)$ 满足初始条件 $y(0)=0$ 的特解 $y(x)$，并证明当 $x\geqslant 0$ 时，有 $|y(x)|\leqslant k(1-\mathrm{e}^{-x})$.

答案: $y(x) = \mathrm{e}^{-x}\int_0^x \varphi(t)\mathrm{e}^t\,\mathrm{d}t$

主要思路:[常数变易法求出初值特解的定积分表达式，利用积分不等式进行绝对值放大估值]

[1]求初值特解:
方程 $\frac{\mathrm{d}y}{\mathrm{d}x} + y = \varphi(x)$ 的积分因子为 $\mathrm{e}^x$。
两边同乘 $\mathrm{e}^x$：
$$\frac{\mathrm{d}}{\mathrm{d}x}\left[y\mathrm{e}^x\right] = \varphi(x)\mathrm{e}^x$$
从 $0$ 到 $x$ 积分：
$$y(x)\mathrm{e}^x - y(0)\mathrm{e}^0 = \int_0^x \varphi(t)\mathrm{e}^t\,\mathrm{d}t$$
代入 $y(0)=0$，得特解：
$$y(x) = \mathrm{e}^{-x}\int_0^x \varphi(t)\mathrm{e}^t\,\mathrm{d}t$$

[2]证明不等式:
当 $x\geqslant 0$ 时，对特解两端取绝对值：
$$|y(x)| = \left|\mathrm{e}^{-x}\int_0^x \varphi(t)\mathrm{e}^t\,\mathrm{d}t\right| \leqslant \mathrm{e}^{-x}\int_0^x |\varphi(t)|\mathrm{e}^t\,\mathrm{d}t$$
已知 $|\varphi(t)|\leqslant k$，代入放大：
$$|y(x)| \leqslant k \mathrm{e}^{-x}\int_0^x \mathrm{e}^t\,\mathrm{d}t = k \mathrm{e}^{-x}\left[\mathrm{e}^x - 1\right] = k(1 - \mathrm{e}^{-x})$$
命题得证。

**(一阶线性解的平均值)<font color=green>题目[11]:欧拉型一阶方程与连续函数区间平均值</font>**

设函数 $y=y(x)$ 是微分方程 $2xy' - 4y = 2\ln x - 1$ 满足条件 $y(1) = \frac{1}{4}$ 的解，求曲线 $y=y(x)$ 在 $[1, \mathrm{e}]$ 上的平均值.

答案: $\frac{\mathrm{e}^3-7}{12(\mathrm{e}-1)}$

主要思路:[化为标准一阶线性方程求解特解，再按积分平均值公式积分计算]

[1]求解一阶线性微分方程:
两端同除以 $2x$：
$$y' - \frac{2}{x}y = \frac{\ln x}{x} - \frac{1}{2x}$$
积分因子为 $\mathrm{e}^{\int -\frac{2}{x}\mathrm{d}x} = \frac{1}{x^2}$。
两边同乘 $\frac{1}{x^2}$：
$$\frac{\mathrm{d}}{\mathrm{d}x}\left[\frac{y}{x^2}\right] = \frac{\ln x}{x^3} - \frac{1}{2x^3}$$
积分右端各项：
$$\int \frac{\ln x}{x^3}\mathrm{d}x = -\frac{1}{2}\int \ln x\,\mathrm{d}(x^{-2}) = -\frac{\ln x}{2x^2} + \frac{1}{2}\int x^{-3}\mathrm{d}x = -\frac{\ln x}{2x^2} - \frac{1}{4x^2}$$
$$\int -\frac{1}{2x^3}\mathrm{d}x = \frac{1}{4x^2}$$
相加得：
$$\frac{y}{x^2} = -\frac{\ln x}{2x^2} + C \implies y = -\frac{1}{2}\ln x + C x^2$$
代入 $y(1) = \frac{1}{4}$：
$$0 + C = \frac{1}{4} \implies C = \frac{1}{4}$$
故特解为 $y(x) = \frac{1}{4}x^2 - \frac{1}{2}\ln x$。

[2]计算在 $[1, \mathrm{e}]$ 上的平均值:
$$\bar{y} = \frac{1}{\mathrm{e}-1}\int_1^{\mathrm{e}} \left(\frac{1}{4}x^2 - \frac{1}{2}\ln x\right)\mathrm{d}x$$
分别计算积分：
$$\int_1^{\mathrm{e}} \frac{1}{4}x^2\,\mathrm{d}x = \left.\frac{x^3}{12}\right|_1^{\mathrm{e}} = \frac{\mathrm{e}^3-1}{12}$$
$$\int_1^{\mathrm{e}} \frac{1}{2}\ln x\,\mathrm{d}x = \left.\frac{1}{2}(x\ln x - x)\right|_1^{\mathrm{e}} = \frac{1}{2}[(\mathrm{e}-\mathrm{e}) - (0-1)] = \frac{1}{2}$$
相减得：
$$\int_1^{\mathrm{e}} \left(\frac{1}{4}x^2 - \frac{1}{2}\ln x\right)\mathrm{d}x = \frac{\mathrm{e}^3-1}{12} - \frac{1}{2} = \frac{\mathrm{e}^3-7}{12}$$
故平均值为：
$$\bar{y} = \frac{\mathrm{e}^3-7}{12(\mathrm{e}-1)}$$

**(几何切线截距围面积)<font color=deeppink>题目[12]:切线截距几何性质建立方程与平面面积</font>**

设曲线 $y=y(x)\ (x>0)$ 经过点 $(1,0)$，该曲线上任一点 $P(x,y)$ 到 $y$ 轴的距离等于该点处的切线在 $y$ 轴上的截距，求 $y(x)$ 在区间 $(0,1)$ 上与 $x$ 轴所围平面图形的面积.

答案: $\frac{1}{2}$

主要思路:[列出切线截距方程求得直线解，再对区间积分求面积]

[1]建立微分方程:
点 $P(x,y)\ (x>0)$ 到 $y$ 轴的距离为 $x$。
过点 $P$ 的切线在 $y$ 轴上的截距为 $Y_T = y - xy'$。
由题意：
$$y - xy' = x \implies xy' - y = -x \implies y' - \frac{1}{x}y = -1$$

[2]求解微分方程:
两端乘积分因子 $\frac{1}{x}$：
$$\frac{\mathrm{d}}{\mathrm{d}x}\left[\frac{y}{x}\right] = -\frac{1}{x^2}$$
积分得：
$$\frac{y}{x} = \frac{1}{x} + C \implies y = 1 + Cx$$
由曲线过点 $(1,0)$：
$$0 = 1 + C \implies C = -1$$
故曲线方程为 $y = 1 - x$（若考虑截距为距离的相反数，对应 $y = x - 1$，围成面积相同）。

[3]计算围成图形的面积:
在区间 $(0,1)$ 上，$y = 1-x \geqslant 0$，所围面积为：
$$S = \int_0^1 (1-x)\,\mathrm{d}x = \left[x - \frac{1}{2}x^2\right]_0^1 = \frac{1}{2}$$

**(二阶常系数初值方程)<font color=green>题目[13]:二阶常系数齐次初值问题与正交切线</font>**

设曲线 $y=y(x)$ 上点 $P(0,4)$ 处的切线垂直于直线 $x-2y+5=0$，且该曲线满足微分方程 $y''+2y'+y=0$，则此曲线方程为 $(\quad)$.

[A] $y = \frac{9}{2}x\mathrm{e}^{-x}$  
[B] $y = \left(4+\frac{9}{2}x\right)\mathrm{e}^{-x}$  
[C] $y = (C_1 x + C_2)\mathrm{e}^{-x}$  
[D] $y = 2(x+2)\mathrm{e}^{-x}$

答案: [D]

主要思路:[由垂线斜率求出 $y'(0)$，解二阶常系数齐次特征方程确定特解]

[1]确定初始条件:
曲线过点 $(0,4)$，故 $y(0) = 4$。
已知直线 $x - 2y + 5 = 0$ 的斜率为 $k_1 = \frac{1}{2}$。
切线垂直于该直线，故切线斜率满足 $y'(0)\cdot \frac{1}{2} = -1 \implies y'(0) = -2$。

[2]求微分方程的通解:
特征方程为：
$$r^2 + 2r + 1 = 0 \implies (r+1)^2 = 0 \implies r_1 = r_2 = -1$$
通解为：
$$y = (C_1 + C_2 x)\mathrm{e}^{-x}$$

[3]代入初值确定常数:
由 $y(0) = 4$，得 $C_1 = 4$。
求导得：
$$y' = C_2\mathrm{e}^{-x} - (C_1 + C_2 x)\mathrm{e}^{-x} = (C_2 - C_1 - C_2 x)\mathrm{e}^{-x}$$
代入 $y'(0) = -2$：
$$C_2 - C_1 = -2 \implies C_2 - 4 = -2 \implies C_2 = 2$$
故曲线方程为：
$$y = (4 + 2x)\mathrm{e}^{-x} = 2(x+2)\mathrm{e}^{-x}$$
故选 [D]。

**(二阶齐次共轭复根)<font color=green>题目[14]:二阶常系数齐次共轭复根初值问题</font>**

设曲线 $y=y(x)$ 经过原点，且在原点处的切线与直线 $2x+y+6=0$ 平行，而 $y(x)$ 满足微分方程 $y''-2y'+5y=0$，则此曲线的方程为 $(\quad)$.

[A] $y = \mathrm{e}^x \sin 2x$  
[B] $y = -\mathrm{e}^x \sin 2x$  
[C] $y = \mathrm{e}^x (\cos 2x - \sin 2x)$  
[D] $y = \mathrm{e}^x (\sin 2x - \cos 2x)$

答案: [B]

主要思路:[由原点及平行切线确定初始值，解含三角因子的共轭复根通解]

[1]确定初始条件:
曲线过原点，得 $y(0) = 0$。
直线 $2x + y + 6 = 0$ 的斜率为 $-2$，在原点处切线与之平行，故 $y'(0) = -2$。

[2]求微分方程的通解:
特征方程为：
$$r^2 - 2r + 5 = 0 \implies (r-1)^2 + 4 = 0 \implies r = 1 \pm 2\mathrm{i}$$
通解为：
$$y = \mathrm{e}^x(C_1\cos 2x + C_2\sin 2x)$$

[3]代入初值确定常数:
由 $y(0) = 0$ 得 $C_1 = 0$。
从而 $y = C_2 \mathrm{e}^x \sin 2x$。
求导：
$$y' = C_2\mathrm{e}^x(\sin 2x + 2\cos 2x)$$
代入 $y'(0) = -2$：
$$2C_2 = -2 \implies C_2 = -1$$
故曲线方程为：
$$y = -\mathrm{e}^x \sin 2x$$
故选 [B]。

**(初值特解与反常积分)<font color=deeppink>题目[15]:二阶初值特解在负半轴的反常积分</font>**

设 $y=y(x)$ 满足 $y''-2y'+y=0$，且 $y(0)=0, y'(0)=1$，则 $\int_{-\infty}^0 y(x)\,\mathrm{d}x = \underline{\qquad\qquad}$.

答案: $-1$

主要思路:[求出特解后应用分部积分法计算负无穷到0的反常积分]

[1]求微分方程的特解:
特征方程 $r^2 - 2r + 1 = 0$ 有二重根 $r = 1$。
通解为 $y = (C_1 + C_2 x)\mathrm{e}^x$。
由 $y(0) = 0$ 得 $C_1 = 0$。
$y' = C_2(1+x)\mathrm{e}^x$，由 $y'(0) = 1$ 得 $C_2 = 1$。
故特解为 $y(x) = x\mathrm{e}^x$。

[2]计算反常积分:
$$\int_{-\infty}^0 x\mathrm{e}^x\,\mathrm{d}x = \left.(x-1)\mathrm{e}^x\right|_{-\infty}^0$$
上限代入：
$$(0-1)\mathrm{e}^0 = -1$$
下限极限：
$$\lim_{x\to -\infty}(x-1)\mathrm{e}^x = 0$$
因此：
$$\int_{-\infty}^0 y(x)\,\mathrm{d}x = -1 - 0 = -1$$

[2]构造特征多项式:

[3]写出对应的微分方程:
由特征方程 $r^3 - 2r^2 + 5r = 0$，直接对应微分方程：

**(待定系数特解结构)<font color=green>题目[17]:二阶常系数非齐次方程特解形式判断</font>**

微分方程 $4y''-12y'+9y = \mathrm{e}^{\frac{3}{2}x}(3x^2+2)$ 的特解形式为 $(\quad)$.

[A] $Ax^2+Bx+C + D\mathrm{e}^{\frac{3}{2}x}$  
[B] $(Ax^2+Bx+C)\mathrm{e}^{\frac{3}{2}x}$  
[C] $x(Ax^2+Bx+C)\mathrm{e}^{\frac{3}{2}x}$  
[D] $x^2(Ax^2+Bx+C)\mathrm{e}^{\frac{3}{2}x}$

特征方程为：

$$y^* = x^2 (Ax^2 + Bx + C)\mathrm{e}^{\frac{3}{2}x}$$
故选 [D]。

**(非齐次解反求方程)<font color=deeppink>题目[18]:由三个非齐次特解反求二阶非齐次微分方程</font>**

已知 $y_1 = x\mathrm{e}^x + \mathrm{e}^{2x}, y_2 = x\mathrm{e}^x + \mathrm{e}^{-x}, y_3 = x\mathrm{e}^x + \mathrm{e}^{2x} - \mathrm{e}^{-x}$ 是某二阶常系数非齐次线性微分方程的三个解，则此微分方程为 $\underline{\qquad\qquad}$.

答案: $y'' - y' - 2y = (1-2x)\mathrm{e}^x$

主要思路:[做差得到齐次方程的基础解系确定左端系数，再代入非齐次特解确定右端自由项]

[1]求对应齐次方程的基础解系:
两个非齐次特解之差为对应齐次方程的解：
$$\bar{y}_1 = y_1 - y_2 = \mathrm{e}^{2x} - \mathrm{e}^{-x}$$
$$\bar{y}_2 = y_1 - y_3 = \mathrm{e}^{-x}$$
齐次解的线性组合仍为齐次解，故：
$$\bar{y}_1 + \bar{y}_2 = \mathrm{e}^{2x}$$
也是齐次方程的解。因此，$\mathrm{e}^{2x}$ 与 $\mathrm{e}^{-x}$ 是齐次方程的两个线性无关的解。

[2]确定齐次部分特征方程与左端形式:
特征根为 $r_1 = 2, r_2 = -1$。
特征方程为：
$$(r-2)(r+1) = 0 \implies r^2 - r - 2 = 0$$
故方程左端为：
$$y'' - y' - 2y$$

[3]代入非齐次特解确定右端 $f(x)$:
由解的结构可知，$y^* = x\mathrm{e}^x$ 是非齐次方程的一个特解。
求导：
$$(y^*)' = (x+1)\mathrm{e}^x,\quad (y^*)'' = (x+2)\mathrm{e}^x$$
代入左端：
$$f(x) = (y^*)'' - (y^*)' - 2y^* = (x+2)\mathrm{e}^x - (x+1)\mathrm{e}^x - 2x\mathrm{e}^x = (1-2x)\mathrm{e}^x$$
故该微分方程为：
$$y'' - y' - 2y = (1-2x)\mathrm{e}^x$$

**(二阶非齐次多项式指数通解)<font color=deeppink>题目[19]:二阶常系数非齐次微分方程的通解求解</font>**

**(负无穷有界特解)<font color=deeppink>题目[20]:负无穷远处有界特解的待定系数与系数消除</font>**

求微分方程 $y''+4y'+5y = 8\cos x$，当 $x\to -\infty$ 时为有界的特解.

答案: $y = \cos x + \sin x$

主要思路:[待定系数法求三角非齐次特解，根据负无穷极限有界性消除发散的齐次解项]

[1]求齐次方程的通解:
特征方程 $r^2 + 4r + 5 = 0 \implies (r+2)^2 + 1 = 0$，特征根为 $r = -2 \pm \mathrm{i}$。
齐次方程通解为：
$$Y = \mathrm{e}^{-2x}(C_1\cos x + C_2\sin x)$$

[2]求非齐次特解:
设 $y^* = A\cos x + B\sin x$。
求导：
$$(y^*)' = -A\sin x + B\cos x$$
$$(y^*)'' = -A\cos x - B\sin x$$
代入方程：
$$(-A\cos x - B\sin x) + 4(-A\sin x + B\cos x) + 5(A\cos x + B\sin x) = 8\cos x$$
整理系数：
$$(4A + 4B)\cos x + (4B - 4A)\sin x = 8\cos x$$
由待定系数对应相等：
$$\begin{cases} 4A + 4B = 8 \\ 4B - 4A = 0 \end{cases} \implies A = 1,\quad B = 1$$
故非齐次特解为 $y^* = \cos x + \sin x$。

[3]利用有界性确定特解:
原方程的通解为：
$$y = \mathrm{e}^{-2x}(C_1\cos x + C_2\sin x) + \cos x + \sin x$$
当 $x\to -\infty$ 时，$\mathrm{e}^{-2x} \to +\infty$。
由于 $\cos x, \sin x$ 在无穷远处振荡，若 $C_1, C_2$ 不全为 $0$，则 $\mathrm{e}^{-2x}(C_1\cos x + C_2\sin x)$ 必无界。
为使解在 $x\to -\infty$ 时有界，必须且只需：
$$C_1 = 0,\quad C_2 = 0$$
故所求有界特解为：
$$y = \cos x + \sin x$$

**(欧拉方程初值问题)<font color=green>题目[21]:二阶欧拉方程的变量变换与初值特解</font>**

欧拉方程 $x^2 y'' + 3xy' + 3y = 0$ 满足条件 $y(1)=0, y'(1)=\sqrt{2}$ 的解为 $y = \underline{\qquad\qquad}$.

答案: $y = \frac{1}{x}\sin(\sqrt{2}\ln x)$

主要思路:[变量代换 $x = \mathrm{e}^t$ 化为常系数线性方程，代入初值求解]

[1]变量代换化为常系数线性微分方程:
令 $x = \mathrm{e}^t$（$x>0$），则 $t = \ln x$。
记 $D = \frac{\mathrm{d}}{\mathrm{d}t}$，有：
$$xy' = Dy,\quad x^2 y'' = D(D-1)y$$
代入原方程：
$$[D(D-1) + 3D + 3]y = 0 \implies (D^2 + 2D + 3)y = 0 \implies \frac{\mathrm{d}^2 y}{\mathrm{d}t^2} + 2\frac{\mathrm{d}y}{\mathrm{d}t} + 3y = 0$$

[2]求解常系数齐次方程:
特征方程为：
$$r^2 + 2r + 3 = 0 \implies (r+1)^2 + 2 = 0 \implies r = -1 \pm \sqrt{2}\mathrm{i}$$
通解为：
$$y(t) = \mathrm{e}^{-t}[C_1 \cos(\sqrt{2}t) + C_2 \sin(\sqrt{2}t)]$$
代回 $t = \ln x$：
$$y(x) = \frac{1}{x}[C_1 \cos(\sqrt{2}\ln x) + C_2 \sin(\sqrt{2}\ln x)]$$

[3]代入初始条件确定特解:
由 $y(1) = 0$：
$$\frac{1}{1}[C_1 \cos 0 + C_2 \sin 0] = C_1 = 0$$
从而：
$$y(x) = \frac{C_2}{x}\sin(\sqrt{2}\ln x)$$
求导：
$$y'(x) = -\frac{C_2}{x^2}\sin(\sqrt{2}\ln x) + \frac{\sqrt{2}C_2}{x^2}\cos(\sqrt{2}\ln x)$$
代入 $y'(1) = \sqrt{2}$：
$$0 + \sqrt{2}C_2 = \sqrt{2} \implies C_2 = 1$$
故所求特解为：
$$y = \frac{1}{x}\sin(\sqrt{2}\ln x)$$
