### 一、选择题与填空题

**(概念辨析)<font color=red>题目[1]:乘积为无穷大的数列性质与反例辨析</font>**

若 $\{x_n\}, \{y_n\}$ 满足 $\lim\limits_{n\to\infty} x_n y_n = \infty$，则以下结论：

① $\lim\limits_{n\to\infty} x_n = \infty$ 或 $\lim\limits_{n\to\infty} y_n = \infty$；  
② $\lim\limits_{n\to\infty} x_n = \infty$ 且 $\lim\limits_{n\to\infty} y_n = \infty$；  
③ $x_n$ 与 $y_n$ 中一个是无穷大量，另一个是无界量；  
④ 当 $x_n$ 是非零无穷小量时，$\lim\limits_{n\to\infty} y_n = \infty$.  

正确结论的个数为 $(\quad)$.

[A] 1  
[B] 2  
[C] 3  
[D] 4  

答案: [A]

主要思路:[构造振荡无界子列反例否定 ①②③；利用无穷大与无穷小的商的保号性证明 ④]

[1]构造反例否定 ①、②、③:
构造数列:
$$x_n = \begin{cases} n, & n \text{ 为奇数} \\ 1, & n \text{ 为偶数} \end{cases}, \qquad y_n = \begin{cases} 1, & n \text{ 为奇数} \\ n, & n \text{ 为偶数} \end{cases}$$
则对任意正整数 $n$，$x_n y_n = n \to \infty$。
然而，当 $n$ 沿偶数趋于无穷时，$x_n = 1 \ne \infty$；当 $n$ 沿奇数趋于无穷时，$y_n = 1 \ne \infty$。
即 $\{x_n\}$ 与 $\{y_n\}$ 均只是无界变量，都不是无穷大量（无穷大量要求对任意子列均趋于无穷）。
因此 ①、②、③ 均错误。

[2]证明结论 ④:
若 $x_n$ 是非零无穷小量，即 $\lim\limits_{n\to\infty} x_n = 0$ 且 $x_n \ne 0$。
因为 $\lim\limits_{n\to\infty} x_n y_n = \infty$，根据无穷大量定义:
任给 $M > 0$，存在 $N_1$，当 $n > N_1$ 时，$|x_n y_n| > \sqrt{M}$。
由 $\lim\limits_{n\to\infty} x_n = 0$，存在 $N_2$，当 $n > N_2$ 时，$0 < |x_n| < \frac{1}{\sqrt{M}}$。
取 $N = \max\{N_1, N_2\}$，当 $n > N$ 时:
$$|y_n| = \frac{|x_n y_n|}{|x_n|} > \frac{\sqrt{M}}{1/\sqrt{M}} = M$$
由定义可知，$\lim\limits_{n\to\infty} y_n = \infty$。故 ④ 正确。

[3]统计正确结论个数:
仅有 ④ 正确，个数为 1。选 [A]。

**(经典计算)<font color=deeppink>题目[2]:裂项求和与重要极限</font>**

$\lim\limits_{n\to\infty} \left[\frac{1}{2} + \frac{1}{6} + \dots + \frac{1}{n(n+1)}\right]^n = \underline{\qquad\qquad}$.

答案: $\mathrm{e}^{-1}$ (或 $\frac{1}{\mathrm{e}}$)

主要思路:[内层和式利用裂项相消求和为 $1 - \frac{1}{n+1}$，再套用 $1^\infty$ 型数列极限公式]

[1]内层裂项相消求和:
利用分拆公式 $\frac{1}{k(k+1)} = \frac{1}{k} - \frac{1}{k+1}$:
$$S_n = \sum_{k=1}^n \frac{1}{k(k+1)} = \left(1 - \frac{1}{2}\right) + \left(\frac{1}{2} - \frac{1}{3}\right) + \dots + \left(\frac{1}{n} - \frac{1}{n+1}\right) = 1 - \frac{1}{n+1}$$

[2]计算幂指数列极限:
原极限转化为:
$$\lim_{n\to\infty} S_n^n = \lim_{n\to\infty} \left(1 - \frac{1}{n+1}\right)^n$$
此为 $1^\infty$ 型极限，由重要极限 $\lim\limits_{n\to\infty} (1+u_n)^{v_n} = \mathrm{e}^{\lim u_n v_n}$:
$$\lim_{n\to\infty} n \cdot \left(-\frac{1}{n+1}\right) = -1$$
因此:
$$\lim_{n\to\infty} \left(1 - \frac{1}{n+1}\right)^n = \mathrm{e}^{-1} = \frac{1}{\mathrm{e}}$$

**(概念分析)<font color=red>题目[3]:复合指数数列的发散与收敛性</font>**

已知数列 $\{a_n\}$ 发散，$b_n = a_n \mathrm{e}^{a_n}$，则 $(\quad)$.

[A] 当 $a_n > 0$ 时，$\{b_n\}$ 收敛  
[B] 当 $a_n < 0$ 时，$\{b_n\}$ 收敛  
[C] 当 $a_n > 0$ 时，$\{b_n\}$ 发散  
[D] 当 $a_n < 0$ 时，$\{b_n\}$ 发散  

答案: [C]

主要思路:[分析函数 $g(x)=x\mathrm{e}^x$ 在正半轴上的严格单调性与反函数连续性，结合负半轴极值与趋近性质举反例]

[1]分析函数 $g(x) = x\mathrm{e}^x$ 的单调性:
求导得 $g'(x) = (x+1)\mathrm{e}^x$。
当 $x > 0$ 时，$g'(x) > 0$，故 $g(x)$ 在 $(0, +\infty)$ 上严格单调递增，且 $g((0, +\infty)) = (0, +\infty)$。
因此 $g(x)$ 在正半轴上存在严格单调连续的反函数 $g^{-1}(y)$。

[2]证明当 $a_n > 0$ 时 $\{b_n\}$ 必发散:
假设 $\{b_n\}$ 收敛，设 $\lim\limits_{n\to\infty} b_n = B$。
由于 $a_n > 0$，必有 $b_n > 0$，故 $B \geqslant 0$。
若 $B > 0$，由反函数连续性，$\lim\limits_{n\to\infty} a_n = \lim\limits_{n\to\infty} g^{-1}(b_n) = g^{-1}(B)$ 存在，与 $\{a_n\}$ 发散矛盾；
若 $B = 0$，由 $\lim\limits_{y\to 0^+} g^{-1}(y) = 0$ 可得 $\lim\limits_{n\to\infty} a_n = 0$，同样与 $\{a_n\}$ 发散矛盾。
因此假设不成立，当 $a_n > 0$ 时，$\{b_n\}$ 必然发散。选 [C]。

[3]举反例说明负半轴情况:
若 $a_n < 0$，取 $a_n = -n$（发散数列）。
此时 $b_n = -n \mathrm{e}^{-n} = -\frac{n}{\mathrm{e}^n} \to 0$（收敛）。
故当 $a_n < 0$ 时，$\{b_n\}$ 可以收敛，也可以发散（如 $a_n = (-1)^n$），因此 [B] 和 [D] 均不正确。

**(经典计算)<font color=deeppink>题目[4]:变限积分与点火公式(Wallis)极限</font>**

设 $a_n = \int_0^1 x^n \sqrt{1-x^2}\,\mathrm{d}x$，$b_n = \int_0^{\frac{\pi}{2}} \sin^n t\,\mathrm{d}t$，则极限 $\lim\limits_{n\to\infty} \left[\frac{(n+1)a_n}{b_n}\right]^n = (\quad)$.

[A] 0  
[B] $\mathrm{e}$  
[C] $\mathrm{e}^{-1}$  
[D] $+\infty$  

答案: [C]

主要思路:[作三角代换 $x=\sin t$ 将 $a_n$ 转化为点火公式，利用递推关系得出 $\frac{a_n}{b_n} = \frac{1}{n+2}$，代入求极限]

[1]三角代换转化 $a_n$:
令 $x = \sin t$，则 $\mathrm{d}x = \cos t\,\mathrm{d}t$，$t \in [0, \frac{\pi}{2}]$:
$$a_n = \int_0^{\frac{\pi}{2}} \sin^n t \sqrt{1-\sin^2 t} \cos t\,\mathrm{d}t = \int_0^{\frac{\pi}{2}} \sin^n t \cos^2 t\,\mathrm{d}t$$
利用 $\cos^2 t = 1 - \sin^2 t$:
$$a_n = \int_0^{\frac{\pi}{2}} \sin^n t\,\mathrm{d}t - \int_0^{\frac{\pi}{2}} \sin^{n+2} t\,\mathrm{d}t = b_n - b_{n+2}$$

[2]利用点火公式递推关系化简:
根据华里士 (Wallis) 递推公式:
$$b_{n+2} = \frac{n+1}{n+2} b_n$$
代入 $a_n$:
$$a_n = b_n - \frac{n+1}{n+2} b_n = \frac{1}{n+2} b_n$$
由此可得:
$$\frac{(n+1)a_n}{b_n} = \frac{(n+1)\cdot \frac{1}{n+2}b_n}{b_n} = \frac{n+1}{n+2} = 1 - \frac{1}{n+2}$$

[3]计算目标极限:
$$\lim_{n\to\infty} \left[\frac{(n+1)a_n}{b_n}\right]^n = \lim_{n\to\infty} \left(1 - \frac{1}{n+2}\right)^n = \mathrm{e}^{\lim\limits_{n\to\infty} n\left(-\frac{1}{n+2}\right)} = \mathrm{e}^{-1}$$
选 [C]。

### 二、解答题

**(单调有界)<font color=red>题目[5]:分式递推数列收敛性证明与不动点极限</font>**

设 $0\leqslant x_1 \leqslant \sqrt{c}$，$x_{n+1} = \frac{c(1+x_n)}{c+x_n}, n\in \mathbb{N}_+, c>1$. 证明数列 $\{x_n\}$ 收敛，并求其极限值.

答案: 证明见步骤；极限值为 $\sqrt{c}$

主要思路:[分析递推生成函数 $f(x)$ 的单调性，利用数学归纳法证明有界性与单调性，通过不动点方程求极限]

[1]分析生成函数的单调性:
令 $f(x) = \frac{c(1+x)}{c+x} = 1 + \frac{c-1}{c+x}$（$x \geqslant 0$）。
求导得:
$$f'(x) = -\frac{c-1}{(c+x)^2}$$
由于 $c > 1$，所以 $c - 1 > 0$，故 $f'(x) < 0$？等等，注意分式拆分:
$$f(x) = \frac{c(x+c) + c(1-c)}{c+x} = c + \frac{c(1-c)}{c+x}$$
求导:
$$f'(x) = -\frac{c(1-c)}{(c+x)^2} = \frac{c(c-1)}{(c+x)^2} > 0$$
因此 $f(x)$ 在 $[0, +\infty)$ 上严格单调递增！

[2]数学归纳法证明有界性与单调性:
考察不动点方程 $x = f(x)$:
$$x = \frac{c(1+x)}{c+x} \implies x(c+x) = c(1+x) \implies x^2 = c \implies x = \sqrt{c} \quad (x\geqslant 0)$$
- 若 $x_1 = \sqrt{c}$，则对所有 $n$ 恒有 $x_n = \sqrt{c}$，极限为 $\sqrt{c}$。
- 若 $0 \leqslant x_1 < \sqrt{c}$:
  - 有界性: 由 $f(x)$ 递增，$x_2 = f(x_1) < f(\sqrt{c}) = \sqrt{c}$，且 $x_2 \geqslant f(0) = 1 > 0$。由归纳法可知对一切 $n\in\mathbb{N}_+$，都有 $0 \leqslant x_n < \sqrt{c}$。
  - 单调性: 考察相邻项差:
    $$x_{n+1} - x_n = \frac{c(1+x_n) - x_n(c+x_n)}{c+x_n} = \frac{c - x_n^2}{c+x_n}$$
    由于 $0 \leqslant x_n < \sqrt{c}$，分子 $c - x_n^2 > 0$，分母 $c+x_n > 0$。
    故 $x_{n+1} - x_n > 0$，即数列 $\{x_n\}$ 严格单调递增。

[3]由单调有界准则求极限:
由单调有界准则，$\lim\limits_{n\to\infty} x_n = L$ 存在。
在递推式两边取极限:
$$L = \frac{c(1+L)}{c+L} \implies L^2 = c$$
因为 $x_n \geqslant 0$，故 $L = \sqrt{c}$。
综上，数列 $\{x_n\}$ 收敛，且 $\lim\limits_{n\to\infty} x_n = \sqrt{c}$。

**(经典计算)<font color=deeppink>题目[6]:指数递推数列的倒数差极限</font>**

设 $x_1 < 0$，$x_{n+1} = \mathrm{e}^{x_n} - 1$，求 $\lim\limits_{n\to\infty} \left(\frac{1}{x_n} - \frac{1}{x_{n+1}}\right)$.

答案: $\frac{1}{2}$

主要思路:[先由单调有界性证明 $x_n \to 0$，再将倒数差通分后利用泰勒展开求极限]

[1]证明数列 $\{x_n\}$ 的收敛性与极限值:
当 $x < 0$ 时，$\mathrm{e}^x - 1 < 0$，故由 $x_1 < 0$ 可归纳得出对所有 $n$ 均有 $x_n < 0$。
又由常用不等式 $\mathrm{e}^x - 1 > x$ ($x \ne 0$) 可知:
$$x_{n+1} = \mathrm{e}^{x_n} - 1 > x_n$$
因此数列 $\{x_n\}$ 严格单调递增且有上界 0。
由单调有界准则，极限 $\lim\limits_{n\to\infty} x_n = L$ 存在。
两边取极限: $L = \mathrm{e}^L - 1 \implies L = 0$。
即 $\lim\limits_{n\to\infty} x_n = 0$。

[2]通分并利用泰勒展开计算极限:
$$\frac{1}{x_n} - \frac{1}{x_{n+1}} = \frac{1}{x_n} - \frac{1}{\mathrm{e}^{x_n} - 1} = \frac{\mathrm{e}^{x_n} - 1 - x_n}{x_n(\mathrm{e}^{x_n} - 1)}$$
当 $n\to\infty$ 时，$x_n \to 0$。
分母等价无穷小: $x_n(\mathrm{e}^{x_n}-1) \sim x_n^2$。
分子麦克劳林展开:
$$\mathrm{e}^{x_n} - 1 - x_n = \frac{1}{2}x_n^2 + o(x_n^2)$$

[3]代入求得极限值:
$$\lim_{n\to\infty} \left(\frac{1}{x_n} - \frac{1}{x_{n+1}}\right) = \lim_{x_n\to 0} \frac{\frac{1}{2}x_n^2 + o(x_n^2)}{x_n^2} = \frac{1}{2}$$

**(综合证明)<font color=red>题目[7]:三角递推数列的敛散性与二阶极限比值</font>**

设数列 $\{x_n\}$ 满足 $0 < x_n < \frac{\pi}{2}$，$\cos x_{n+1} - x_{n+1} = \cos x_n, n=1,2,\dots$.

(1) 证明 $\lim\limits_{n\to\infty} x_n$ 存在并求其值；  
(2) 计算 $\lim\limits_{n\to\infty} \frac{x_{n+1}}{x_n^2}$.

答案: (1) 存在且极限为 0；(2) $\frac{1}{2}$

主要思路:[(1) 引入辅助函数 $g(x)=\cos x - x$，利用其单调减性证明 $x_{n+1} < x_n$；(2) 移项利用余弦泰勒展开求解]

[1]第 (1) 问: 证明极限存在并求值:
令辅助函数 $g(x) = \cos x - x$。
在区间 $(0, \frac{\pi}{2})$ 上:
$$g'(x) = -\sin x - 1 < 0$$
故 $g(x)$ 在该区间上严格单调递减。
已知递推关系为:
$$g(x_{n+1}) = \cos x_{n+1} - x_{n+1} = \cos x_n$$
因为 $x_n \in (0, \frac{\pi}{2})$，所以:
$$g(x_n) = \cos x_n - x_n < \cos x_n = g(x_{n+1})$$
由 $g(x)$ 的严格单调递减性，必有:
$$x_{n+1} < x_n$$
又由题设 $x_n > 0$，故数列 $\{x_n\}$ 单调递减且有下界 0。
由单调有界定理，极限 $\lim\limits_{n\to\infty} x_n = L$ 存在，且 $0 \leqslant L < \frac{\pi}{2}$。
在递推式两边取极限:
$$\cos L - L = \cos L \implies L = 0$$
故 $\lim\limits_{n\to\infty} x_n = 0$。

[2]第 (2) 问: 计算极限 $\lim\limits_{n\to\infty}\frac{x_{n+1}}{x_n^2}$:
将已知递推式移项整理:
$$x_{n+1} = \cos x_{n+1} - \cos x_n$$
由泰勒公式，当 $x\to 0$ 时，$\cos x = 1 - \frac{1}{2}x^2 + o(x^2)$。
代入得:
$$x_{n+1} = \left(1 - \frac{1}{2}x_{n+1}^2 + o(x_{n+1}^2)\right) - \left(1 - \frac{1}{2}x_n^2 + o(x_n^2)\right) = \frac{1}{2}x_n^2 - \frac{1}{2}x_{n+1}^2 + o(x_n^2) + o(x_{n+1}^2)$$
两边同除以 $x_n^2$:
$$\frac{x_{n+1}}{x_n^2} = \frac{1}{2} - \frac{1}{2}\left(\frac{x_{n+1}}{x_n}\right)^2 + o(1)$$
因为 $0 < x_{n+1} < x_n$，所以 $0 < \frac{x_{n+1}}{x_n} < 1$，进而 $x_{n+1} = O(x_n^2)$，故 $\frac{x_{n+1}}{x_n} \to 0$。
因此:
$$\lim_{n\to\infty} \frac{x_{n+1}}{x_n^2} = \frac{1}{2}$$

**(综合证明)<font color=red>题目[8]:正切递推数列的收敛性与交叉倒数差极限</font>**

已知数列 $\{x_n\}$ 满足 $0 < x_1 < \frac{\pi}{4}$，$x_{n+1} + \tan x_n = 2x_n, n=1,2,\dots$.

(1) 证明 $\lim\limits_{n\to\infty} x_n$ 存在并求其值；  
(2) 求极限 $\lim\limits_{n\to\infty} \left(\frac{1}{x_n^2} - \frac{1}{x_n x_{n+1}}\right)$.

答案: (1) 存在且极限为 0；(2) $-\frac{1}{3}$

主要思路:[(1) 利用函数 $f(x)=2x-\tan x$ 的增减性与 $x<\tan x$ 证明单调有界；(2) 通分后利用 $x-\tan x \sim -\frac{1}{3}x^3$ 求解]

[1]第 (1) 问: 证明极限存在并求值:
递推关系可写为:
$$x_{n+1} = 2x_n - \tan x_n$$
令 $f(x) = 2x - \tan x$。当 $x \in (0, \frac{\pi}{4})$ 时:
$$f'(x) = 2 - \sec^2 x = 1 - \tan^2 x > 0$$
故 $f(x)$ 在 $(0, \frac{\pi}{4})$ 上严格单调递增。
因为 $f(0) = 0$，故当 $x > 0$ 时 $f(x) > 0$。
又当 $x \in (0, \frac{\pi}{4})$ 时，$\tan x > x$，所以:
$$f(x) = 2x - \tan x < 2x - x = x$$
因此:
$$0 < x_{n+1} < x_n < \frac{\pi}{4}$$
数列 $\{x_n\}$ 单调递减且有下界 0。
由单调有界准则，极限 $\lim\limits_{n\to\infty} x_n = L$ 存在。
两端取极限:
$$L = 2L - \tan L \implies \tan L = L \implies L = 0$$
故 $\lim\limits_{n\to\infty} x_n = 0$。

[2]第 (2) 问: 计算极限 $\lim\limits_{n\to\infty} \left(\frac{1}{x_n^2} - \frac{1}{x_n x_{n+1}}\right)$:
通分代数式:
$$\frac{1}{x_n^2} - \frac{1}{x_n x_{n+1}} = \frac{x_{n+1} - x_n}{x_n^2 x_{n+1}}$$
由递推式 $x_{n+1} - x_n = x_n - \tan x_n$，代入得:
$$\frac{x_n - \tan x_n}{x_n^2 x_{n+1}} = \frac{x_n - \tan x_n}{x_n^3} \cdot \frac{x_n}{x_{n+1}}$$

[3]分别计算各因子极限:
由正切麦克劳林展开式 $\tan x = x + \frac{1}{3}x^3 + o(x^3)$:
$$\lim_{x_n\to 0} \frac{x_n - \tan x_n}{x_n^3} = -\frac{1}{3}$$
又因为 $x_{n+1} = 2x_n - \tan x_n = x_n - \frac{1}{3}x_n^3 + o(x_n^3) \sim x_n$，所以:
$$\lim_{n\to\infty} \frac{x_n}{x_{n+1}} = 1$$
因此:
$$\lim_{n\to\infty} \left(\frac{1}{x_n^2} - \frac{1}{x_n x_{n+1}}\right) = \left(-\frac{1}{3}\right) \times 1 = -\frac{1}{3}$$

**(经典计算)<font color=deeppink>题目[9]:对数反常积分与幂指数列极限</font>**

已知 $a_n = \int_0^1 t^n |\ln t|\,\mathrm{d}t, n=1,2,\dots$，计算 $\lim\limits_{n\to\infty} (n^2 a_n)^n$.

答案: $\mathrm{e}^{-2}$ (或 $\frac{1}{\mathrm{e}^2}$)

主要思路:[分部积分法去掉对数求得 $a_n = \frac{1}{(n+1)^2}$，再计算 $1^\infty$ 型极限]

[1]计算定积分 $a_n$:
当 $t \in (0, 1]$ 时，$\ln t \leqslant 0$，故 $|\ln t| = -\ln t$。
$$a_n = -\int_0^1 t^n \ln t\,\mathrm{d}t$$
应用分部积分法:
$$a_n = -\frac{1}{n+1}\int_0^1 \ln t\,\mathrm{d}(t^{n+1}) = -\frac{1}{n+1}\left(\left. t^{n+1}\ln t \right|_0^1 - \int_0^1 t^{n+1}\cdot \frac{1}{t}\,\mathrm{d}t\right)$$
由于 $\lim\limits_{t\to 0^+} t^{n+1}\ln t = 0$，首项为 0:
$$a_n = \frac{1}{n+1}\int_0^1 t^n\,\mathrm{d}t = \frac{1}{(n+1)^2}$$

[2]化简底数并求极限:
$$n^2 a_n = \frac{n^2}{(n+1)^2} = \left(\frac{n}{n+1}\right)^2 = \left(1 - \frac{1}{n+1}\right)^2$$
代入幂指结构:
$$(n^2 a_n)^n = \left(1 - \frac{1}{n+1}\right)^{2n}$$
由重要极限公式:
$$\lim_{n\to\infty} (n^2 a_n)^n = \mathrm{e}^{\lim\limits_{n\to\infty} 2n\left(-\frac{1}{n+1}\right)} = \mathrm{e}^{-2} = \frac{1}{\mathrm{e}^2}$$

**(经典计算)<font color=deeppink>题目[10]:有理反常积分与点火公式极限</font>**

设数列 $\{a_n\}$ 的通项 $a_n = \int_0^{+\infty} \frac{\mathrm{d}x}{(1+x^2)^n}, n=2,3,\dots$，计算 $\lim\limits_{n\to\infty} \left(\frac{a_{n+1}}{a_n}\right)^{\ln(1+\mathrm{e}^{2n})}$.

答案: $\mathrm{e}^{-1}$ (或 $\frac{1}{\mathrm{e}}$)

主要思路:[三角代换将反常积分转化为点火公式，求得比值 $\frac{a_{n+1}}{a_n} = \frac{2n-1}{2n}$，结合指数化简求极限]

[1]三角代换计算积分 $a_n$:
令 $x = \tan\theta$，则 $\mathrm{d}x = \sec^2\theta\,\mathrm{d}\theta$，$1+x^2 = \sec^2\theta$，$\theta \in [0, \frac{\pi}{2})$:
$$a_n = \int_0^{\frac{\pi}{2}} \frac{\sec^2\theta}{\sec^{2n}\theta}\,\mathrm{d}\theta = \int_0^{\frac{\pi}{2}} \cos^{2n-2}\theta\,\mathrm{d}\theta$$

[2]利用华里士公式求比值:
根据华里士公式递推关系:
$$\frac{a_{n+1}}{a_n} = \frac{\int_0^{\frac{\pi}{2}} \cos^{2n}\theta\,\mathrm{d}\theta}{\int_0^{\frac{\pi}{2}} \cos^{2n-2}\theta\,\mathrm{d}\theta} = \frac{2n-1}{2n} = 1 - \frac{1}{2n}$$

[3]化简指数并计算极限:
考察指数部分:
$$\ln(1+\mathrm{e}^{2n}) = \ln\left[\mathrm{e}^{2n}(1+\mathrm{e}^{-2n})\right] = 2n + \ln(1+\mathrm{e}^{-2n}) = 2n + o(1)$$
因此:
$$\lim_{n\to\infty} \left(\frac{a_{n+1}}{a_n}\right)^{\ln(1+\mathrm{e}^{2n})} = \lim_{n\to\infty} \left(1 - \frac{1}{2n}\right)^{2n + o(1)} = \mathrm{e}^{-1} = \frac{1}{\mathrm{e}}$$

**(微分中值证明)<font color=red>题目[11]:拉格朗日中值定理与压缩映射高阶无穷小证明</font>**

已知 $f(x)$ 可导，且 $|f'(x)|\leqslant \frac{1}{\mathrm{e}}$，方程 $f(x)=x$ 有唯一解 $x=0$，又 $x_{n+1}=f(x_n)\ne 0, n=1,2,\dots$.

证明：当 $n\to\infty$ 时，$x_n$ 是 $\mathrm{e}^{-\frac{n}{2}}$ 的高阶无穷小.

答案: 证明见步骤

主要思路:[由拉格朗日中值定理建立压缩不等式 $|x_{n+1}| \leqslant \frac{1}{\mathrm{e}}|x_n|$，归纳得出 $|x_n| \leqslant M \mathrm{e}^{-n}$，与 $\mathrm{e}^{-n/2}$ 相比后用夹逼定理证明]

[1]应用拉格朗日中值定理建立递推不等式:
因为方程 $f(x) = x$ 有唯一解 $x = 0$，所以 $f(0) = 0$。
对区间 $[0, x_n]$（或 $[x_n, 0]$）上的函数 $f(x)$ 应用拉格朗日中值定理:
$$x_{n+1} = f(x_n) = f(x_n) - f(0) = f'(\xi_n)(x_n - 0) = f'(\xi_n) x_n$$
其中 $\xi_n$ 介于 0 与 $x_n$ 之间。
由题设 $|f'(x)| \leqslant \frac{1}{\mathrm{e}}$:
$$|x_{n+1}| = |f'(\xi_n)| \cdot |x_n| \leqslant \frac{1}{\mathrm{e}} |x_n|$$

[2]归纳导出通项控制式:
由上式递推:
$$|x_n| \leqslant \frac{1}{\mathrm{e}} |x_{n-1}| \leqslant \left(\frac{1}{\mathrm{e}}\right)^2 |x_{n-2}| \leqslant \dots \leqslant \left(\frac{1}{\mathrm{e}}\right)^{n-1} |x_1| = \mathrm{e} |x_1| \mathrm{e}^{-n}$$
令常数 $M = \mathrm{e} |x_1| > 0$，则对任意正整数 $n$:
$$|x_n| \leqslant M \mathrm{e}^{-n}$$

[3]利用夹逼准则证明高阶无穷小:
考察比值 $\frac{x_n}{\mathrm{e}^{-\frac{n}{2}}}$ 的极限:
$$0 \leqslant \left|\frac{x_n}{\mathrm{e}^{-\frac{n}{2}}}\right| = \frac{|x_n|}{\mathrm{e}^{-\frac{n}{2}}} \leqslant \frac{M \mathrm{e}^{-n}}{\mathrm{e}^{-\frac{n}{2}}} = M \mathrm{e}^{-\frac{n}{2}}$$
因为当 $n\to\infty$ 时，$\lim\limits_{n\to\infty} M \mathrm{e}^{-\frac{n}{2}} = 0$。
由夹逼定理:
$$\lim_{n\to\infty} \frac{x_n}{\mathrm{e}^{-\frac{n}{2}}} = 0$$
根据高阶无穷小的定义，当 $n\to\infty$ 时，$x_n$ 是 $\mathrm{e}^{-\frac{n}{2}}$ 的高阶无穷小，即 $x_n = o\left(\mathrm{e}^{-\frac{n}{2}}\right)$。
命题得证。
