# Chap2.3 浮点数的表示与运算

## 1.浮点数表示法

思想:源自于科学计数法($1200=1.2\times 10^3$),只要是非0,二进制的最高位必然是1,通过阶码来移动小数点

浮点数表示法:将比例因子嵌入数据中,使得小数点位置根据需要浮动:

```math
N = (-1)^S \times M \times R^E
```

S(Sign):	    浮点数的符号	[0或1]

M(Mantissa):	非负的定点小数(尾数,**使用原码表示**)

E(Exponent):	定点整数(阶码/指数)  {}

R(Radix):	   基数		[通常约定为2,4,8]

```
IBM 360/370系列:[符号1位][阶码7位][尾数24位]		基数:16	移码Bias=64
IEEE 754系列:	  [符号1位][阶码8位][尾数23位]		基数:2    移码Bias=127
```

## 2.IEEE754 浮点数

IEE754浮点数(32位):[符号1位]\[阶码8位]\[尾数23位]  (float,$E=e+Bias=e+127$)   $(-1)^s\times 1.f\times2^{e-127}$

IEE754浮点数(64位):[符号1位]\[阶码11位]\[尾数52位] (double,$E=e+Bias=e+1023$)  $(-1)^s\times 1.f\times2^{e-1023}$

规格化的二进制浮点数的[阶码]:float中e的取值是(1\~254),double中e的取值是(1\~2048)    **[全0全1表示特殊值]**

规格化的二进制浮点数的[尾数]:尾数的最高位恒为1(隐藏位),隐含在小数点之前

>   对于32位小数,23位的尾数其实有效位为24位
>
>   对于64位小数,52位的尾数其实有效位为53位

Eg:$$(12)_{10}=(1100)_2$$,规格化为$1.1\times 2^3$,原理如下

>   (1)规格化:$(1100)_2 = (1.1\times10^3)_2$$\rightarrow$去掉最高位的1=$0.1\times 10^3$
>
>   (2)偏移量:$$E = e + \text{Bias} = 3 + 127 = 130 = (1000\ 0010)_2$$
>
>   (3)写规格化数:
>
>   ​	{1:不实际存储}.[0]       \[1000 0010]   \[$$M = 100\ 0000\ 0000\ 0000\ 0000\ 0000_2$$]      
>
>   ​		      \[符号1位]  \[阶码8位]     \[尾数23位]	
>
>       		最终答案:│0│10000010│10000000000000000000000
>       		十六进制:0100 0001 0100 0000 0000 0000 0000 0000
>       			0x    4   1	    4	 0	  0    0    0    0
>   ***
>
>   反向操作:
>
>   (1)提取符号:S=0,(-1)^0^=+1
>
>   (2)还原偏移:(1000 0010)=130,130-127=3
>
>   (3)移动真数:(1.10000000000000000000000)移动三位(1100.0)=12

## 3.IEEE754浮点数的溢出

IEE754浮点数(32位):[符号1位]\[阶码8位]\[尾数23位]  (float,$E=e+Bias=e+127$)   $(-1)^s\times 1.f\times2^{e-127}$

>最大正数值:[符号位:0]\[阶码:E=254,e=254-127=127][尾数M:全部为1,共23位]:$+(2-2^{23})\times 2^{127}$
>
>最小负数值:[符号位:1]\[阶码:E=254,e=254-127=127][尾数M:全部为1,共23位]:$-(2-2^{23})\times 2^{127}$
>
>最小正数值:[符号位:0]\[阶码:E=1,e=1-127=-126][尾数M:全部为0,共23位]:$$+1.0 \times 2^{-126}$$
>
>最大负数值:[符号位:1]\[阶码:E=1,e=1-127=-126][尾数M:全部为0,共23位]:$$-1.0 \times 2^{-126}$$

IEE754浮点数(64位):[符号1位]\[阶码11位]\[尾数52位] (double,$E=e+Bias=e+1023$)  $(-1)^s\times 1.f\times2^{e-1023}$

>最大正数值:[符号位:0]\[阶码:E=2046,e=2046-1023=1023][尾数M:全部为1,共52位]:$$+(2 - 2^{-52}) \times 2^{1023}$$
>
>最小负数值:[符号位:1]\[阶码:E=2046,e=2046-1023=1023][尾数M:全部为1,共52位]:$$-(2 - 2^{-52}) \times 2^{1023}$$
>
>最小正数值:[符号位:0]\[阶码:E=1,e=1-1023=-1022][尾数M:全部为0,共52位]:$$+1.0 \times 2^{-1022}$$
>
>最大负数值:[符号位:1]\[阶码:E=1,e=1-1023=-1022][尾数M:全部为0,共52位]:$$-1.0 \times 2^{-1022}$$
