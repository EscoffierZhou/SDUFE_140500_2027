# Chap 4.1 串的定义和实现

## 1.串的定义

定义:串是由**零个**或多个字符组成的**有限序列**

>   ```math
>   S= 'a_1a_2\cdots a_n'
>   ```
>
>   其中S是串名,每个$a_i$可以是字母/数字/其它字符,n称为串的长度,n=0为空串

**串和字串:串中多个连续字符组成的子序列是该串的子串,包含字串的称为主串**

>   字符在串中的位置:某个字符在串中的序号
>
>   字串在主串的位置:字串第一个字符在主串的位置
>
>   串相等:两个串的长度相同,且对应位置上的字符完全相同
>
>   注:空格是一种特殊字符,空格串不是空串,长度等于空格的个数

## 2.串的基本操作

```C++
StrAssign(&T,chars):		// 赋值操作:将串T赋值为chars
StrCopy(&T,S):				// 复制操作:将串S复制给T
StrEmpty(S);				// 判空操作
StrCompare(S,T):			// 比较操作:比较S和T的长度,返回值>0/=0/<0
StrLength(S):				// 返回串长:S中字符的个数
SubString(&Sub,S,pos,len):  // 返回子串:用Sub 返回S从第pos个字符起,长度为len的子串
Concat(&T,S1,S2):			// 联接操作:用T   返回S1和S2联接的新串
Index(S,T):					// 定位操作:返回在S中首次出现T的位置,否则返回0
ClearString(&S):			// 清空操作:将串S置为空串
DestroyString(&S):			// 销毁操作:将串S销毁
```
