# Chap 3.4 数组和特殊矩阵

## 1.数组的定义

定义:数组是由n个**相同类型**的数据元素组成的有限序列

(每个元素称为数组元素,其在序列中的位置由**下标**标识,下标的取值范围称为**维界**)

**<font color=red>数组一旦定义,其维数和维界即固定不变->仅支持存取元素和修改元素</font>**

>   一维数组:一个线性表
>
>   二维数组:元素为定长一维数组的线性表

## 2.数组的存储结构

**逻辑上的数组通常映射为内存中一段连续的存储空间**

>   一维数组:	 元素$A[i]$的地址为:	$LOC(a_i) = LOC(a_0)+iL(0\leq i <n)$
>
>   二维数组(按行优先):元素$A[i][j]$的地址为:     $LOC(a_{i,j}) = LOC(a_{0,0})+[i(h_2+1)+j]L$
>
>   二维数组(按列优先):元素$A[i][j]$的地址为:     $LOC(a_{i,j}) = LOC(a_{0,0})+[j(h_2+1)+i]L$ 

```math
A_{[2][3]} = \begin{bmatrix}a_{[0][0]}&a_{[0][1]}&a_{[0][2]}\\a_{[1][0]}&a_{[1][1]}&a_{[1][2]}\end{bmatrix}
\begin{cases}
\text{按行优先}:[a_{[0][0]}a_{[0][1]}a_{[0][2]}],[a_{[1][0]}a_{[1][1]}a_{[1][2]}]
\\\\
\text{按行优先}:[a_{[0][0]}a_{[1][0]}],[a_{[0][1]}a_{[1][1]}],[a_{[0][2]}a_{[1][2]}]
\end{cases}
```

## 3.特殊矩阵的压缩存储

**压缩存储**:把多个值相同的元素只分配一个存储空间,对零元素不分配空间

**特殊矩阵**:具有大量相同元素或零元素,且这些元素分布具有规律性的矩阵(对称矩阵/三角矩阵/对角矩阵)

**特殊矩阵的压缩存储**:分析相同元素的分布规律,存储一份数据,其余可以通过下标映射访问,将冗余的数据压缩到一个共享的空间

###### **1.对称矩阵**

**特点:n阶矩阵A中任意元素$a_{i,j}$均满足$a_{i,j} = a_{j,i}$(上三角区-主对角线-下三角区)**

**优化方式:存储个数:$n(n+1)/2$:主对角线-下三角区的元素即可(放入一维数组B中)**

**考点:矩阵元素在一维数组的次序k和在数组B的下标ij的关系**

(1)前i-1行的元素总数:$S = \frac{[1+(i-1)(i-1)]}{2} = \frac{i(i-1)}{2}$

(2)第i行在$a_{i,j}$前面的个数:$j-1$

(3)两者组合:$\frac{i(i-1)}{2}+j-1$

```math
k = \begin{cases}
\frac{i(i-1)}{2}+j-1,&i\geq j &(主对角线和下三角元素^*)
\\ \\
\frac{j(j-1)}{2}+i-1,&i<j&(上三角元素)
\end{cases}
```

###### **2.三角矩阵**

**特点:矩阵中下三角矩阵是有效元素,上三角矩阵都是同一常量**

**优化方式:存储个数:$n(n+1)/2+1$:主对角线-下三角区-1个常量的元素**

**考点:矩阵元素在一维数组的次序k和在数组B的下标ij的关系**

>==**a.保留下三角矩阵(正向考虑:1,2,...,i-1,<font color=deeppink>(共i-1项)</font>[j-1])**==
>
>(1)前i-1行的元素总数:$S = \frac{(1+(i-1))(i-1)}{2} = \frac{i(i-1)}{2}$
>
>(2)第i行在$a_{i,j}$前面的个数:$j-1$
>
>(3)两者组合:$\frac{i(i-1)}{2}+j-1$
>
>```math
>k = \begin{cases}
>\frac{i(i-1)}{2}+j-1,&i\geq j &(主对角线和下三角元素^*)
>\\ \\
>\frac{n(n+1)}{2}&&(上三角元素)
>\end{cases}
>```
>
>==**b.保留上三角矩阵(逆向考虑:n,n-1,...,n-i+2,<font color=deeppink>(共i-1项)</font>[j-i])**==
>
>(1)第i行的元素总数:$n-i+1$;第i-1行的元素总数:$n-(i-1)+1=n-i+2$
>
>(2)前i-1行的元素总数:$S=\frac{(n+(n-i+2))\times(i-1)}{2} = \frac{(2n-i+2)(i-1)}{2}$
>
>(3)第i行在$a_{i,j}$前面的个数:$j-i$
>
>(4)两者组合:$\frac{(2n-i+2)(i-1)}{2}+j-i$
>
>```math
>k = \begin{cases}
>\frac{(2n-i+2)(i-1)}{2}+j-i,&i\geq j &(主对角线和下三角元素^*)
>\\ \\
>\frac{n(n+1)}{2}&&(下三角元素)
>\end{cases}
>```

###### **3.三对角矩阵**

若n阶矩阵A的任意元素$a_{i,j}$,非零元素仅集中在以主对角线为中心的3条对角线的区域

```math
\begin{bmatrix}
a_{1,1}&a_{1,2}&&&
\\
a_{2,1}&a_{2,1}&a_{2,3}&&
\\
&a_{3,2}&a_{3,3}&a_{3,4}&
\\
&&a_{n-1,n-2}&a_{n-1,n-1}&a_{n-1,n}
\\
&\qquad&\ddots&\ddots&\ddots
\\ 
&&&a_{n,n-1}&a_{n,n}
\end{bmatrix}\text{(按行存取)}
```

**特点:除了第一行和最后一行是2个元素,其余每行都有3个元素**

(1)第i-1行的总元素个数:$2+3\times(i-2)=3i-4$

(2)第i行中$a_{i,j}$相对于第一个元素的偏移量:$j-i+1$

(3)两者组合:$3i-4+(j-i+1) = 2i+j-3$

**反过来由k推导i和j**

(1)锁定列号:`j=i-1`,`j=i`,`j=i+1`带入公式:$k_{min} = 3i-4,k_{max}=3i-2$

(2)求不等式:$3i-4\leq k \leq 3i-2\rightarrow i\leq \frac{k+4}{3}$

(3)求出行号:$j=k-2i+3$

###### **4.稀疏矩阵**

**特点:矩阵中非零元素的个数t相对于总元素个数s来说非常少**

**优化方法:除了记录值,还需要记录其行和列$\rightarrow$三元组$(i,j,a_{ij})$**

>   实现方式(1):存储在一维数组中,插入删除操作效率极低
>
>   实现方式(2):存储在十字链表中(`*right`,`*down`)
>
>   ```C++
>   struct Orthogonal{
>     int row;			// 矩阵总行数
>     int col;			// 矩阵总列数
>     ElemType value;
>     Orthogonal* right; // 贯穿该行的链表指针(行表)
>     Orthogonal* down;  // 贯穿该列的链表指针(列表)
>     Orthogonal(int r,int c,int v):
>       		row(r),col(c),value(v),right(nullptr),down(nullptr){}
>   };
>   ```

**<font color=deeppink>对于稀疏矩阵,注意的是稀疏数据的个数:一般全存,存三角的算法难度很高</font>**
