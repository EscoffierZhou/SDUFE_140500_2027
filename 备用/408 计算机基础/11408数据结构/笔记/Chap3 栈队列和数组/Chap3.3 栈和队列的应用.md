# Chap3.3 栈和队列的应用

## 1.栈在括号匹配中的应用

原理:读入类型A的括号以后,如果中途读入类型B,则期望变为类型B的右半边

(1)初始化一个空栈,顺序扫描输入括号序列

(2)遇到左括号,压栈,新增一个优先级最高的期待

(3a)遇到右括号,栈非空 且 和栈顶元素匹配,则出栈

(3b)遇到右括号,栈空 或 出现非法右括号,则算法终止

## 2.栈在表达式求值中的应用

###### **1.算术表达式**

最常见的算数表达式是数字在两侧,符号在中间的**中缀表达式**

>   计算机为了方便计算,所以引入了**前缀表达式**或**后缀表达式**

中缀表达式和树:最明显的子节点都是数字,父节点则是符号

```
中缀表达式:AA+B*(C-D)-E/F
添加括号:((A+(B*(C-D)))-(E/F))
表达式树:即根据运算顺序得到的树状结构
=======================================
		   '-'
		 /     \
	   '+'      '/'
	  /  \      /  \
	 A   '*'   E    F
	    /   \
	   B     -
	        /  \
	       C    D	       
=======================================
后缀表达式:ABCD-*+EF/-
```

###### **2.中缀表达式$\rightarrow$后缀表达式**

**方法A:画出表达式树,然后直接写**

**方法B:运算符后移法(Eg:`A+B*(C-D)-E/F`)**

(1):加括号:`((A+(B*(C-D)))-(E/F))`

(2):运算符后移:`((A(B(CD)-)*)+(EF)/)-`

(3):去括号:`ABCD-*+EF/-`

>   直觉:操作数放在括号里面表示需要先运算->遇到右括号的优先级

**方法B的实现:运算符栈(存储没有被匹配的运算符)**

(1):遇到操作数->直接加入后缀表达式

(2a):遇到`(`->直接入栈

(2b):遇到`)`->一直出栈并加入后缀表达式,直到遇到`(`

(3a):遇到运算符:运算优先级高于栈顶运算符或者栈顶是`(`,直接入栈

(3b):遇到运算符:运算优先级低于等于栈顶运算符,一直出栈,直到栈顶为`(`或者运算优先级更低的运算符

## 3.栈在递归中的应用

**<font color=red>递归:若一个函数/过程/数据结构,在定义中直接或间接引用自身,则为递归</font>**

>   递归是通过将原问题分解为规模更小**且结构相同的**子问题求解
>
>   递归体(递归表达式):描述问题如何分解为更小规模的同类子问题(核心)
>
>   递归边界:确保递归在有限步内终止

栈在递归中的应用:**递归调用栈**->递归深度过大时容易导致栈溢出

>   递归的缺点:存在大量重复计算(为了计算更高层反复调用叶节点)

## 4.队列在层次遍历中的应用

背景:需要逐层或者逐行处理的问题->将下一层元素加入待处理队列(FIFO)

算法:将所有同层的结点加入队列,处理完成后再放入下一层所有结点

>   取出队首元素访问其左右孩子,将孩子入队

```
           'a'
		 /     \
	   'b'      'c'				则:a|bc|def
	  /  \     /  
	'd'  'e'  'f'   
```

## 5.队列在计算机系统中的应用

###### **场景一:解决主机与外部设备之间速度不匹配问题**

问题:主机输出数据的速度远快于打印机处理数据速度->直接发送会数据丢失和错误

(1)主机将待打印的数据依次存入缓冲区,直到缓冲区满,主机停止输出

(2)打印机则从缓冲区中FIFO取出数据进行打印

(3)打印机向主机发出请求,主机再次向缓冲区写入新的数据

###### **场景二:解决多用户的资源竞争问题**

用户通过各自的终端向操作系统提出对CPU的请求

(1)每次将CPU分配给队首用户的程序运行

(2)运行结束或用完规定的时间片以后,操作系统让它出队

(3)CPU分配给新的队首用户
