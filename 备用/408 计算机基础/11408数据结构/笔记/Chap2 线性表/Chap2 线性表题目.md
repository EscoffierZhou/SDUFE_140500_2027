###### **33(没错但是是新题)2016统考**

| 变量/对象    | 存放区域  | 物理地址 | 存的值      |
| ------------ | --------- | -------- | ----------- |
| 指针变量L    | 栈(Stack) | 0x2000   | 0x1000      |
| 头节点       | 堆(Heap)  | 0x1000   | [data,next] |
| 头节点->next | 堆(Heap)  | 0x1004   | 0x1000      |

>   **首先,头节点和指针变量L的存放区域完全不同**
>
>   **其次,头节点和指针变量L的物理地址不相同**
>
>   正确说法:头节点的指针域所指向的地址，与头结点的地址相等。

| 地址  | 元素 | 链接地址 |
| ----- | ---- | -------- |
| 1000H | a    | 1010H    |
| 1004H | b    | 100CH    |
| 1008H | c    | 1000H    |
| 100CH | d    | NULL     |
| 1010H | e    | 1004H    |
| 1014H |      |          |

将f存放在1014H处并插入单链表,若f在逻辑上位于a和e之间,a,e,f的链接地址是?

>   从d反向构建原单链表:c->a->e->b->d
>
>   由于插入仅f地址变化(链表O(1)特点):
>
>   | 地址  | 元素 | 链接地址 |

>   所以最后是a:1014H,e:1004H,f:1010H
