# 8.2 插入排序

**基本思想:每次将一个待排序的记录,按照关键字啊小插入到前面已经排好序的子序列**

插入排序的时间复杂度都是$O(n^2)$,和元素是否基本有序有关,如果存在基本有序,则希尔排序好点$O(n^{1.3})$

**<font color=red>插入排序包括:直接插入排序/折半插入排序/希尔排序</font>**

## 1.直接插入排序

```
有序序列L[1...i-1]		| 		L[i]		|		无序序列L[i+1...n]
```

最简单

>   (1):遍历到L(i)的时候,查找在前面L[1...i-1]中找到一个插入位置k
>
>   (2):对于L[k-1...i-1],往后挪一位
>
>   (3):将L(i)放入位置k

额外将表首A[0]作为哨兵节点,用于复制A[i]\(需要插入的元素)

```c++
void InsertSort(ElemType A[],int n){
    int i,j;
    // A[1]是长度为1的有序表,所以从第二个元素开始
    for(i=2;i<=n;i++)				
        if(A[i]<A[i-1]){// 如果遍历的时候小于前面的元素,进入插入流程
            A[0] = A[i];
            for(j=i-1;A[0]<A[j];--j)//这里是倒序查的!!!
                A[j+1] = A[j];
            A[j+1] = A[0];
        }
}
```

>   **<font color=red>需要注意的是,有相同关键字的也要移动到后面(相等判定)</font>**
>
>   ==由于判断插入位置是倒序看的,所以越正序的比较次数越少==
>
>   空间复杂度:O(1)
>
>   时间复杂度:O(n^2^)(有序表内n次,外部查找n次)/最好情况O(n)/随机时查找和移动次数约为$\frac{n^2}{4}$

>稳定性:相同大小关键字,仍保持相对顺序(比如上面的49),因此直接排序是稳定排序
>
>适用性:适用于顺序存储和链式存储的线性表,使用链式存储无需移动元素(修改next指针)

## 2.折半插入排序

插入排序:	对于每个元素都进行两步操作(查找正确位置+腾出空间移动)

折半插入排序:    折半查找提高效率,定位以后,对半的元素组统一后移一位

```C++
void BInsertSort(ElemType A[],int n){
    int i,j,low,high,mid;
    for(i=2;i<=n;i++){
        A[0] = A[i];
        low=1;
        high=i-1;
        while(low<=high){
            mid = (low+high)/2;
            if(A[mid]>A[0])high = mid-1;
            else low=mid+1;
        }
        for(j=i-1;j>=high+1;--j)
            A[j+1] = A[j];
        A[high+1] = A[0];
    }
}
```

**基本思路:**

>(1):暂存元素A[i]放到A[0]
>
>(2-Loop):初始化边界,下界low=0;high=i-1;
>
>(3):折半查找:只要$low \leq high$,就计算中点$\lfloor (low+high)/2 \rfloor$
>
>>中点$\lfloor (low+high)/2 \rfloor>$比较元素,则说明比较元素插在左侧,high指针左移缩小范围(high = mid - 1)
>>
>>中点$\lfloor (low+high)/2 \rfloor\leq$比较元素,则说明比较元素插在右侧,low指针右移缩小范围(low = mid + 1)
>
>(4):循环被打破(low>high),找到了插入的位置
>
>(5):对后半元素整体后移,留出插入位置
>
>(6):插入操作

```
Eg:(58),57,59,72 <-58 A[0]=58
(1)low=0,high=i-1=3
   第一次折半:mid=(0+3)/2=1,A[1]=59>A[0]=58
			 目标在左半区:high = mid - 1 = 0
(2)low=0.high=(0+0)/2=0
   第二次折半:mid=(0+0)/2=0,A[0]=58=A[0]=58
   			 目标在右半区:low = mid + 1 = 1
(3)low=1,high=0,因此循环打破,在A[1]插入
(4)对于A[1]以后的元素,整体后移,然后插入	  
```

>空间复杂度:O(1)
>
>时间复杂度:减少了查找有序表内插入位置的比较次数$O(log_2n)$,外部不变,整体$O(nlog_2n)$[查找]
>
>​	  但是!!!仍然整体排序仍然看本身的有序性,时间复杂度仍然是$O(n^2)$

>   稳定性:相同大小关键字,仍保持相对顺序,是稳定排序
>
>   适用性:仅适用于顺序存储的线性表

## 3.希尔排序

目的:如果序列基本有序的前提下,直接排序可以优化到O(n),因此进行粗略排序

核心思想:通过逐步缩小增量的方式,对表中相隔一定距离的元素构成的子序列进行多次直接插入排序

最后通过一趟完整的直接插入排序(d=1)完成整体排序

但是目前没有找到最合适的增量序列,默认从一个值开始逐渐减到1

**<font color=red>注意,并非划分为[49,38,65,97,76,13]区间</font>**

>   而是d=5,整体划分为$[49,13][38,27][65,49][97,55][76,04]$5个线性表,然后单独做直接排序
>
>   $[13,49][27,38],[49,65],[55,97],[04,76]$
>
>   (d=5,算后不算前)
>
>   ==这里是比较理想的情况,不应该只有两两配对==,比如存在[35,36,7],直接插入排序后是[7,35,36]

```
		49 		38 		65 		97 		76 		13 		27 		49 		55 		04
d=5     (49) 	38 		65 		97 		76 		(13) 	27 		49 		55 		04
aft   	13	   	27		49		55		04		49		38		65		97		76
d=4		(13)	27		49		55		(04)	49		38		65		97		76
```

```C++
void ShellSort(ElemType A[],int n){
	int dk,i,j;
	for(dk=n/2;dk>=1;dk=dk/2){// 这里的增量变换函数不是固定的
        for(i=dk+1;i<=n;++i){
            if(A[i]<A[i-dk]){
                A[0] = A[i];
                for(j=i-dk;j>0&&A[0]<A[j];j-=dk)
                    A[j+dk] = A[j];
                A[j+dk] = A[0] // 插入
            }
        }
    }
}
```

>空间复杂度:O(1)
>
>时间复杂度:依赖增量序列函数,n在常见范围内$O(n^{1.3})$,最坏退化为$O(n^2)$

>稳定性:相同大小的关键字被划分到不同线性表,可能会改变它们的相对次序
>
>适用性:仅适用于顺序存储的线性表
