# Chap8.3 交换排序

交换:根据两个元素关键字的比较结果,互换它们在序列中的位置

交换排序包括:冒泡排序/快速排序

## 1.冒泡排序

基本思想:**从前往后(或从后往前)**依次比较相邻元素的关键字,若为逆序,则交换它们的位置

>   **<font color=red>注意:每次排序都会将当前未排序部分中最小/最大元素放在最终位置</font>**
>
>   所以需要进行n-1次冒泡就可以完成整个排序

```c++
void BubbleSort(ElemType A[],int n){
    for(int i=0;i<n-1;i++)}{
    	bool flag = false;
    	for(int j=n-1;j>i;j--){		// 逆序
            if(A[j-1]>A[j]){		
                swap(A[j-1],A[j]);	// 则交换
                flag = true;
            }
        }
    	if(flag==false)	// 本趟遍历后没有发生交换,所以表已经有序
            return;
	}
}
```

>空间复杂度:O(1)
>
>时间复杂度:最好情况(初始序列有序):仅需要第一趟冒泡,进行n-1次比较,0次移动,$O(n)$
>
>​	  最坏情况(初始序列逆序):需要n-1趟排序(第i趟需要n-i次比较),$$O(n^2)$$
>
>​	  总比较次数:$\sum^{n-1}_{i=1}(n-i) = \frac{n(n-1)}{2}$,移动次数:$\sum^{n-1}_{i=1}3(n-i) = \frac{3n(n-1)}{2}$
>
>**<font color=red>特点:每趟有序子序列具有全局有序性:每一趟都有一个元素被放在最终位置</font>**

>稳定性:比较相邻元素的时候,相同元素不会被交换,因此稳定
>
>适用性:适用于链式存储和顺序存储

## 2.快速排序

基本思想:在待排序表L[1...n]中任取一个元素作为枢轴(通常取首元素)

>   通过一趟排序将原表划分为两个独立的子表L[1...k-1]和L[k+1...n]
>
>   使得左子表中所有元素的关键字都小于枢轴,右子表中所有元素的关键字都大于枢轴
>
>   同时枢轴元素被放在最终位置L(k)上,这个过程为一次划分
>
>   ->随后对两个子表递归进行:枢轴->划分(直到每个子表仅包含一个元素或者为空)

```C++
int Partition(ElemType A[],int low,int high){
    ElemType pivot = A[low];
    while(low<high){
        while(low<high && A[high]>=pivot)--high;
        A[low] = A[high];
        while(low<high && A[low]<=pivot)++low;
        A[high]= A[low];
    }
    A[low]=pivot;
    return low;
}
```

>空间复杂度:需要递归调用栈,最好情况$O(log_2n)$,最坏情况$O(n)$
>
>时间复杂度:最坏情况:初始序列基本有序 或 基本逆序,每趟划分仅减少一个元素:$O(n^2)$
>
>​	  最好情况:每次划分将序列等分为两部分:$O(nlog_2n)$
>
>特点:取枢轴:三数取中法

>稳定性:由于涉及到分块的位置,内外相对位置不变,但是左右变了,比如a1a2b1->b1a2a1
>
>适用性:快速排序能够随机访问元素,所以适用于顺序存储的线性表
>
>**<font color=red>特点:快速排序在每趟划分后不会产生全局有序的子序列,但是枢轴能确定最终位置</font>**
